# Algorithm Notes · 算法学习笔记

## 📖 [点击阅读《算法学习手册》](算法学习手册/算法学习手册.md)

以本地四章算法模板与基础课题目清单为依据，解释代码怎样执行、为什么正确、何时使用，以及容易出错的边界。

组织方式参照 [XCPC 算法模板](https://github.com/xingchen7749/xcpc-algorithm-templates)：总手册、分章节、独立代码与验证报告。内容来自本地学习资料，未复制参考仓库的讲解或程序。

- [分章节阅读](算法学习手册/章节/)：基础算法、数据结构、搜索与图论、数学知识、动态规划、贪心。
- [104 道题目索引](算法学习手册/题目索引.md)：按原 Word 文档分类导航。
- [清单专有题目补充](算法学习手册/清单专有题目补充.md)：模板文件未包含的另外 15 道题对应知识点。
- [完整 C++17 示例](算法学习手册/代码/README.md)：8 个可编译、可运行的入门程序。
- [原文片段](算法学习手册/原文片段/)：保留原有模板和公式，按条目拆分；这些是教学片段，包含未定义变量、伪代码和原始笔误，不能当完整程序直接编译。
- [来源、去重与修正](算法学习手册/来源与修正.md)：逐项记录原模板的问题与处理建议。
- [验证报告](算法学习手册/验证报告.md)：内容覆盖、链接、重复生成及程序测试。

当前包含 **63 个原文讲解条目、23 个 DP/贪心补充专题、15 个清单专有题目说明**。第五、六章的原文件只有题目清单，没有代码；本项目明确把相应讲解与示例标为补充。

## 建议阅读顺序

先读基础算法，练排序、二分、前缀和；再读数据结构与图论，最后学习数学、动态规划、贪心。每次先理解状态或不变量，再手算例子，再运行程序。练习时自行补齐题面要求的输入输出，不把片段中的全局变量默认视为已经初始化。

## 维护与验证

在项目根目录运行（Python 3.10+，GNU C++17）：

```sh
python build_handbook.py
python verify_handbook.py
python verify_programs.py
```

`handbook_data.py` 维护逐条讲解；`build_handbook.py` 读取 `原始资料/` 后生成六章、总手册、片段与题目索引。补充说明、完整程序、来源说明为手工维护文件，不会被生成器覆盖。

`verify_programs.py` 可使用环境变量 `CXX` 指定编译器；没有编译器时会明确失败，不会把未运行项目记成通过。验证报告记录本地编译与测试，不代表已经通过 AcWing 在线评测。
