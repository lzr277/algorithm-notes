## 试除法判定质数

来源：`第四章.txt` 第 1 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 866。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

若合数存在因子，至少有一个不超过平方根。

### 代码与步骤解读

x<2直接false，循环i<=x/i，找到整除即false。

### 为什么正确

若两个因子都大于sqrt(x)，乘积就大于x。

### 复杂度

O(√x)时间，O(1)空间。

### 使用条件与易错点

i<=x/i避免i*i溢出；只对正整数讨论素数。

### 小例子

49在i=7找到因子，判合数。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
bool is_prime(int x)
{
    if (x < 2) return false;
    for (int i = 2; i <= x / i; i ++ )
        if (x % i == 0)
            return false;
    return true;
}
```

## 试除法分解质因数

来源：`第四章.txt` 第 10 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 867。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

按小到大试除并记录指数。

### 代码与步骤解读

能整除时不断x/=i并增加s，循环后x>1则剩余一个大质因子。

### 为什么正确

较小因子已被移尽，所以每次发现的新因子必为质数。

### 复杂度

O(√x)时间，O(log x)输出空间。

### 使用条件与易错点

x>=1；输入1没有质因子；除法会改变x，要保留原值另存副本。

### 小例子

72=2³×3²。

```text
void divide(int x)
{
    for (int i = 2; i <= x / i; i ++ )
        if (x % i == 0)
        {
            int s = 0;
            while (x % i == 0) x /= i, s ++ ;
            cout << i << ' ' << s << endl;
        }
    if (x > 1) cout << x << ' ' << 1 << endl;
```

## 朴素筛法求素数

来源：`第四章.txt` 第 23 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 868。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

从每个未筛掉的素数标记其倍数。

### 代码与步骤解读

遇到st[i]跳过，否则记录素数并把j=i,i+i...标记。

### 为什么正确

每个合数至少被其某个素因子标记。

### 复杂度

O(n log log n)时间，O(n)空间。

### 使用条件与易错点

原版本虽然叫朴素筛，但只枚举素数倍数，属于埃氏筛；可从i*i开始，注意乘法溢出。

### 小例子

到10的素数为2,3,5,7。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
int primes[N], cnt;     // primes[]存储所有素数
bool st[N];         // st[x]存储x是否被筛掉

void get_primes(int n)
{
    for (int i = 2; i <= n; i ++ )
    {
        if (st[i]) continue;
        primes[cnt ++ ] = i;
        for (int j = i; j <= n; j += i)
            st[j] = true;
    }
}
```

## 线性筛法求素数

来源：`第四章.txt` 第 37 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 868。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

使每个合数只由最小质因子筛掉一次。

### 代码与步骤解读

依次枚举primes[j]，标记i*p；若p整除i立即break。

### 为什么正确

break防止用非最小质因子重复标记同一个合数。

### 复杂度

O(n)时间与空间。

### 使用条件与易错点

最好写j<cnt&&primes[j]<=n/i；重复调用前清空cnt与st；容量需覆盖n。

### 小例子

12只由6×2筛掉。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
int primes[N], cnt;     // primes[]存储所有素数
bool st[N];         // st[x]存储x是否被筛掉

void get_primes(int n)
{
    for (int i = 2; i <= n; i ++ )
    {
        if (!st[i]) primes[cnt ++ ] = i;
        for (int j = 0; primes[j] <= n / i; j ++ )
        {
            st[primes[j] * i] = true;
            if (i % primes[j] == 0) break;
        }
    }
}
```

## 试除法求所有约数

来源：`第四章.txt` 第 53 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 869。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

成对枚举小于等于平方根的因子。

### 代码与步骤解读

若i整除x，加入i和x/i；平方数时只加入一次；最后排序。

### 为什么正确

每个因子都有互补因子，枚举较小者覆盖全部。

### 复杂度

枚举O(√x)，排序O(d log d)，空间O(d)。

### 使用条件与易错点

x>0；d为约数个数；平方根重复必须排除。

### 小例子

12的约数1,2,3,4,6,12。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
vector<int> get_divisors(int x)
{
    vector<int> res;
    for (int i = 1; i <= x / i; i ++ )
        if (x % i == 0)
        {
            res.push_back(i);
            if (i != x / i) res.push_back(x / i);
        }
    sort(res.begin(), res.end());
    return res;
}
```

```text
如果 N = p1^c1 * p2^c2 * ... *pk^ck

```

## 欧几里得算法

来源：`第四章.txt` 第 70 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 872。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

使用gcd(a,b)=gcd(b,a%b)。

### 代码与步骤解读

当b=0返回a，否则递归交换并取余。

### 为什么正确

两数的公共因子集合在这一步保持不变。

### 复杂度

O(log min(a,b))时间与递归空间。

### 使用条件与易错点

原模板适用非负a,b；负数先规范化；gcd(0,0)=0约定；lcm先除再乘减少溢出。

### 小例子

gcd(18,12)=gcd(12,6)=6。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
int gcd(int a, int b)
{
    return b ? gcd(b, a % b) : a;
}
```

## 求欧拉函数

来源：`第四章.txt` 第 75 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 873。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

欧拉函数计数1..x中与x互质的数。

### 代码与步骤解读

每个不同素因子p让res变为res/p*(p-1)，最后处理残留大因子。

### 为什么正确

容斥或独立排除素因子倍数得到x∏(1-1/p)。

### 复杂度

O(√x)时间，O(1)空间。

### 使用条件与易错点

x>=1且phi(1)=1；先除后乘避免溢出；Euler定理需gcd(a,m)=1。

### 小例子

phi(12)=12×1/2×2/3=4。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
int phi(int x)
{
    int res = x;
    for (int i = 2; i <= x / i; i ++ )
        if (x % i == 0)
        {
            res = res / i * (i - 1);
            while (x % i == 0) x /= i;
        }
    if (x > 1) res = res / x * (x - 1);

    return res;
}
```

## 筛法求欧拉函数

来源：`第四章.txt` 第 89 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 874。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

在线性筛过程中递推欧拉函数。

### 代码与步骤解读

若p整除i，phi(i*p)=phi(i)*p并break；否则乘(p-1)。

### 为什么正确

新素因子与已有素因子的两种情况由乘积公式直接推出。

### 复杂度

O(n)时间与空间。

### 使用条件与易错点

euler[1]=1；总和可能超int，求和用long long；重置数组。

### 小例子

phi(6)=phi(3)×(2-1)=2。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
int primes[N], cnt;     // primes[]存储所有素数
int euler[N];           // 存储每个数的欧拉函数
bool st[N];         // st[x]存储x是否被筛掉


void get_eulers(int n)
{
    euler[1] = 1;
    for (int i = 2; i <= n; i ++ )
    {
        if (!st[i])
        {
            primes[cnt ++ ] = i;
            euler[i] = i - 1;
        }
        for (int j = 0; primes[j] <= n / i; j ++ )
        {
            int t = primes[j] * i;
            st[t] = true;
            if (i % primes[j] == 0)
            {
                euler[t] = euler[i] * primes[j];
                break;
            }
            euler[t] = euler[i] * (primes[j] - 1);
        }
    }
}
```

## 快速幂

来源：`第四章.txt` 第 118 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 875。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

把指数拆成二进制位减少乘法次数。

### 代码与步骤解读

k&1时累乘t，t每轮平方，k右移。

### 为什么正确

循环保持res*t^k与最初的m^k同余。

### 复杂度

O(log k)时间，O(1)空间。

### 使用条件与易错点

原res*t与t*t为int会溢出，应1LL提升；p>0、k>=0；k=0返回1%p；更大模数需更宽乘法。

### 小例子

3^5 mod7=5。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
求 m^k mod p，时间复杂度 O(logk)。

int qmi(int m, int k, int p)
{
    int res = 1 % p, t = m;
    while (k)
    {
        if (k&1) res = res * t % p;
        t = t * t % p;
        k >>= 1;
    }
    return res;
}
```

## 扩展欧几里得算法

来源：`第四章.txt` 第 132 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 877。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

递归求贝祖等式的系数。

### 代码与步骤解读

基础b=0给x=1,y=0；递归交换系数后y-=(a/b)*x。

### 为什么正确

把bx'+(a%b)y'=d展开，可还原ax+by=d。

### 复杂度

O(log min(a,b))时间与递归空间。

### 使用条件与易错点

用long long；ax≡c mod m有解当且仅当gcd(a,m)整除c；系数可为负，解需规范到模范围。

### 小例子

30×(-1)+18×2=6。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
// 求x, y，使得ax + by = gcd(a, b)
int exgcd(int a, int b, int &x, int &y)
{
    if (!b)
    {
        x = 1; y = 0;
        return a;
    }
    int d = exgcd(b, a % b, y, x);
    y -= (a/b) * x;
    return d;
}
```

## 高斯消元

来源：`第四章.txt` 第 145 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 883。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

用等价行变换将增广矩阵化为阶梯形。

### 代码与步骤解读

选绝对值最大主元、归一化、消下方系数；秩不足检查矛盾行，唯一解回代。

### 为什么正确

交换、非零倍乘与加减其他行保持解集合。

### 复杂度

O(n³)时间，O(n²)空间。

### 使用条件与易错点

double与eps按尺度选择；0=非零为无解；原实现为方程数=未知数的方阵；精度误差可能需要残差复核。

### 小例子

x+y=3、x-y=1得到x=2,y=1。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
// a[N][N]是增广矩阵
int gauss()
{
    int c, r;
    for (c = 0, r = 0; c < n; c ++ )
    {
        int t = r;
        for (int i = r; i < n; i ++ )   // 找到绝对值最大的行
            if (fabs(a[i][c]) > fabs(a[t][c]))
                t = i;

        if (fabs(a[t][c]) < eps) continue;

        for (int i = c; i <= n; i ++ ) swap(a[t][i], a[r][i]);      // 将绝对值最大的行换到最顶端
        for (int i = n; i >= c; i -- ) a[r][i] /= a[r][c];      // 将当前上的首位变成1
        for (int i = r + 1; i < n; i ++ )       // 用当前行将下面所有的列消成0
            if (fabs(a[i][c]) > eps)
                for (int j = n; j >= c; j -- )
                    a[i][j] -= a[r][j] * a[i][c];

        r ++ ;
    }

    if (r < n)
    {
        for (int i = r; i < n; i ++ )
            if (fabs(a[i][n]) > eps)
                return 2; // 无解
        return 1; // 有无穷多组解
    }

    for (int i = n - 1; i >= 0; i -- )
        for (int j = i + 1; j < n; j ++ )
            a[i][n] -= a[i][j] * a[j][n];

    return 0; // 有唯一解
}
```

## 递归法求组合数

来源：`第四章.txt` 第 183 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 885。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

用Pascal递推预处理组合数。

### 代码与步骤解读

c[i][0]=1，c[i][j]=c[i-1][j]+c[i-1][j-1]。

### 为什么正确

按是否选择某个固定元素，把方案分成不相交两类。

### 复杂度

预处理O(N²)时间空间，查询O(1)。

### 使用条件与易错点

```text
首先预处理出所有阶乘取模的余数fact[N]，以及所有阶乘取模的逆元infact[N]

int qmi(int a, int k, int p)    // 快速幂模板
{
```

## Lucas定理

来源：`第四章.txt` 第 211 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 887。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

把大组合数分解到素数进制的每一位。

### 代码与步骤解读

递归计算C(a%p,b%p)*lucas(a/p,b/p)模p。

### 为什么正确

Lucas定理表明各位组合数的乘积给出结果。

### 复杂度

当前小组合数逐项算，最坏O(p log p·log_p n)，栈O(log_p n)。

### 使用条件与易错点

p必须素数；C(a,b)在b>a应返回0；b=0是1；大p时逐项求逆较慢。

### 小例子

C(8,2) mod3=1。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
若p是质数，则对于任意整数 1 <= m <= n，有：
    C(n, m) = C(n % p, m % p) * C(n / p, m / p) (mod p)

int qmi(int a, int k)       // 快速幂模板
{
    int res = 1;
    while (k)
    {
        if (k & 1) res = (LL)res * a % p;
        a = (LL)a * a % p;
        k >>= 1;
    }
    return res;
}


int C(int a, int b)     // 通过定理求组合数C(a, b)
{
    int res = 1;
    for (int i = 1, j = a; i <= b; i ++, j -- )
    {
        res = (LL)res * j % p;
        res = (LL)res * qmi(i, p - 2) % p;
    }
    return res;
}


int lucas(LL a, LL b)
{
    if (a < p && b < p) return C(a, b);
    return (LL)C(a % p, b % p) * lucas(a / p, b / p) % p;
}
```

## 分解质因数法求组合数

来源：`第四章.txt` 第 245 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 888。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

直接求组合数各素因子的指数再高精度还原。

### 代码与步骤解读

get(n,p)累加floor(n/p^k)；指数为a!减b!和(a-b)!；高精度连乘。

### 为什么正确

阶乘商的质因子指数相减，唯一分解还原精确整数。

### 复杂度

筛O(a)，指数O(π(a)log a)，连乘成本取决于答案位数与总乘次数；空间O(a+位数)。

### 使用条件与易错点

0<=b<=a；不是固定模数算法；中间乘积用long long，特别是大素数。

### 小例子

C(5,2)=2×5=10。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
当我们需要求出组合数的真实值，而非对某个数的余数时，分解质因数的方式比较好用：
    1. 筛法求出范围内的所有质数
    2. 通过 C(a, b) = a! / b! / (a - b)! 这个公式求出每个质因子的次数。 n! 中p的次数是 n / p + n / p^2 + n / p^3 + ...
    3. 用高精度乘法将所有质因子相乘

int primes[N], cnt;     // 存储所有质数
int sum[N];     // 存储每个质数的次数
bool st[N];     // 存储每个数是否已被筛掉


void get_primes(int n)      // 线性筛法求素数
{
    for (int i = 2; i <= n; i ++ )
    {
        if (!st[i]) primes[cnt ++ ] = i;
        for (int j = 0; primes[j] <= n / i; j ++ )
        {
            st[primes[j] * i] = true;
            if (i % primes[j] == 0) break;
        }
    }
}


int get(int n, int p)       // 求n！中的次数
{
    int res = 0;
    while (n)
    {
        res += n / p;
        n /= p;
    }
    return res;
}


vector<int> mul(vector<int> a, int b)       // 高精度乘低精度模板
{
    vector<int> c;
    int t = 0;
    for (int i = 0; i < a.size(); i ++ )
    {
        t += a[i] * b;
        c.push_back(t % 10);
        t /= 10;
    }

    while (t)
    {
        c.push_back(t % 10);
        t /= 10;
    }

    return c;
}

get_primes(a);  // 预处理范围内的所有质数

for (int i = 0; i < cnt; i ++ )     // 求每个质因数的次数
{
    int p = primes[i];
    sum[i] = get(a, p) - get(b, p) - get(a - b, p);
}

vector<int> res;
res.push_back(1);

for (int i = 0; i < cnt; i ++ )     // 用高精度乘法将所有质因子相乘
    for (int j = 0; j < sum[i]; j ++ )
        res = mul(res, primes[i]);
```

## NIM游戏

来源：`第四章.txt` 第 319 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 891。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

把多堆取石游戏的局面表示成异或和。

### 代码与步骤解读

计算A1^...^An；非零先手胜，零先手败。

### 为什么正确

零局面任一步变非零，非零局面可选最高位把某堆变小使异或归零。

### 复杂度

O(n)时间，O(1)空间。

### 使用条件与易错点

每次仅一堆、任意正数量、取最后者胜；misère版本或限制取法不能直接套；有限无环公平游戏才能直接用SG递推。

### 小例子

[1,2,3]异或0，先手败。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
给定N堆物品，第i堆物品有Ai个。两名玩家轮流行动，每次可以任选一堆，取走任意多个物品，可把一堆取光，但不能不取。取走最后一件物品者获胜。两人都采取最优策略，问先手是否必胜。

我们把这种游戏称为NIM博弈。把游戏过程中面临的状态称为局面。整局游戏第一个行动的称为先手，第二个行动的称为后手。若在某一局面下无论采取何种行动，都会输掉游戏，则称该局面必败。
所谓采取最优策略是指，若在某一局面下存在某种行动，使得行动后对面面临必败局面，则优先采取该行动。同时，这样的局面被称为必胜。我们讨论的博弈问题一般都只考虑理想情况，即两人均无失误，都采取最优策略行动时游戏的结果。
NIM博弈不存在平局，只有先手必胜和先手必败两种情况。

定理： NIM博弈先手必胜，当且仅当 A1 ^ A2 ^ … ^ An != 0

公平组合游戏ICG
若一个游戏满足：

由两名玩家交替行动；
在游戏进程的任意时刻，可以执行的合法行动与轮到哪名玩家无关；
不能行动的玩家判负；
则称该游戏为一个公平组合游戏。
NIM博弈属于公平组合游戏，但城建的棋类游戏，比如围棋，就不是公平组合游戏。因为围棋交战双方分别只能落黑子和白子，胜负判定也比较复杂，不满足条件2和条件3。

有向图游戏
给定一个有向无环图，图中有一个唯一的起点，在起点上放有一枚棋子。两名玩家交替地把这枚棋子沿有向边进行移动，每次可以移动一步，无法移动者判负。该游戏被称为有向图游戏。
任何一个公平组合游戏都可以转化为有向图游戏。具体方法是，把每个局面看成图中的一个节点，并且从每个局面向沿着合法行动能够到达的下一个局面连有向边。

Mex运算
设S表示一个非负整数集合。定义mex(S)为求出不属于集合S的最小非负整数的运算，即：
mex(S) = min{x}, x属于自然数，且x不属于S

SG函数
在有向图游戏中，对于每个节点x，设从x出发共有k条有向边，分别到达节点y1, y2, …, yk，定义SG(x)为x的后继节点y1, y2, …, yk 的SG函数值构成的集合再执行mex(S)运算的结果，即：
SG(x) = mex({SG(y1), SG(y2), …, SG(yk)})
特别地，整个有向图游戏G的SG函数值被定义为有向图游戏起点s的SG函数值，即SG(G) = SG(s)。
```

## 有向图游戏的和
