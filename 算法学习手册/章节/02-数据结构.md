## 单链表

来源：`第二章.txt` 第 1 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 826。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

数组下标模拟节点和next指针。

### 代码与步骤解读

e存值，ne存后继，head=-1表示空，idx分配新节点。

### 为什么正确

插头时新节点指向旧head，再把head改为新节点。

### 复杂度

已知位置插删O(1)，查找O(n)，空间O(容量)。

### 使用条件与易错点

remove只能删除存在的头节点；idx通常只增不复用；节点编号不是链表位置。

### 小例子

头插3再头插5，链为5→3。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
// head存储链表头，e[]存储节点的值，ne[]存储节点的next指针，idx表示当前用到了哪个节点
int head, e[N], ne[N], idx;

// 初始化
void init()
{
    head = -1;
    idx = 0;
}

// 在链表头插入一个数a
void insert(int a)
{
    e[idx] = a, ne[idx] = head, head = idx ++ ;
}

// 将头结点删除，需要保证头结点存在
void remove()
{
    head = ne[head];
}
```

## 双链表

来源：`第二章.txt` 第 23 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 827。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

用左右指针支持已知节点的双向插删。

### 代码与步骤解读

0、1是两个哨兵；插入时连好新节点两端再修改邻居；删除时让左右邻居互相连接。

### 为什么正确

操作后每条相邻关系都有相反方向的对应指针。

### 复杂度

已知节点插删O(1)，空间O(容量)。

### 使用条件与易错点

不能删除哨兵；初始化idx=2；注意操作编号到节点编号的偏移。

### 小例子

0↔a↔1，在a右侧插b得到0↔a↔b↔1。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
// e[]表示节点的值，l[]表示节点的左指针，r[]表示节点的右指针，idx表示当前用到了哪个节点
int e[N], l[N], r[N], idx;

// 初始化
void init()
{
    //0是左端点，1是右端点
    r[0] = 1, l[1] = 0;
    idx = 2;
}

// 在节点a的右边插入一个数x
void insert(int a, int x)
{
    e[idx] = x;
    l[idx] = a, r[idx] = r[a];
    l[r[a]] = idx, r[a] = idx ++ ;
}

// 删除节点a
void remove(int a)
{
    l[r[a]] = l[a];
    r[l[a]] = r[a];
}
```

## 单调栈

### 代码与步骤解读

### 复杂度

总O(n)时间，O(n)空间。

### 使用条件与易错点

栈存下标便于求距离；严格与非严格决定>=或>；每次读栈顶前判空。

### 小例子

[3,1,2]的左侧更小值为[-1,-1,1]。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
常见模型：找出每个数左边离它最近的比它大/小的数
int tt = 0;
for (int i = 1; i <= n; i ++ )
{
    while (tt && check(stk[tt], i)) tt -- ;
    stk[ ++ tt] = i;
}
```

## Trie树

来源：`第二章.txt` 第 144 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 835。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

共享字符串前缀形成字典树。

### 代码与步骤解读

son[p][u]是字符u对应的下一节点；缺节点时++idx；cnt记录完整单词次数。

### 为什么正确

走完字符串后唯一到达对应的终点。

### 复杂度

插入查询O(L)，空间O(节点数×字符集)。

### 使用条件与易错点

原模板仅支持小写a-z；查询前缀出现次数需额外维护经过次数；重置idx还需清空数组。

### 小例子

插入ab两次、abc一次，query(ab)=2。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
int son[N][26], cnt[N], idx;
// 0号点既是根节点，又是空节点
// son[][]存储树中每个节点的子节点
// cnt[]存储以每个节点结尾的单词数量

// 插入一个字符串
void insert(char *str)
{
    int p = 0;
    for (int i = 0; str[i]; i ++ )
    {
        int u = str[i] - 'a';
        if (!son[p][u]) son[p][u] = ++ idx;
        p = son[p][u];
    }
    cnt[p] ++ ;
}

// 查询字符串出现的次数
int query(char *str)
{
    int p = 0;
    for (int i = 0; str[i]; i ++ )
    {
        int u = str[i] - 'a';
        if (!son[p][u]) return 0;
        p = son[p][u];
    }
    return cnt[p];
}
```

## 堆

来源：`第二章.txt` 第 245 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 838、AcWing 839。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

完全二叉树中维护父节点不大于孩子。

### 代码与步骤解读

down选更小的孩子交换，up与父比较；ph和hp互为插入编号与堆位置映射。

### 为什么正确

每次局部交换把违例沿一条路径推进，最终恢复堆序。

### 复杂度

插删修改O(log n)，自底向上建堆O(n)，空间O(n)。

### 使用条件与易错点

heap_swap需同步h、ph、hp；删除后视情况up和down；size与STL函数重名时注意作用域。

### 小例子

小根堆[1,3,2]弹1后堆顶2。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
// h[N]存储堆中的值, h[1]是堆顶，x的左儿子是2x, 右儿子是2x + 1
// ph[k]存储第k个插入的点在堆中的位置
// hp[k]存储堆中下标是k的点是第几个插入的
int h[N], ph[N], hp[N], size;

// 交换两个点，及其映射关系
void heap_swap(int a, int b)
{
    swap(ph[hp[a]],ph[hp[b]]);
    swap(hp[a], hp[b]);
    swap(h[a], h[b]);
}

void down(int u)
{
    int t = u;
    if (u * 2 <= size && h[u * 2] < h[t]) t = u * 2;
    if (u * 2 + 1 <= size && h[u * 2 + 1] < h[t]) t = u * 2 + 1;
    if (u != t)
    {
        heap_swap(u, t);
        down(t);
    }
}

void up(int u)
{
    while (u / 2 && h[u] < h[u / 2])
    {
        heap_swap(u, u / 2);
        u >>= 1;
    }
}

// O(n)建堆
for (int i = n / 2; i; i -- ) down(i);
```

## 一般哈希

来源：`第二章.txt` 第 282 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 840。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

把整数映射到有限桶，用链或探测处理冲突。

### 代码与步骤解读

拉链法h初始化-1；开放寻址找到空位或相同值；负数用(x%N+N)%N。

### 为什么正确

同哈希值不代表同元素，最终必须比较真实值。

### 复杂度

平均O(1)，最坏O(n)，空间O(容量)。

### 使用条件与易错点

null必须定义成不会出现的整数哨兵或单独used数组；表满会无限探测；开放寻址删元素需墓碑。

### 小例子

x=-1时桶下标为N-1。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
(1) 拉链法
    int h[N], e[N], ne[N], idx;

    // 向哈希表中插入一个数
    void insert(int x)
    {
        int k = (x % N + N) % N;
        e[idx] = x;
        ne[idx] = h[k];
        h[k] = idx ++ ;
    }

    // 在哈希表中查询某个数是否存在
    bool find(int x)
    {
        int k = (x % N + N) % N;
        for (int i = h[k]; i != -1; i = ne[i])
            if (e[i] == x)
                return true;

        return false;
    }

(2) 开放寻址法
    int h[N];

    // 如果x在哈希表中，返回x的下标；如果x不在哈希表中，返回x应该插入的位置
    int find(int x)
    {
        int t = (x % N + N) % N;
        while (h[t] != null && h[t] != x)
        {
            t ++ ;
            if (t == N) t = 0;
        }
        return t;
    }
```

## 字符串哈希

来源：`第二章.txt` 第 320 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 841。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

多项式前缀哈希快速比较子串。

### 代码与步骤解读

h[i]=h[i-1]*P+字符；p[i]=P^i；h[r]-h[l-1]*p[长度]消除前缀。

### 为什么正确

乘相同幂对齐前缀后相减，只剩子串。

### 复杂度

预处理O(n)，查询O(1)，空间O(n)。

### 使用条件与易错点

unsigned long long溢出有定义，相当于模2^64；有碰撞，不能作为严格相等证明；可双哈希或复核。

### 小例子

abc的[2,3]与独立bc具有同一多项式值。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
核心思想：将字符串看成P进制数，P的经验值是131或13331，取这两个值的冲突概率低
小技巧：取模的数用2^64，这样直接用unsigned long long存储，溢出的结果就是取模的结果

typedef unsigned long long ULL;
ULL h[N], p[N]; // h[k]存储字符串前k个字母的哈希值, p[k]存储 P^k mod 2^64

// 初始化
p[0] = 1;
for (int i = 1; i <= n; i ++ )
{
    h[i] = h[i - 1] * P + str[i];
    p[i] = p[i - 1] * P;
}

// 计算子串 str[l ~ r] 的哈希值
ULL get(int l, int r)
{
    return h[r] - h[l - 1] * p[r - l + 1];
}
```

## C++ STL简介

来源：`第二章.txt` 第 340 行起。以下原文未改写，修正建议单独列出。

### 知识点与用途

按操作需求选择标准容器。

### 代码与步骤解读

vector连续存储，queue/stack限制访问端，priority_queue默认大根堆，map/set维护有序键。

### 为什么正确

容器封装对应数据结构，但复杂度与迭代器规则仍需遵守。

### 复杂度

vector尾插摊还O(1)；map/set查改O(log n)；unordered平均O(1)最坏O(n)。

### 使用条件与易错点

原文map.erase(pair)不正确，应erase(key)或迭代器；unordered支持迭代器++但不支持--和有序范围查询；empty时不可读front/top。

### 小例子

需要最小优先队列用priority_queue<int,vector<int>,greater<int>>。
