## 单链表

来源：`第二章.txt` 第 1 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 826。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

数组下标模拟节点和next指针。

### 代码与步骤解读

e存值，ne存后继，head=-1表示空，idx分配新节点。

### 为什么正确

插头时新节点指向旧head，再把head改为新节点。

### 复杂度

已知位置插删O(1)，查找O(n)，空间O(容量)。

### 使用条件与易错点

remove只能删除存在的头节点；idx通常只增不复用；节点编号不是链表位置。

### 小例子

头插3再头插5，链为5→3。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
// head存储链表头，e[]存储节点的值，ne[]存储节点的next指针，idx表示当前用到了哪个节点
int head, e[N], ne[N], idx;

// 初始化
void init()
{
    head = -1;
    idx = 0;
}

// 在链表头插入一个数a
void insert(int a)
{
    e[idx] = a, ne[idx] = head, head = idx ++ ;
}

// 将头结点删除，需要保证头结点存在
void remove()
{
    head = ne[head];
}
```

## 双链表

来源：`第二章.txt` 第 23 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 827。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

用左右指针支持已知节点的双向插删。

### 代码与步骤解读

0、1是两个哨兵；插入时连好新节点两端再修改邻居；删除时让左右邻居互相连接。

### 为什么正确

操作后每条相邻关系都有相反方向的对应指针。

### 复杂度

已知节点插删O(1)，空间O(容量)。

### 使用条件与易错点

不能删除哨兵；初始化idx=2；注意操作编号到节点编号的偏移。

### 小例子

0↔a↔1，在a右侧插b得到0↔a↔b↔1。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
// e[]表示节点的值，l[]表示节点的左指针，r[]表示节点的右指针，idx表示当前用到了哪个节点
int e[N], l[N], r[N], idx;

// 初始化
void init()
{
    //0是左端点，1是右端点
    r[0] = 1, l[1] = 0;
    idx = 2;
}

// 在节点a的右边插入一个数x
void insert(int a, int x)
{
    e[idx] = x;
    l[idx] = a, r[idx] = r[a];
    l[r[a]] = idx, r[a] = idx ++ ;
}

// 删除节点a
void remove(int a)
{
    l[r[a]] = l[a];
    r[l[a]] = r[a];
}
```

## 单调栈

来源：`第二章.txt` 第 106 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 830。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

丢弃不会成为最近更小元素的候选。

### 代码与步骤解读

求左侧最近严格更小值时，弹出所有>=a[i]的栈顶，再读取栈顶，最后压入i。

### 为什么正确

被弹出的元素更大且更远，以后会被当前元素支配。

### 复杂度

总O(n)时间，O(n)空间。

### 使用条件与易错点

栈存下标便于求距离；严格与非严格决定>=或>；每次读栈顶前判空。

### 小例子

[3,1,2]的左侧更小值为[-1,-1,1]。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
常见模型：找出每个数左边离它最近的比它大/小的数
int tt = 0;
for (int i = 1; i <= n; i ++ )
{
    while (tt && check(stk[tt], i)) tt -- ;
    stk[ ++ tt] = i;
}
```

## Trie树

来源：`第二章.txt` 第 144 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 835。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

共享字符串前缀形成字典树。

### 代码与步骤解读

son[p][u]是字符u对应的下一节点；缺节点时++idx；cnt记录完整单词次数。

### 为什么正确

走完字符串后唯一到达对应的终点。

### 复杂度

插入查询O(L)，空间O(节点数×字符集)。

### 使用条件与易错点

原模板仅支持小写a-z；查询前缀出现次数需额外维护经过次数；重置idx还需清空数组。

### 小例子

插入ab两次、abc一次，query(ab)=2。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
int son[N][26], cnt[N], idx;
// 0号点既是根节点，又是空节点
// son[][]存储树中每个节点的子节点
// cnt[]存储以每个节点结尾的单词数量

// 插入一个字符串
void insert(char *str)
{
    int p = 0;
    for (int i = 0; str[i]; i ++ )
    {
        int u = str[i] - 'a';
        if (!son[p][u]) son[p][u] = ++ idx;
        p = son[p][u];
    }
    cnt[p] ++ ;
}

// 查询字符串出现的次数
int query(char *str)
{
    int p = 0;
    for (int i = 0; str[i]; i ++ )
    {
        int u = str[i] - 'a';
        if (!son[p][u]) return 0;
        p = son[p][u];
    }
    return cnt[p];
}
```

## 并查集

练习题号：AcWing 836、AcWing 837。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

把集合表示成父指针森林，路径压缩加速查询。

### 代码与步骤解读

## 堆

来源：`第二章.txt` 第 245 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 838、AcWing 839。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

完全二叉树中维护父节点不大于孩子。

### 代码与步骤解读

down选更小的孩子交换，up与父比较；ph和hp互为插入编号与堆位置映射。

### 为什么正确

每次局部交换把违例沿一条路径推进，最终恢复堆序。

### 复杂度

插删修改O(log n)，自底向上建堆O(n)，空间O(n)。

### 使用条件与易错点

heap_swap需同步h、ph、hp；删除后视情况up和down；size与STL函数重名时注意作用域。

### 小例子

小根堆[1,3,2]弹1后堆顶2。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
// h[N]存储堆中的值, h[1]是堆顶，x的左儿子是2x, 右儿子是2x + 1
// ph[k]存储第k个插入的点在堆中的位置
// hp[k]存储堆中下标是k的点是第几个插入的
int h[N], ph[N], hp[N], size;

// 交换两个点，及其映射关系
void heap_swap(int a, int b)
{
    swap(ph[hp[a]],ph[hp[b]]);
    swap(hp[a], hp[b]);
    swap(h[a], h[b]);
}

void down(int u)
{
    int t = u;
    if (u * 2 <= size && h[u * 2] < h[t]) t = u * 2;
    if (u * 2 + 1 <= size && h[u * 2 + 1] < h[t]) t = u * 2 + 1;
    if (u != t)
    {
        heap_swap(u, t);
        down(t);
    }
}

void up(int u)
{
    while (u / 2 && h[u] < h[u / 2])
    {
        heap_swap(u, u / 2);
        u >>= 1;
    }
}

// O(n)建堆
for (int i = n / 2; i; i -- ) down(i);
```

把整数映射到有限桶，用链或探测处理冲突。

### 代码与步骤解读

拉链法h初始化-1；开放寻址找到空位或相同值；负数用(x%N+N)%N。

### 为什么正确

同哈希值不代表同元素，最终必须比较真实值。

### 复杂度

平均O(1)，最坏O(n)，空间O(容量)。

### 使用条件与易错点

null必须定义成不会出现的整数哨兵或单独used数组；表满会无限探测；开放寻址删元素需墓碑。

### 小例子

x=-1时桶下标为N-1。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
(1) 拉链法
    int h[N], e[N], ne[N], idx;

    // 向哈希表中插入一个数
    void insert(int x)
    {
        int k = (x % N + N) % N;
        e[idx] = x;
        ne[idx] = h[k];
        h[k] = idx ++ ;
    }

    // 在哈希表中查询某个数是否存在
    bool find(int x)
    {
        int k = (x % N + N) % N;
        for (int i = h[k]; i != -1; i = ne[i])
            if (e[i] == x)
                return true;

        return false;
    }

(2) 开放寻址法
    int h[N];

    // 如果x在哈希表中，返回x的下标；如果x不在哈希表中，返回x应该插入的位置
    int find(int x)
    {
        int t = (x % N + N) % N;
        while (h[t] != null && h[t] != x)
        {
            t ++ ;
            if (t == N) t = 0;
        }
        return t;
    }
```

## 字符串哈希

来源：`第二章.txt` 第 320 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 841。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

多项式前缀哈希快速比较子串。

### 代码与步骤解读

h[i]=h[i-1]*P+字符；p[i]=P^i；h[r]-h[l-1]*p[长度]消除前缀。

### 为什么正确

乘相同幂对齐前缀后相减，只剩子串。

### 复杂度

预处理O(n)，查询O(1)，空间O(n)。

### 使用条件与易错点

unsigned long long溢出有定义，相当于模2^64；有碰撞，不能作为严格相等证明；可双哈希或复核。

### 小例子

abc的[2,3]与独立bc具有同一多项式值。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
核心思想：将字符串看成P进制数，P的经验值是131或13331，取这两个值的冲突概率低
小技巧：取模的数用2^64，这样直接用unsigned long long存储，溢出的结果就是取模的结果

typedef unsigned long long ULL;
ULL h[N], p[N]; // h[k]存储字符串前k个字母的哈希值, p[k]存储 P^k mod 2^64

// 初始化
p[0] = 1;
for (int i = 1; i <= n; i ++ )
{
    h[i] = h[i - 1] * P + str[i];
    p[i] = p[i - 1] * P;
}

// 计算子串 str[l ~ r] 的哈希值
ULL get(int l, int r)
{
    return h[r] - h[l - 1] * p[r - l + 1];
}
```

| 2. 数组模拟 | `lc/rc`、双向邻接表、父节点数组 | 在给定规模内稳定建树，不依赖动态分配 |
| 3. 遍历与统计 | DFS、BFS、前中后序、父节点、深度、子树大小 | 计算层数、子树信息、树的重心与树形 DP 基础 |

**树首先是图的一种。** 本节默认图没有自环和重边。无向图连通且无环时称为树；有 `n` 个节点的树恰有 `n-1` 条边，任意两点间有且只有一条简单路径。只知道“边数为 `n-1`”还不够，仍须保证连通。多个互不相连的树组成森林。

选定根后，无向树就有了父子关系。根没有父节点；一个节点的父节点是它到根路径上的相邻节点，其余相邻点是孩子。子树包含节点自身及它的全部后代。无孩子的是叶子。本文令根深度为0，深度按边数计；树高为最大深度，只有根的树高度为0。别把“无向图度数为1”和“有根树没有孩子”混成同一个定义：单节点树的根是叶子，但度数是0。

**二叉树、二叉搜索树、完全二叉树是不同约束。** 二叉树每个节点至多有左、右两个孩子，左右有区别；二叉搜索树还要求左子树键值小于当前、右子树键值大于当前（重复值需另定规则）；完全二叉树要求除最后一层外都填满、最后一层从左连续排列。堆利用完全二叉树形状，但通常不满足二叉搜索树的有序规则。

### 二、先选存储方式：三种数组表示

| 表示 | 关键数组 | 适用情形 | 限制与代价 |
|---|---|---|---|
| 顺序位置表示 | `a[u]`，孩子为 `2*u`、`2*u+1` | 完全二叉树、二叉堆 | 任意稀疏二叉树可能浪费指数级下标空间 |
| 节点编号表示 | `value[u]`、`lc[u]`、`rc[u]` | 任意二叉树、数组 BST、静态节点池 | 编号只是身份，不能再用 `2*u` 推导孩子 |
| 邻接表表示 | `head[u]`、`to[e]`、`nxt[e]` | 一般树、无向树、树上算法 | 一条无向边存两次；需要选根后求父子关系 |

例如完全二叉树可直接表示为：

```text
          1
        /   \
       2     3
      / \   /
     4   5 6

父节点：u/2；左孩子：2*u；右孩子：2*u+1。
判断孩子是否存在：孩子下标<=n。
```

但一条每次只走右孩子的链，在顺序表示中编号会是 `1,3,7,15,...`，深度 `h` 的下标达到 `2^(h+1)-1`。节点数明明只有 `h+1`，因此一般二叉树应改用显式孩子数组：

```text
节点编号     1  2  3
value       8  4  9
lc          2  0  0
rc          3  0  0

含义：1的左孩子是2，右孩子是3；2、3都是叶子。
```

这里 `lc[1]=2` 是存进去的关系，`lc[2]=0` 表示空，和键值 `value[2]=4` 没有关系。节点值可能重复，但节点编号应唯一。使用节点池时可令 `idx=0`，新节点编号为 `++idx`；预先分配 `N+1` 个位置，0号保留为空。所谓数组模拟，本质是“用下标代替指针”，并没有改变树的结构。

如果题目只要求从节点向上找祖先，还可以只存 `parent[u]`；但仅有父节点数组，不能在 O(孩子数) 内找到所有孩子。要向下遍历，应额外建立孩子表或邻接表。

<a id="02-tree-binary"></a>

### 三、数组二叉树：建树与四种遍历

四种遍历的区别是“何时处理当前节点”：前序为 **根—左—右**，中序为 **左—根—右**，后序为 **左—右—根**，层序用队列按深度从浅到深访问。中序只有在二叉搜索树上才按键值有序；普通二叉树不能据此排序。

对于根值8、左孩子4、右孩子9的树，前序是 `8 4 9`，中序是 `4 8 9`，后序是 `4 9 8`，层序是 `8 4 9`。

递归前序最直接的思路是“处理自己，再调用左子树、右子树”。其递归空间是 O(h)，退化长链时为 O(n)，可能超过运行环境的栈容量。下面用显式数组栈模拟递归，深链不会占用深度为 n 的函数调用栈。

**完整程序 A：数组二叉树遍历。** 输入 `n`，接着第 `i` 行给出节点 `i` 的 `value lc rc`，空孩子写0。输入保证是一棵合法二叉树；程序通过“未被任何节点作为孩子”的编号寻找根，不假定根编号一定为1。输出四行，依次为前序、中序、后序、层序。`n=0` 时输出四个空行。

```cpp
// TREE_EXAMPLE_A：GNU C++17，0<=n<=200000。
#include <iostream>
using namespace std;
constexpr int N = 200000 + 5;
long long value[N];
int lc[N], rc[N], indeg[N], stk[N], que[N];
bool done[N];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    if (!(cin >> n) || n < 0 || n > 200000) return 1;
    for (int i = 1; i <= n; ++i) {
        cin >> value[i] >> lc[i] >> rc[i];
        if (lc[i]) ++indeg[lc[i]];
        if (rc[i]) ++indeg[rc[i]];
    }
    int root = 0;
    for (int i = 1; i <= n; ++i)
        if (!indeg[i]) root = i;

    // 前序：LIFO栈要先压右孩子，才会先访问左孩子。
    int top = 0;
    if (root) stk[++top] = root;
    while (top) {
        int u = stk[top--];
        cout << value[u] << ' ';
        if (rc[u]) stk[++top] = rc[u];
        if (lc[u]) stk[++top] = lc[u];
    }
    cout << '\n';

    // 中序：先一路压左链，回到栈顶处理自己，再进入右子树。
    top = 0;
    int u = root;
    while (u || top) {
        while (u) {
            stk[++top] = u;
            u = lc[u];
        }
        u = stk[top--];
        cout << value[u] << ' ';
        u = rc[u];
    }
    cout << '\n';

    // 后序：done标记该栈帧的孩子是否已安排。
    top = 0;
    if (root) { stk[++top] = root; done[top] = false; }
    while (top) {
        int x = stk[top];
        if (done[top]) {
            --top;
            cout << value[x] << ' ';
        } else {
            done[top] = true;
            if (rc[x]) { stk[++top] = rc[x]; done[top] = false; }
            if (lc[x]) { stk[++top] = lc[x]; done[top] = false; }
        }
    }
    cout << '\n';

    // 层序：先进先出队列。
    int hh = 0, tt = 0;
    if (root) que[tt++] = root;
    while (hh < tt) {
        int x = que[hh++];
        cout << value[x] << ' ';
        if (lc[x]) que[tt++] = lc[x];
        if (rc[x]) que[tt++] = rc[x];
    }
    cout << '\n';
}
```

**为什么正确：** 显式栈保存尚未完成的访问任务。前序通过“右先入栈、左先出栈”实现根左右；中序只在左链处理结束后输出当前节点；后序的当前节点帧只有在它压入的两个孩子任务全部出栈后才输出。层序队列把当前层发现的孩子放在已有任务之后，确保逐层处理。

四种遍历各访问每个节点一次，分别为 O(n) 时间。节点数组占 O(n) 空间（实现按最大容量静态预留），显式栈最坏 O(n)，队列最坏 O(n)。一般有根树没有天然“左、右”，通常谈 DFS 进入顺序、退出顺序和 BFS，不直接套用二叉树中序。

### 四、一般树：邻接表、父节点与子树信息

一般树一个节点可以有很多孩子，不能只用 `lc/rc` 两个槽存全部孩子。本节使用与第三章兼容的数组邻接表：`head[u]` 是顶点 `u` 的第一条边；`to[e]` 存边终点；`nxt[e]` 存下一条边的编号。添加边时把新边放在链首，所以访问邻居的顺序一般与输入顺序相反。

无向边 `(a,b)` 要调用两次 `add`，容量开到至少 `2*(n-1)`；本节 `head` 初始化为 `-1`，边编号从0开始。别把邻接表的“边编号0”和节点池的“空节点0”混用。

选根 `r` 后，可以先用数组队列求 `parent` 和 `depth`。树中从根到每点只有一条路径，因此一条父边之外的相邻边都会指向孩子；如果输入可能有环、重边或不连通，就必须先校验，或改用访问标记遍历，不能直接套“跳过父节点”写法。

子树大小的状态定义为：

```text
sz[u] = 1 + 所有孩子v的sz[v]之和。
```

`1` 表示节点自身。计算 `sz[u]` 前必须先算完全部孩子，所以这是后序依赖。**不一定非得递归**：只要有一个父节点排在孩子之前的遍历顺序，将这个顺序倒过来处理，就能把每个孩子的结果累加到父节点。本节完整程序 B 使用 BFS 顺序的逆序完成累加；它能用于子树统计，但 BFS 编号本身不是保证子树连续的 DFS 序。

进一步，树的重心可用子树大小判断：删除 `u` 后，孩子方向的连通块大小分别为 `sz[v]`，父方向为 `n-sz[u]`。这些值的最大值不超过 `n/2` 时，`u` 是重心。全树扫描 O(n)，重心可能有两个；它与“到所有点距离的最大值最小”的树中心不是同一概念。

**DFS 序的用途：** 在第一次进入节点时令 `tin[u]=++timer`，完成全部孩子后令 `tout[u]=timer`。由于 DFS 会连续处理完一整棵子树再回到外部，子树 `u` 恰好对应 `[tin[u],tout[u]]`，且 `sz[u]=tout[u]-tin[u]+1`。将节点权写到 `a[tin[u]]` 后，“子树加法/求和”就转化成区间操作，可衔接树状数组或线段树。这个区间性质依赖 DFS 顺序，不能换成层序编号。

<a id="02-tree-lca"></a>

### 五、倍增 LCA 与树上距离

LCA（最近公共祖先）是选定根后，两个节点的公共祖先中深度最大的节点，允许节点本身作为自己的祖先。定义 `up[k][u]` 为 `u` 的第 `2^k` 个祖先，0表示已经越过根：

```text
up[0][u] = parent[u]
up[k][u] = up[k-1][ up[k-1][u] ]
```

查询时先按深度差的二进制位把较深节点抬到同一深度；若两点已经相同，它就是 LCA。否则从大到小枚举 `k`，在两个 `2^k` 祖先不相同时同时上跳。最终两点停在 LCA 的不同孩子位置，返回它们共同的父节点。

**为什么最后一步成立：** 同深度两点如果跳到的祖先仍不相同，说明这次跳跃没有到达或跨过公共祖先，可以安全上跳；从大到小尝试完后，两点各再走一步就会第一次汇合。每次跳跃只查数组，单次查询 O(log n)，预处理与祖先表空间都是 O(n log n)。根的深度为0、父节点为0，0号整列初始化为0。

无权树的两点距离按边数计：

```text
distance(u,v) = depth[u] + depth[v] - 2*depth[lca(u,v)]。
```

带权树可用根到节点的路径权和 `distRoot` 替换 `depth`；`depth` 仍须单独记录边数用于抬升，不能用权和比较层级。路径权和建议用 `long long`。

**完整程序 B：一般树统计与 LCA。** 输入 `n q root`，接着 `n-1` 条无向边，最后 `q` 组查询 `u v`。输出前 `n` 行依次为节点 `1..n` 的 `parent depth sz`；随后每个查询输出 `LCA 无权距离`。输入保证是节点编号为 `1..n` 的合法连通树。

```cpp
// TREE_EXAMPLE_B：GNU C++17，1<=n<=200000，q>=0。
#include <algorithm>
#include <iostream>
using namespace std;
constexpr int N = 200000 + 5;
constexpr int LOG = 20; // 2^19>200000，k=0..19覆盖所需跳跃。
int head[N], to[2*N], nxt[2*N], edge_count;
int up[LOG][N], depth[N], sz[N], que[N];

void add(int a, int b) {
    to[edge_count] = b;
    nxt[edge_count] = head[a];
    head[a] = edge_count++;
}

void prepare(int n, int root) {
    // 全局数组初始为0；每轮重建时也显式重置有效状态。
    for (int u = 0; u <= n; ++u) {
        depth[u] = 0;
        sz[u] = (u != 0);
        for (int k = 0; k < LOG; ++k) up[k][u] = 0;
    }
    int hh = 0, tt = 0;
    que[tt++] = root;
    while (hh < tt) {
        int u = que[hh++];
        for (int e = head[u]; e != -1; e = nxt[e]) {
            int v = to[e];
            if (v == up[0][u]) continue; // 仅在输入保证是树时足够。
            up[0][v] = u;
            depth[v] = depth[u] + 1;
            for (int k = 1; k < LOG; ++k)
                up[k][v] = up[k-1][up[k-1][v]];
            que[tt++] = v;
        }
    }
    // 逆序确保孩子先于父节点处理，不使用深度递归。
    for (int i = tt - 1; i >= 0; --i) {
        int u = que[i];
        if (up[0][u]) sz[up[0][u]] += sz[u];
    }
}

int lca(int u, int v) {
    if (depth[u] < depth[v]) swap(u, v);
    int delta = depth[u] - depth[v];
    for (int k = 0; k < LOG; ++k)
        if ((delta >> k) & 1) u = up[k][u];
    if (u == v) return u;
    for (int k = LOG - 1; k >= 0; --k) {
        if (up[k][u] != up[k][v]) {
            u = up[k][u];
            v = up[k][v];
        }
    }
    return up[0][u];
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, q, root;
    if (!(cin >> n >> q >> root) || n < 1 || n > 200000 ||
        q < 0 || root < 1 || root > n) return 1;
    fill(head, head + n + 1, -1);
    for (int i = 1; i < n; ++i) {
        int a, b;
        cin >> a >> b;
        add(a, b); add(b, a);
    }
    prepare(n, root);
    for (int u = 1; u <= n; ++u)
        cout << up[0][u] << ' ' << depth[u] << ' ' << sz[u] << '\n';
    while (q--) {
        int u, v;
        cin >> u >> v;
        int p = lca(u, v);
        cout << p << ' ' << depth[u] + depth[v] - 2*depth[p] << '\n';
    }
}
```

手算一棵以1为根、边为 `1-2,1-3,2-4,2-5` 的树：`parent[4]=2`，`depth[4]=2`，`sz[2]=3`；`lca(4,5)=2`、距离2；`lca(4,3)=1`、距离3。只有一个节点时，根的 `parent=0,depth=0,sz=1`，自己到自己的距离为0。

### 六、树状数组：维护动态前缀和

树状数组（Fenwick Tree/BIT）维护的是序列，不是题面输入的一棵父子关系树；它的“树”是下标所隐含的依赖关系。接在这里学习，是为了从数组表示进一步理解“一个节点维护一段信息”。

令 `lowbit(i)=i&-i`，`bit[i]` 维护原数组区间 `[i-lowbit(i)+1,i]` 的和。例如 `i=6=110₂`，`lowbit(6)=2`，所以 `bit[6]` 覆盖 `[5,6]`。

查询前缀和时反复 `i-=lowbit(i)`：每次取出前缀末端的一块，这些块互不重叠且恰好拼出 `[1,x]`。单点加法时反复 `i+=lowbit(i)`：依次更新所有覆盖该位置的维护区间。两种操作都是 O(log n)，空间 O(n)。区间和由 `prefix(r)-prefix(l-1)` 得到。

**完整程序 C：单点加、区间求和。** 输入 `n q`、初始数组，之后每行 `A x delta` 或 `Q l r`。位置从1计，查询为闭区间。初值和所有中间和保证在 `long long` 范围内。

```cpp
// TREE_EXAMPLE_C：GNU C++17，1<=n<=200000。
#include <iostream>
using namespace std;
constexpr int N = 200000 + 5;
int n;
long long bit[N];
int lowbit(int x) { return x & -x; }
void add(int x, long long delta) {
    for (int i = x; i <= n; i += lowbit(i)) bit[i] += delta;
}
long long prefix(int x) {
    long long sum = 0;
    for (int i = x; i > 0; i -= lowbit(i)) sum += bit[i];
    return sum;
}
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int q;
    if (!(cin >> n >> q) || n < 1 || n > 200000 || q < 0) return 1;
    for (int i = 1; i <= n; ++i) {
        long long x; cin >> x; add(i, x);
    }
    while (q--) {
        char op; cin >> op;
        if (op == 'A') {
            int x; long long delta; cin >> x >> delta;
            if (x < 1 || x > n) return 1;
            add(x, delta);
        } else if (op == 'Q') {
            int l, r; cin >> l >> r;
            if (l < 1 || l > r || r > n) return 1;
            cout << prefix(r) - prefix(l - 1) << '\n';
        } else return 1;
    }
}
```

`add(0,delta)` 会因 `lowbit(0)=0` 形成死循环，因此更新位置必须从1开始。查询 `prefix(0)=0` 则是正常边界。初始建树这里调用 n 次 add，复杂度 O(n log n)，不要把它写成 O(n)。原数组某项改成新值时，应增加“新值−旧值”，而不是把新值直接当 delta。

标准“前缀和相减”依赖可做减法的聚合结果，不能把加法机械替换成最小值就得到任意区间最小值查询。离线区间加、最终还原可用第一章差分；在线区间加、单点查询可用差分加 BIT；在线区间加、区间求和可用双 BIT 或下面的懒标记线段树。

### 七、线段树：维护区间信息与懒标记

线段树把序列 `[1,n]` 递归二分。节点 `u` 维护区间 `[l,r]`，左右孩子维护 `[l,mid]` 和 `[mid+1,r]`，因此虽然叶子不一定构成堆式完全二叉树，按这套固定分治结构分配 `4*n` 个数组槽也足够。这里的 `u*2`、`u*2+1` 是**线段树自己的区间节点**，不是原树顶点的孩子，也不是序列元素位置。

本节维护区间和 `sum[u]`，有 `sum[u]=sum[2*u]+sum[2*u+1]`。如果整段加 `d`，和应增加 `d*(r-l+1)`。只要查询暂时不深入孩子，就无需立即逐叶修改：用 `lazy[u]` 记录尚未传给孩子的统一增量。

**完整程序 D：区间加、区间求和。** 输入 `n q`、初始数组，操作为 `A l r delta` 或 `Q l r`，下标从1计、区间闭合。中间的元素和、区间和、懒标记及乘积保证不超 `long long`。

```cpp
// TREE_EXAMPLE_D：GNU C++17，1<=n<=200000。
#include <iostream>
using namespace std;
constexpr int N = 200000 + 5;
long long a[N], sum[4*N], lazy[4*N];

void pull(int u) { sum[u] = sum[u*2] + sum[u*2+1]; }
void apply(int u, int l, int r, long long d) {
    sum[u] += d * (r-l+1);
    lazy[u] += d;
}
void push(int u, int l, int r) {
    if (lazy[u] == 0 || l == r) return;
    int mid = l + (r-l)/2;
    apply(u*2, l, mid, lazy[u]);
    apply(u*2+1, mid+1, r, lazy[u]);
    lazy[u] = 0;
}
void build(int u, int l, int r) {
    lazy[u] = 0;
    if (l == r) { sum[u] = a[l]; return; }
    int mid = l + (r-l)/2;
    build(u*2, l, mid);
    build(u*2+1, mid+1, r);
    pull(u);
}
void modify(int u, int l, int r, int ql, int qr, long long d) {
    if (ql <= l && r <= qr) { apply(u, l, r, d); return; }
    push(u, l, r);
    int mid = l + (r-l)/2;
    if (ql <= mid) modify(u*2, l, mid, ql, qr, d);
    if (qr > mid) modify(u*2+1, mid+1, r, ql, qr, d);
    pull(u);
}
long long query(int u, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return sum[u];
    push(u, l, r);
    int mid = l + (r-l)/2;
    long long answer = 0;
    if (ql <= mid) answer += query(u*2, l, mid, ql, qr);
    if (qr > mid) answer += query(u*2+1, mid+1, r, ql, qr);
    return answer;
}
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, q;
    if (!(cin >> n >> q) || n < 1 || n > 200000 || q < 0) return 1;
    for (int i = 1; i <= n; ++i) cin >> a[i];
    build(1, 1, n);
    while (q--) {
        char op; int l, r; cin >> op >> l >> r;
        if (l < 1 || l > r || r > n) return 1;
        if (op == 'A') {
            long long d; cin >> d;
            modify(1, 1, n, l, r, d);
        } else if (op == 'Q') cout << query(1, 1, n, l, r) << '\n';
        else return 1;
    }
}
```

**维护不变量：** `sum[u]` 已计入所有作用于本区间的操作；`lazy[u]` 仅表示孩子可能还没收到的增量。完全覆盖时直接更新本节点，部分覆盖前先 push，让孩子的信息包含父节点尚未传递的更新，递归修改后再 pull。查询下传后父区间总和并未改变，所以不需要再 pull。忘记在部分查询前下传，会读到旧的孩子信息。

建树 O(n)，单次连续区间修改和查询 O(log n)，空间 O(n)，函数递归深度 O(log n)。线段树按区间对半划分，深度很浅，不会像任意输入树一样退化成长链；不能把“树遍历用迭代防深链”误解成所有递归都不可用。

**先判断题目需求再选择：** 静态区间和用前缀和；单点加、区间和用 BIT 较简洁；需要区间加、区间最值或复杂合并时再考虑线段树。若同时有“赋值”和“加法”标记，二者有先后顺序，不能直接都用 `lazy+=d`。若坐标范围巨大而实际操作稀疏，可进阶到离散化或数组节点池动态开点，无需先改成 `new`。

### 八、有序查找树及后续学习方向

二叉搜索树可同样用 `key[u],lc[u],rc[u]` 数组表示：从根比较键值，小的往左，大的往右，找到空位置就分配节点；重复键可增加 `cnt[u]`。查找与插入时间均为 O(h)。如果依次插入 `1,2,3,...,n`，普通 BST 会退化为链，单次操作 O(n)，连续建树 O(n²)。数组表示节省分配开销，但**不会自动带来平衡性**。

竞赛中只需有序集合与前驱后继时，先使用现有 STL 的 `set/map`；若要求第 k 小、某个键的排名，可进一步学带子树计数的平衡树。维护 `size[u]=size[lc[u]]+size[rc[u]]+cnt[u]` 后，能根据左子树大小决定第 k 小应该向哪边走，但仍需 Treap 等平衡机制才能获得好的时间界。随机 Treap 的 O(log n) 是期望界，不是任意操作下的最坏保证。

| 结构/方法 | 在数组中的常见形式 | 后续学习重点 |
|---|---|---|
| 堆 | `h[u]`，孩子 `2*u/2*u+1` | 只保证堆顶最值；接回本章“堆”，不提供有序遍历 |
| Trie | `son[u][字符]` | 按字符或二进制位分支；接回本章“Trie树”，节点数按总长度估计 |
| Treap/平衡树 | `lc/rc/key/priority/size/cnt` | 分裂合并或旋转、秩统计、随机优先级 |
| 树形 DP | 邻接表加 `dp[u][状态]` | 孩子先算，再合并到父；如选/不选、换根 DP |
| 树链剖分 | `parent/depth/sz/heavy/top/dfn` | 分重链，将一条路径拆成 O(log n) 个连续区间；配线段树通常每次 O(log² n) |
| 动态开点线段树 | 节点池 `lc/rc/sum/lazy` | 只分配实际访问节点；估算 O(操作数×log 值域) 的节点容量 |

**先做子树，再做路径。** DFS 序把一棵子树变成一个连续区间，但一般的 `u→v` 路径在 DFS 序里不连续，不能直接查询 `[tin[u],tin[v]]`。LCA 解决祖先关系；需要动态路径统计时，再引入树链剖分。后续方法在本节只列学习方向，不把概念介绍当成已经给出的完整实现。

### 九、`new` 与指针实现：补充对照

指针节点把数组的 `value[u],lc[u],rc[u]` 放到一个对象里，孩子从整数编号变成 `Node*`：空节点用 `nullptr`，访问成员用 `p->left`，创建节点用 `new Node(value)`。逻辑仍然是同一棵二叉树，前中后序含义也不变。

| 操作 | 数组节点池 | 指针节点 |
|---|---|---|
| 创建节点 | `u=++idx; value[u]=x; lc[u]=rc[u]=0` | `Node* p=new Node(x)` |
| 左孩子 | `lc[u]`，0为空 | `p->left`，nullptr为空 |
| 取值 | `value[u]` | `p->value` |
| 释放 | 整体重置池；单独复用需空闲表 | 对自己拥有的节点 `delete`；避免重复释放与悬空指针 |

数组池容量可预测、编号便于和 `depth/sz/up` 等辅助数组配合，通常更适合本手册的竞赛主线。指针适合理解教材、对象结构与动态关系；并不因此改变时间复杂度，逐节点动态分配还可能增加常数开销。数组池同样可以按需分配，也可以用 `struct Node pool[N]` 把字段聚合起来，不必把“数组”和“结构体”对立起来。

**完整程序 E：固定小树的指针对照。** 不读输入，构建与前面相同的 `8(4,9)` 二叉树，输出前序 `8 4 9` 后释放全部节点。这里只补充 `new/delete` 的机制；大输入的竞赛树遍历仍优先使用上面的数组程序。

```cpp
// TREE_EXAMPLE_E：GNU C++17，无输入。
#include <iostream>
#include <vector>
using namespace std;
struct Node {
    long long value;
    Node* left;
    Node* right;
    explicit Node(long long x) : value(x), left(nullptr), right(nullptr) {}
};

void preorder(Node* root) {
    vector<Node*> stk;
    if (root) stk.push_back(root);
    while (!stk.empty()) {
        Node* p = stk.back(); stk.pop_back();
        cout << p->value << ' ';
        if (p->right) stk.push_back(p->right);
        if (p->left) stk.push_back(p->left);
    }
    cout << '\n';
}

// 每个节点仅有一个拥有者，无共享子节点、无环；Node无递归析构函数。
void destroy(Node*& root) {
    vector<Node*> stk;
    if (root) stk.push_back(root);
    while (!stk.empty()) {
        Node* p = stk.back(); stk.pop_back();
        if (p->left) stk.push_back(p->left);
        if (p->right) stk.push_back(p->right);
        delete p; // 已先保存孩子指针，此后不再访问p。
    }
    root = nullptr;
}

int main() {
    Node* root = new Node(8);
    root->left = new Node(4);
    root->right = new Node(9);
    preorder(root);
    destroy(root);
}
```

不要写 `Node* p; p->value=8;`：未初始化指针没有指向有效对象。`delete p` 后也不能再读取 `p->left`；两个节点共享同一个孩子时，上面的整树释放会重复删除，所以本示例明确要求独占的真树结构。实际工程中的独占所有权常用 `unique_ptr` 管理，理解本节手动分配后再学习即可；本节不引入另一套主实现。

### 十、练习安排与易错点检查

建议按以下顺序练，每一步都先手算，再运行对应程序。

1. 画出 `8(4,9)`、只有左孩子的链、完全二叉树，分别写出 `lc/rc` 表与四种遍历结果；用非1号节点作根，确认没有把编号当层级。
2. 用程序 B 检查单节点、长链、星形树；核对根子树大小为 n、叶子子树大小为1、所有非根节点深度比父节点多1。
3. 练习已有的 AcWing 846（树的重心）与847（图中点的层次），区分子树信息与BFS距离；不要把通用遍历当成已经完成重心计算。
4. 测试 LCA 的同一点、父子、祖孙、不同子树四种情况；手算示例中的 `lca(4,5)=2` 与 `lca(4,3)=1`。
5. 对 `[2,3,5]` 用 BIT 查询 `[2,3]` 得到8，再在位置2加4，查询得到12；用朴素数组核对多次正负更新。
6. 用线段树先对整段加值，再查询单点，确保发生懒标记下传；对局部区间重复加负值，核对合并结果。
7. 把 DFS 序与 BIT 组合，完成“单点加、子树求和”；熟练后再学树形DP、路径查询与树链剖分。
8. 最后用指针版重建小树，解释每次 `new` 的对象由谁释放，确认理解即可，不必把前面的数组实现全部重写成指针。

检查边界：节点数组多开0号和边界余量；无向边容量按两倍；清空 `head`、边计数与辅助数组；区分空节点0和有效边编号0；累计值和乘法中间量使用 `long long`；BIT 更新从1开始；输入树可能为20万节点长链时避免线性深度递归。线段树的递归深度为 O(log n)，与输入树的高度限制不同。
