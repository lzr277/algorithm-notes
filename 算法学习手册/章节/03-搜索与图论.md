## 树与图的存储

来源：`第三章.txt` 第 1 行起。以下原文未改写，修正建议单独列出。

### 知识点与用途

用邻接矩阵或邻接表表示连接关系。

### 代码与步骤解读

矩阵g[a][b]直接查边；h存首边，e存终点，ne存下一边，add头插。

### 为什么正确

沿ne链能访问一个顶点的全部出边。

### 复杂度

矩阵空间O(n²)，邻接表空间O(n+m)，遍历全图O(n+m)。

### 使用条件与易错点

无向边需add两次，容量至少2m；h初始化-1；带权图另存w；重边矩阵取最小权。

### 小例子

无向1—2存1→2和2→1。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
树是一种特殊的图，与图的存储方式相同。
对于无向图中的边ab，存储两条有向边a->b, b->a。
因此我们可以只考虑有向图的存储。

(1) 邻接矩阵：g[a][b] 存储边a->b

(2) 邻接表：

// 对于每个点k，开一个单链表，存储k所有可以走到的点。h[k]存储这个单链表的头结点
int h[N], e[N], ne[N], idx;

// 添加一条边a->b
void add(int a, int b)
{
    e[idx] = b, ne[idx] = h[a], h[a] = idx ++ ;
}

// 初始化
idx = 0;
memset(h, -1, sizeof h);
```

## 深度优先遍历

来源：`第三章.txt` 第 24 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 846。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

递归访问当前节点所有未访问邻居。

### 代码与步骤解读

进入dfs(u)先标记st[u]，依次递归邻居；求重心需返回子树大小。

### 为什么正确

访问标记阻止在环上重复递归。

### 复杂度

O(n+m)时间，最坏O(n)递归空间。

### 使用条件与易错点

原int dfs没有return，应改void；若实现树的重心，则应累计子树大小并返回；深链可改显式栈。

### 小例子

树1—2—3的重心是2。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
int dfs(int u)
{
    st[u] = true; // st[u] 表示点u已经被遍历过

    for (int i = h[u]; i != -1; i = ne[i])
    {
        int j = e[i];
        if (!st[j]) dfs(j);
    }
}
```

## 宽度优先遍历

来源：`第三章.txt` 第 36 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 847。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

用先进先出队列按离起点的边数分层。

### 代码与步骤解读

起点入队时标记；每个新邻居立即标记并入队；求距离令dist[j]=dist[t]+1。

### 为什么正确

首次发现时经过的层数最小，因此等权边图首次距离最短。

### 复杂度

O(n+m)时间，O(n)辅助空间。

### 使用条件与易错点

原if(!s[j])应为if(!st[j])；不能直接用于不同权值最短路；入队时标记。

### 小例子

1→2→3与1→3并存，dist[3]=1。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
queue<int> q;
st[1] = true; // 表示1号点已经被遍历过
q.push(1);

while (q.size())
{
    int t = q.front();
    q.pop();

    for (int i = h[t]; i != -1; i = ne[i])
    {
        int j = e[i];
        if (!s[j])
        {
            st[j] = true; // 表示点j已经被遍历过
            q.push(j);
        }
    }
}
```

## 拓扑排序

来源：`第三章.txt` 第 57 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 848。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

反复删除入度为0的顶点构造拓扑序。

### 代码与步骤解读

初始零入度点入队，出队后逐条--d[j]，变成0就入队。

### 为什么正确

DAG必有零入度点；若剩余图没有零入度点就包含环。

### 复杂度

O(n+m)时间，O(n)辅助空间。

### 使用条件与易错点

仅适用于有向图；会破坏入度数组，重复调用前重建；队列顺序不保证字典序最小。

### 小例子

1→3、2→3可输出1,2,3。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
时间复杂度 O(n+m)O(n+m), nn 表示点数，mm 表示边数
bool topsort()
{
    int hh = 0, tt = -1;

    // d[i] 存储点i的入度
    for (int i = 1; i <= n; i ++ )
        if (!d[i])
            q[ ++ tt] = i;

    while (hh <= tt)
    {
        int t = q[hh ++ ];

        for (int i = h[t]; i != -1; i = ne[i])
        {
            int j = e[i];
            if (-- d[j] == 0)
                q[ ++ tt] = j;
        }
    }

    // 如果所有点都入队了，说明存在拓扑序列；否则不存在拓扑序列。
    return tt == n - 1;
}
```

## 朴素dijkstra算法

来源：`第三章.txt` 第 83 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 849。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

每次确定当前未访问的最近顶点。

### 代码与步骤解读

选dist最小的t，再以dist[t]+g[t][j]松弛所有点。

### 为什么正确

非负边保证未来绕路无法让已确定距离变小。

### 复杂度

O(n²+m)时间，矩阵O(n²)空间。

### 使用条件与易错点

边权必须非负；重边取min；多次调用清空st；有限INF不能无保护相加，推荐long long和可达性判断。

### 小例子

1→2权2、2→3权3、1→3权8，答案5。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
时间复杂是 O(n2+m)O(n2+m), nn 表示点数，mm 表示边数
int g[N][N];  // 存储每条边
int dist[N];  // 存储1号点到每个点的最短距离
bool st[N];   // 存储每个点的最短路是否已经确定

// 求1号点到n号点的最短路，如果不存在则返回-1
int dijkstra()
{
    memset(dist, 0x3f, sizeof dist);
    dist[1] = 0;

    for (int i = 0; i < n - 1; i ++ )
    {
        int t = -1;     // 在还未确定最短路的点中，寻找距离最小的点
        for (int j = 1; j <= n; j ++ )
            if (!st[j] && (t == -1 || dist[t] > dist[j]))
                t = j;

        // 用t更新其他点的距离
        for (int j = 1; j <= n; j ++ )
            dist[j] = min(dist[j], dist[t] + g[t][j]);

        st[t] = true;
    }

    if (dist[n] == 0x3f3f3f3f) return -1;
    return dist[n];
}
```

## 堆优化版dijkstra

来源：`第三章.txt` 第 112 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 850。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

用小根堆寻找待确定的最短距离。

### 代码与步骤解读

堆项为{距离,顶点}；弹出已确定点则跳过；成功松弛后压入新项。

### 为什么正确

与朴素Dijkstra相同，堆只优化最小候选选择。

### 复杂度

懒删除实现O((n+m)log(n+m))时间，O(n+m)空间。

### 使用条件与易错点

仍要求非负边；dist与堆距离类型一致，推荐long long；并行边多时不能无条件将log m写成log n。

### 小例子

旧堆项{8,3}会在{5,3}确定后被跳过。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
时间复杂度 O(mlogn)O(mlogn), nn 表示点数，mm 表示边数
typedef pair<int, int> PII;

int n;      // 点的数量
int h[N], w[N], e[N], ne[N], idx;       // 邻接表存储所有边
int dist[N];        // 存储所有点到1号点的距离
bool st[N];     // 存储每个点的最短距离是否已确定

// 求1号点到n号点的最短距离，如果不存在，则返回-1
int dijkstra()
{
    memset(dist, 0x3f, sizeof dist);
    dist[1] = 0;
    priority_queue<PII, vector<PII>, greater<PII>> heap;
    heap.push({0, 1});      // first存储距离，second存储节点编号

    while (heap.size())
    {
        auto t = heap.top();
        heap.pop();

        int ver = t.second, distance = t.first;

        if (st[ver]) continue;
        st[ver] = true;

        for (int i = h[ver]; i != -1; i = ne[i])
        {
            int j = e[i];
            if (dist[j] > distance + w[i])
            {
                dist[j] = distance + w[i];
                heap.push({dist[j], j});
            }
        }
    }

    if (dist[n] == 0x3f3f3f3f) return -1;
    return dist[n];
}
```

## Bellman-Ford算法

来源：`第三章.txt` 第 153 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 853。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

按轮枚举所有边允许负权松弛。

### 代码与步骤解读

求最多k条边时每轮复制backup，并用backup[a]+w更新dist[b]。

### 为什么正确

第i轮只由最多i-1条边的结果扩展，得到最多i条边答案。

### 复杂度

边数限制版O(km)时间，O(n+m)空间。

### 使用条件与易错点

原文件没有backup，不能直接解决853；guard可达性防INF减负数；普通最短路需处理可达负环。

### 小例子

1→2→3两条边，k=1不能通过2到3。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
时间复杂度 O(nm)O(nm), nn 表示点数，mm 表示边数
注意在模板题中需要对下面的模板稍作修改，加上备份数组，详情见模板题。

int n, m;       // n表示点数，m表示边数
int dist[N];        // dist[x]存储1到x的最短路距离

struct Edge     // 边，a表示出点，b表示入点，w表示边的权重
{
    int a, b, w;
}edges[M];

// 求1到n的最短路距离，如果无法从1走到n，则返回-1。
int bellman_ford()
{
    memset(dist, 0x3f, sizeof dist);
    dist[1] = 0;

    // 如果第n次迭代仍然会松弛三角不等式，就说明存在一条长度是n+1的最短路径，由抽屉原理，路径中至少存在两个相同的点，说明图中存在负权回路。
    for (int i = 0; i < n; i ++ )
    {
        for (int j = 0; j < m; j ++ )
        {
            int a = edges[j].a, b = edges[j].b, w = edges[j].w;
            if (dist[b] > dist[a] + w)
                dist[b] = dist[a] + w;
        }
    }

    if (dist[n] > 0x3f3f3f3f / 2) return -1;
    return dist[n];
}
```

## spfa 算法（队列优化的Bellman-Ford算法）

来源：`第三章.txt` 第 185 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 851。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

只让距离改变的点进入队列尝试松弛。

### 代码与步骤解读

st含义是在队列中，出队时置false，成功松弛才按需重新入队。

### 为什么正确

队列为空说明所有可达边均无法继续改善距离。

### 复杂度

最坏O(nm)时间，O(n+m)空间。

### 使用条件与易错点

不能保证平均O(m)；可达负环会导致不终止，应加判环或改算法；st与dist需初始化。

### 小例子

权-2的边允许使用，但不能有可达负环。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
时间复杂度 平均情况下 O(m)O(m)，最坏情况下 O(nm)O(nm), nn 表示点数，mm 表示边数
int n;      // 总点数
int h[N], w[N], e[N], ne[N], idx;       // 邻接表存储所有边
int dist[N];        // 存储每个点到1号点的最短距离
bool st[N];     // 存储每个点是否在队列中

// 求1号点到n号点的最短路距离，如果从1号点无法走到n号点则返回-1
int spfa()
{
    memset(dist, 0x3f, sizeof dist);
    dist[1] = 0;

    queue<int> q;
    q.push(1);
    st[1] = true;

    while (q.size())
    {
        auto t = q.front();
        q.pop();

        st[t] = false;

        for (int i = h[t]; i != -1; i = ne[i])
        {
            int j = e[i];
            if (dist[j] > dist[t] + w[i])
            {
                dist[j] = dist[t] + w[i];
                if (!st[j])     // 如果队列中已存在j，则不需要将j重复插入
                {
                    q.push(j);
                    st[j] = true;
                }
            }
        }
    }

    if (dist[n] == 0x3f3f3f3f) return -1;
    return dist[n];
}
```

## spfa判断图中是否存在负环

来源：`第三章.txt` 第 227 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 852。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

给所有顶点零距离起点检测任意连通分量的负环。

### 代码与步骤解读

所有点先入队，dist全置0，cnt[j]=cnt[t]+1；cnt>=n判负环。

### 为什么正确

严格改善的路径含至少n条边时重复顶点并包含负环。

### 复杂度

最坏O(nm)时间，O(n+m)空间。

### 使用条件与易错点

不能仅从1入队，否则漏不连通负环；cnt数的是边数；原不初始化依赖全局零值，复用时显式清零。

### 小例子

孤立点1之外，2→3权-1与3→2权0也要发现。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
时间复杂度是 O(nm)O(nm), nn 表示点数，mm 表示边数
int n;      // 总点数
int h[N], w[N], e[N], ne[N], idx;       // 邻接表存储所有边
int dist[N], cnt[N];        // dist[x]存储1号点到x的最短距离，cnt[x]存储1到x的最短路中经过的点数
bool st[N];     // 存储每个点是否在队列中

// 如果存在负环，则返回true，否则返回false。
bool spfa()
{
    // 不需要初始化dist数组
    // 原理：如果某条最短路径上有n个点（除了自己），那么加上自己之后一共有n+1个点，由抽屉原理一定有两个点相同，所以存在环。

    queue<int> q;
    for (int i = 1; i <= n; i ++ )
    {
        q.push(i);
        st[i] = true;
    }

    while (q.size())
    {
        auto t = q.front();
        q.pop();

        st[t] = false;

        for (int i = h[t]; i != -1; i = ne[i])
        {
            int j = e[i];
            if (dist[j] > dist[t] + w[i])
            {
                dist[j] = dist[t] + w[i];
                cnt[j] = cnt[t] + 1;
                if (cnt[j] >= n) return true;       // 如果从1号点到x的最短路中包含至少n个点（不包括自己），则说明存在环
                if (!st[j])
                {
                    q.push(j);
                    st[j] = true;
                }
            }
        }
    }

    return false;
}
```

## floyd算法

来源：`第三章.txt` 第 273 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 854。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

逐步允许编号1..k的点作为中转点。

### 代码与步骤解读

k必须最外层；d[i][j]与d[i][k]+d[k][j]比较。

### 为什么正确

中转集合加入k后，最短路要么不经k，要么拆成两段。

### 复杂度

O(n³)时间，O(n²)空间。

### 使用条件与易错点

负边可用但有负环时普通最短路无定义；INF相加前检查可达；重边取min，d[i][i]=0。

### 小例子

1→2权2、2→3权4，使d[1][3]变6。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
时间复杂度是 O(n3)O(n3), nn 表示点数
初始化：
    for (int i = 1; i <= n; i ++ )
        for (int j = 1; j <= n; j ++ )
            if (i == j) d[i][j] = 0;
            else d[i][j] = INF;

// 算法结束后，d[a][b]表示a到b的最短距离
void floyd()
{
    for (int k = 1; k <= n; k ++ )
        for (int i = 1; i <= n; i ++ )
            for (int j = 1; j <= n; j ++ )
                d[i][j] = min(d[i][j], d[i][k] + d[k][j]);
}
```

## 朴素版prim算法

来源：`第三章.txt` 第 289 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 858。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

维护所有未入树点到当前生成树的最小连接权。

### 代码与步骤解读

dist[j]=min(dist[j],g[t][j])；每次选最小连接点，累加连接边。

### 为什么正确

割性质保证跨当前树与外部的最小边可加入某棵MST。

### 复杂度

O(n²+m)时间，O(n²)空间。

### 使用条件与易错点

适用无向图，允许负边；dist不是从起点的路径长度；不连通返回失败；总权值用long long。

### 小例子

三角形权1、2、4，选1和2得到总权3。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
时间复杂度是 O(n2+m)O(n2+m), nn 表示点数，mm 表示边数
int n;      // n表示点数
int g[N][N];        // 邻接矩阵，存储所有边
int dist[N];        // 存储其他点到当前最小生成树的距离
bool st[N];     // 存储每个点是否已经在生成树中


// 如果图不连通，则返回INF(值是0x3f3f3f3f), 否则返回最小生成树的树边权重之和
int prim()
{
    memset(dist, 0x3f, sizeof dist);

    int res = 0;
    for (int i = 0; i < n; i ++ )
    {
        int t = -1;
        for (int j = 1; j <= n; j ++ )
            if (!st[j] && (t == -1 || dist[t] > dist[j]))
                t = j;

        if (i && dist[t] == INF) return INF;

        if (i) res += dist[t];
        st[t] = true;

        for (int j = 1; j <= n; j ++ ) dist[j] = min(dist[j], g[t][j]);
    }

    return res;
}
```

## Kruskal算法

来源：`第三章.txt` 第 320 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 859。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

按边权排序，用并查集过滤成环边。

### 代码与步骤解读

find两端根，不同根则合并并计边；选到n-1条完成。

### 为什么正确

按割性质，当前最小连接不同连通块的边安全。

### 复杂度

O(m log m+mα(n))（按秩并查集），空间O(n+m)。

### 使用条件与易错点

无向图；重边、自环可自然过滤；不足n-1条说明不连通；原仅路径压缩应谨慎表述DSU界。

### 小例子

三角形先选权1、2，权4两端已连通。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
时间复杂度是 O(mlogm)O(mlogm), nn 表示点数，mm 表示边数
int n, m;       // n是点数，m是边数
int p[N];       // 并查集的父节点数组

struct Edge     // 存储边
{
    int a, b, w;

    bool operator< (const Edge &W)const
    {
        return w < W.w;
    }
}edges[M];

int find(int x)     // 并查集核心操作
{
    if (p[x] != x) p[x] = find(p[x]);
    return p[x];
}

int kruskal()
{
    sort(edges, edges + m);

    for (int i = 1; i <= n; i ++ ) p[i] = i;    // 初始化并查集

    int res = 0, cnt = 0;
    for (int i = 0; i < m; i ++ )
    {
        int a = edges[i].a, b = edges[i].b, w = edges[i].w;

        a = find(a), b = find(b);
        if (a != b)     // 如果两个连通块不连通，则将这两个连通块合并
        {
            p[a] = b;
            res += w;
            cnt ++ ;
        }
    }

    if (cnt < n - 1) return INF;
    return res;
}
```

## 染色法判别二分图

来源：`第三章.txt` 第 364 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 860。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

相邻顶点必须染不同颜色。

### 代码与步骤解读

未染色邻居赋!c；已染邻居与当前同色就失败；从每个未染节点启动。

### 为什么正确

无冲突染色给出二分划分，奇环无法两色染色。

### 复杂度

O(n+m)时间，O(n)辅助空间。

### 使用条件与易错点

所有连通块都要检查；color初值-1；自环立即失败；递归深度可能溢栈。

### 小例子

三角形不能二分，四边形可以。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
时间复杂度是 O(n+m)O(n+m), nn 表示点数，mm 表示边数
int n;      // n表示点数
int h[N], e[M], ne[M], idx;     // 邻接表存储图
int color[N];       // 表示每个点的颜色，-1表示为染色，0表示白色，1表示黑色

// 参数：u表示当前节点，c表示当前点的颜色
bool dfs(int u, int c)
{
    color[u] = c;
    for (int i = h[u]; i != -1; i = ne[i])
    {
        int j = e[i];
        if (color[j] == -1)
        {
            if (!dfs(j, !c)) return false;
        }
        else if (color[j] == c) return false;
    }

    return true;
}

bool check()
{
    memset(color, -1, sizeof color);
    bool flag = true;
    for (int i = 1; i <= n; i ++ )
        if (color[i] == -1)
            if (!dfs(i, 0))
            {
                flag = false;
                break;
            }
    return flag;
}
```

## 匈牙利算法

来源：`第三章.txt` 第 400 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 861。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

寻找交替路径以增加二分图匹配数。

### 代码与步骤解读

遍历左点x的右侧邻居j；j空闲或原左匹配可改配时，match[j]=x。

### 为什么正确

增广路径反转后匹配数加1；无增广路径时匹配最大。

### 复杂度

简单DFS增广O(n1·m)时间，O(n+m)空间。

### 使用条件与易错点

原注释边方向写反，实际存左集合→右集合；每轮清空右侧st；此实现是二分图无权最大匹配，非带权指派算法。

### 小例子

L1接R1,R2，L2只接R1，可让L1改配R2得到2对。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
时间复杂度是 O(nm)O(nm), nn 表示点数，mm 表示边数
int n1, n2;     // n1表示第一个集合中的点数，n2表示第二个集合中的点数
int h[N], e[M], ne[M], idx;     // 邻接表存储所有边，匈牙利算法中只会用到从第二个集合指向第一个集合的边，所以这里只用存一个方向的边
int match[N];       // 存储第二个集合中的每个点当前匹配的第一个集合中的点是哪个
bool st[N];     // 表示第二个集合中的每个点是否已经被遍历过

bool find(int x)
{
    for (int i = h[x]; i != -1; i = ne[i])
    {
        int j = e[i];
        if (!st[j])
        {
            st[j] = true;
            if (match[j] == 0 || find(match[j]))
            {
                match[j] = x;
                return true;
            }
        }
    }

    return false;
}

// 求最大匹配数，依次枚举第一个集合中的每个点能否匹配第二个集合中的点
int res = 0;
for (int i = 1; i <= n1; i ++ )
{
    memset(st, false, sizeof st);
    if (find(i)) res ++ ;
}
```
