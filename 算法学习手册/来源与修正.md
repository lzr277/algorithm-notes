## 修正清单

原文片段不改动，以下建议用于学习与另写程序。完整示例采用新实现并加了明确类型、初始化和输入输出。

| 位置 | 原问题 | 正确理解或修正 |
|---|---|---|
| 归并排序 | `q[i] < q[j]` 相等时先取右边 | 当前代码不稳定；需稳定时改 `<=` |
| 整数二分 | `check` 空实现；没有“答案不存在”逻辑 | 按具体单调性质实现；用 lower_bound 等返回末尾哨兵并检查 |
| 高精度乘、除 | int 进位和 `r*10` 可能溢出 | 使用 long long 中间量；乘零后规范化 |
| 区间合并 | -2e9 同时用作初始化与合法值判断 | 使用 bool 标记或处理第一段，避免哨兵碰撞 |
| 循环队列 | 只有头尾，没区分满与空 | 空留一格、维护 size 或单独标志 |
| KMP | s 被误注释为模式串 | s 是文本，p 是模式串 |
| 维护 size 的并查集 | `p[find(a)]=find(b); size[b]+=size[a]` | 保存 ra、rb；若不同，先聚合根大小，再合并根；同根不重复加 |
| 带权并查集 | `d[I]` 大写；先改父再 `d[find(a)]=distance` | 改 `d[i]`；保存根。若 d[x]=val(x)-val(parent[x])，约束 val(a)-val(b)=w，则 d[ra]=w-d[a]+d[b] 后挂 ra 到 rb |
| STL map | erase 的键被写成 pair | map.erase(key) 或 erase(iterator)；unordered 迭代器支持 ++，不支持 -- |
| DFS | int 函数无返回值 | 通用遍历用 void；树重心版需实际统计并返回子树大小 |
| BFS | `if (!s[j])` | 应使用 `st[j]`；无权距离要另维护 dist |
| 有边数限制最短路 | 原循环没有 backup | 每一轮复制上轮距离，用 backup[a] 松弛，才限制最多 k 条边 |
| Dijkstra/Floyd/Bellman-Ford | int 距离与有限 INF 无保护相加 | 先判断可达，再用 long long；INF 选择留出安全余量 |
| SPFA | “平均 O(m)”容易被当成保证 | 只保留最坏 O(nm) 保证；最短路版需处理可达负环 |
| SPFA 判负环 | 不初始化依赖全局零值；cnt 注释混用点与边 | 重复调用显式清零，全部节点入队；cnt 记录松弛路径边数 |
| 匈牙利算法 | 注释写第二集合指向第一集合 | 实际邻接表是左集合 → 右集合；st 在每轮增广前清零 |
| 快速幂 | int 乘法可能溢出 | 模数不超过 int 正范围时，1LL 乘法中间量足够；更大模数另需宽乘法 |
| 组合数 I | 标题叫递归法，代码实际递推 | Pascal 三角递推 DP |
| 组合数 II/Lucas | 逆元条件没有完整约束 | 素数模；阶乘法预处理范围小于模数；Lucas 小组合数 b>a 返回0 |
| 卡特兰数 | 模意义下直接除 n+1 不一定成立 | 有逆元才能模除，或使用组合数差式 |
| ICG/SG | 所有公平游戏都可无条件 DAG 化的表述过宽 | 本手册的 SG 递推限有限终止/无环正常规则游戏；带循环需另分析 |

完整示例不是对所有片段的可编译封装。其余条目保留“概念/伪代码/模板片段”身份，避免误把初始化未定义的内容当验证通过程序。
