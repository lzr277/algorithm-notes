## 快速排序算法模板

来源：`第一章基础算法.txt` 第 2 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 785。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

选定枢轴，把较小与较大元素分到两边再递归。

### 代码与步骤解读

i从左找不小于x的元素，j从右找不大于x的元素，交换后继续；按j划分递归区间。

### 为什么正确

循环结束时左段不大于枢轴，右段不小于枢轴；递归使两段分别有序。

### 复杂度

平均O(n log n)，最坏O(n²)；递归空间平均O(log n)。

### 使用条件与易错点

原模板不稳定；必须保存枢轴的值；使用[l,j]与[j+1,r]，不要随意混用另一种分区的递归边界。

### 小例子

[3,1,2]以1为枢轴可分成[1]与[3,2]。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
void quick_sort(int q[], int l, int r)
{
    if (l >= r) return;

    int i = l - 1, j = r + 1, x = q[l + r >> 1];
    while (i < j)
    {
        do i ++ ; while (q[i] < x);
        do j -- ; while (q[j] > x);
        if (i < j) swap(q[i], q[j]);
    }
    quick_sort(q, l, j), quick_sort(q, j + 1, r);
}
```

## 归并排序算法模板

来源：`第一章基础算法.txt` 第 17 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 787。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

分治排序后线性合并两个有序段。

### 代码与步骤解读

mid拆分区间，tmp暂存两段较小的当前元素，最后复制回q。

### 为什么正确

两段的当前最小值也是未输出元素的最小值。

### 复杂度

O(n log n)时间，O(n)辅助空间。

### 使用条件与易错点

tmp至少能存整个区间；原代码使用<，相等时右边优先，因此这个版本不稳定；改成<=才稳定。

### 小例子

[1,4]和[2,3]合并为[1,2,3,4]。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
void merge_sort(int q[], int l, int r)
{
    if (l >= r) return;

    int mid = l + r >> 1;
    merge_sort(q, l, mid);
    merge_sort(q, mid + 1, r);

    int k = 0, i = l, j = mid + 1;
    while (i <= mid && j <= r)
        if (q[i] < q[j]) tmp[k ++ ] = q[i ++ ];
        else tmp[k ++ ] = q[j ++ ];

    while (i <= mid) tmp[k ++ ] = q[i ++ ];
    while (j <= r) tmp[k ++ ] = q[j ++ ];

    for (i = l, j = 0; i <= r; i ++, j ++ ) q[i] = tmp[j];
}
```

## 整数二分算法模板

来源：`第一章基础算法.txt` 第 36 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 789。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

在单调真假分界上寻找最左真或最右真。

### 代码与步骤解读

bsearch_1使用下取整mid与r=mid；bsearch_2使用上取整mid与l=mid。

### 为什么正确

每次保留包含目标的半区间且区间严格缩小。

### 复杂度

O(log n)时间，O(1)空间。

### 使用条件与易错点

check必须单调；原模板假定区间内存在答案，否则可能返回无效边界；mid用l+(r-l)/2避免加法溢出。

### 小例子

[1,2,2,4]中2的范围为下标[1,2]（从0计）。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
bool check(int x) {/* ... */} // 检查x是否满足某种性质

// 区间[l, r]被划分成[l, mid]和[mid + 1, r]时使用：
int bsearch_1(int l, int r)
{
    while (l < r)
    {
        int mid = l + r >> 1;
        if (check(mid)) r = mid;    // check()判断mid是否满足性质
        else l = mid + 1;
    }
    return l;
}
// 区间[l, r]被划分成[l, mid - 1]和[mid, r]时使用：
int bsearch_2(int l, int r)
{
    while (l < r)
    {
        int mid = l + r + 1 >> 1;
        if (check(mid)) l = mid;
        else r = mid - 1;
    }
    return l;
}
```

## 浮点数二分算法模板

来源：`第一章基础算法.txt` 第 61 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 790。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

用单调性不断压缩实数答案的区间。

### 代码与步骤解读

比较mid后只保留一侧，r-l<=eps时返回近似值。

### 为什么正确

答案始终被两端夹住，区间长度每轮减半。

### 复杂度

O(log((r-l)/eps))时间，O(1)空间。

### 使用条件与易错点

check需按问题实现；eps不能直接等同最终输出误差；可固定迭代次数防止浮点停滞。

### 小例子

x³=8在[0,10]二分得到约2。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
bool check(double x) {/* ... */} // 检查x是否满足某种性质

double bsearch_3(double l, double r)
{
    const double eps = 1e-6;   // eps 表示精度，取决于题目对精度的要求
    while (r - l > eps)
    {
        double mid = (l + r) / 2;
        if (check(mid)) r = mid;
        else l = mid;
    }
    return l;
}
```

## 高精度加法

来源：`第一章基础算法.txt` 第 75 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 791。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

用低位在前的数字数组模拟竖式加法。

### 代码与步骤解读

t累加两位与进位，t%10存当前位，t/10进入下一位。

### 为什么正确

处理第i位前t是低i位产生的进位。

### 复杂度

O(max(len A,len B))时间与空间。

### 使用条件与易错点

仅处理非负整数；输入需规范化，零用{0}；读取字符串时反向存储。

### 小例子

99+1：低位得到0、0，最后进位1。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
// C = A + B, A >= 0, B >= 0
vector<int> add(vector<int> &A, vector<int> &B)
{
    if (A.size() < B.size()) return add(B, A);

    vector<int> C;
    int t = 0;
    for (int i = 0; i < A.size(); i ++ )
    {
        t += A[i];
        if (i < B.size()) t += B[i];
        C.push_back(t % 10);
        t /= 10;
    }

    if (t) C.push_back(t);
    return C;
}
```

## 高精度减法

来源：`第一章基础算法.txt` 第 94 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 792。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

按位相减并传递借位。

### 代码与步骤解读

t=A[i]-借位-B[i]；负数加10成为该位，下一位继续借1。

### 为什么正确

每个借位恰好相当于从高位借一个十。

### 复杂度

O(len A)时间与空间。

### 使用条件与易错点

必须A>=B；若A<B先交换再单独处理负号；删除高位零但保留一个0。

### 小例子

100-1先借位，结果数组[9,9]。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
// C = A - B, 满足A >= B, A >= 0, B >= 0
vector<int> sub(vector<int> &A, vector<int> &B)
{
    vector<int> C;
    for (int i = 0, t = 0; i < A.size(); i ++ )
    {
        t = A[i] - t;
        if (i < B.size()) t -= B[i];
        C.push_back((t + 10) % 10);
        if (t < 0) t = 1;
        else t = 0;
    }

    while (C.size() > 1 && C.back() == 0) C.pop_back();
    return C;
}
```

## 高精度乘低精度

来源：`第一章基础算法.txt` 第 111 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 793。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

每位乘以一个小整数并处理进位。

### 代码与步骤解读

t累加A[i]*b，输出t%10，剩余t/10继续处理。

### 为什么正确

当前t包含本位乘积与低位进位。

### 复杂度

O(len A+log b)时间与输出空间。

### 使用条件与易错点

原t为int可能溢出，改long long；b=0时需要去掉多余零；这里只是大数乘小数。

### 小例子

123×12=1476。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
// C = A * b, A >= 0, b > 0
vector<int> mul(vector<int> &A, int b)
{
    vector<int> C;
    int t = 0;
    for (int i = 0; i < A.size() || t; i ++ )
    {
        if (i < A.size()) t += A[i] * b;
        C.push_back(t % 10);
        t /= 10;
    }

    return C;
}
```

## 高精度除以低精度

来源：`第一章基础算法.txt` 第 126 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 794。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

从最高位开始做长除法。

### 代码与步骤解读

余数r先乘10加当前位，商位为r/b，再更新r%=b；最后反转商。

### 为什么正确

处理每一位后0<=r<b，已经处理的前缀等于商×b+r。

### 复杂度

O(len A)时间与空间。

### 使用条件与易错点

b>0；r*10可能溢出int，使用long long中间量；商仍以低位在前存储。

### 小例子

123/10商12、余3。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
// A / b = C ... r, A >= 0, b > 0
vector<int> div(vector<int> &A, int b, int &r)
{
    vector<int> C;
    r = 0;
    for (int i = A.size() - 1; i >= 0; i -- )
    {
        r = r * 10 + A[i];
        C.push_back(r / b);
        r %= b;
    }
    reverse(C.begin(), C.end());
    while (C.size() > 1 && C.back() == 0) C.pop_back();
    return C;
}
```

```text
S[i] = a[1] + a[2] + ... a[i]
a[l] + ... + a[r] = S[r] - S[l - 1]
```

## 二维前缀和

来源：`第一章基础算法.txt` 第 145 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 796。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

二维容斥计算矩形和。

### 代码与步骤解读

S[i][j]=a[i][j]+上方+左方-左上；查询减两个外部前缀再补交集。

### 为什么正确

左上交集被减两次，需要加回一次。

### 复杂度

预处理O(nm)，查询O(1)，空间O(nm)。

### 使用条件与易错点

第0行和第0列清零；坐标与闭区间约定一致；使用long long。

### 小例子

矩阵[[1,2],[3,4]]全矩形和10。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
vector<int> alls; // 存储所有待离散化的值
sort(alls.begin(), alls.end()); // 将所有值排序
alls.erase(unique(alls.begin(), alls.end()), alls.end());   // 去掉重复元素

// 二分求出x对应的离散化的值
int find(int x) // 找到第一个大于等于x的位置
{
    int l = 0, r = alls.size() - 1;
    while (l < r)
    {
        int mid = l + r >> 1;
        if (alls[mid] >= x) r = mid;
        else l = mid + 1;
    }
    return r + 1; // 映射到1, 2, ...n
}
```

## 区间合并

来源：`第一章基础算法.txt` 第 184 行起。以下原文未改写，修正建议单独列出。

按左端点排序后逐个扩展当前合并段。

### 代码与步骤解读

无交集时保存当前段；有交集时ed=max(ed,右端点)。

### 为什么正确

排序后后续区间不会从当前左端点之前开始。

### 复杂度

O(n log n)时间，O(n)输出空间。

### 使用条件与易错点

原-2e9哨兵会与合法端点冲突，改用是否已有区间的标记；闭区间端点相接应合并。

### 小例子

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
// 将所有存在交集的区间合并
void merge(vector<PII> &segs)
{
    vector<PII> res;

    sort(segs.begin(), segs.end());

    int st = -2e9, ed = -2e9;
    for (auto seg : segs)
        if (ed < seg.first)
        {
            if (st != -2e9) res.push_back({st, ed});
            st = seg.first, ed = seg.second;
        }
        else ed = max(ed, seg.second);

    if (st != -2e9) res.push_back({st, ed});

    segs = res;
}
```

```text
// h[N]存储堆中的值, h[1]是堆顶，x的左儿子是2x, 右儿子是2x + 1
// ph[k]存储第k个插入的点在堆中的位置
// hp[k]存储堆中下标是k的点是第几个插入的
int h[N], ph[N], hp[N], size;

// 交换两个点，及其映射关系
void heap_swap(int a, int b)
{
    swap(ph[hp[a]],ph[hp[b]]);
    swap(hp[a], hp[b]);
    swap(h[a], h[b]);
}

void down(int u)
{
    int t = u;
    if (u * 2 <= size && h[u * 2] < h[t]) t = u * 2;
    if (u * 2 + 1 <= size && h[u * 2 + 1] < h[t]) t = u * 2 + 1;
    if (u != t)
    {
        heap_swap(u, t);
        down(t);
    }
}

void up(int u)
{
    while (u / 2 && h[u] < h[u / 2])
    {
        heap_swap(u, u / 2);
        u >>= 1;
    }
}

// O(n)建堆
for (int i = n / 2; i; i -- ) down(i);
```

```text
(1) 拉链法
    int h[N], e[N], ne[N], idx;

    // 向哈希表中插入一个数
    void insert(int x)
    {
        int k = (x % N + N) % N;
        e[idx] = x;
        ne[idx] = h[k];
        h[k] = idx ++ ;
    }

    // 在哈希表中查询某个数是否存在
    bool find(int x)
    {
        int k = (x % N + N) % N;

                return true;

        return false;
    }

(2) 开放寻址法
    int h[N];

    // 如果x在哈希表中，返回x的下标；如果x不在哈希表中，返回x应该插入的位置
    int find(int x)
    {
        int t = (x % N + N) % N;
        while (h[t] != null && h[t] != x)
        {
            t ++ ;
            if (t == N) t = 0;
        }
        return t;
    }
```

## 拓扑排序

来源：`第三章.txt` 第 57 行起。以下原文未改写，修正建议单独列出。

反复删除入度为0的顶点构造拓扑序。

初始零入度点入队，出队后逐条--d[j]，变成0就入队。

### 为什么正确

DAG必有零入度点；若剩余图没有零入度点就包含环。

### 复杂度

O(n+m)时间，O(n)辅助空间。

### 使用条件与易错点

仅适用于有向图；会破坏入度数组，重复调用前重建；队列顺序不保证字典序最小。

### 小例子

1→3、2→3可输出1,2,3。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
时间复杂度 O(n+m)O(n+m), nn 表示点数，mm 表示边数
bool topsort()
{
    int hh = 0, tt = -1;

    // d[i] 存储点i的入度
    for (int i = 1; i <= n; i ++ )
        if (!d[i])
            q[ ++ tt] = i;

    while (hh <= tt)
    {
        int t = q[hh ++ ];

        for (int i = h[t]; i != -1; i = ne[i])
        {
            int j = e[i];
            if (-- d[j] == 0)
                q[ ++ tt] = j;
        }
    }

    // 如果所有点都入队了，说明存在拓扑序列；否则不存在拓扑序列。

}
```

## 朴素dijkstra算法

来源：`第三章.txt` 第 83 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 849。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

每次确定当前未访问的最近顶点。

### 代码与步骤解读

选dist最小的t，再以dist[t]+g[t][j]松弛所有点。

### 为什么正确

非负边保证未来绕路无法让已确定距离变小。

### 复杂度

O(n²+m)时间，矩阵O(n²)空间。

### 使用条件与易错点

边权必须非负；重边取min；多次调用清空st；有限INF不能无保护相加，推荐long long和可达性判断。

### 小例子

1→2权2、2→3权3、1→3权8，答案5。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
时间复杂是 O(n2+m)O(n2+m), nn 表示点数，mm 表示边数
int g[N][N];  // 存储每条边
int dist[N];  // 存储1号点到每个点的最短距离
bool st[N];   // 存储每个点的最短路是否已经确定

// 求1号点到n号点的最短路，如果不存在则返回-1
int dijkstra()
{
    memset(dist, 0x3f, sizeof dist);
    dist[1] = 0;

    for (int i = 0; i < n - 1; i ++ )
    {
        int t = -1;     // 在还未确定最短路的点中，寻找距离最小的点
        for (int j = 1; j <= n; j ++ )
            if (!st[j] && (t == -1 || dist[t] > dist[j]))
                t = j;

        // 用t更新其他点的距离
        for (int j = 1; j <= n; j ++ )
            dist[j] = min(dist[j], dist[t] + g[t][j]);

        st[t] = true;
    }

    if (dist[n] == 0x3f3f3f3f) return -1;
    return dist[n];
}
```

## 堆优化版dijkstra

来源：`第三章.txt` 第 112 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 850。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

用小根堆寻找待确定的最短距离。

### 代码与步骤解读

堆项为{距离,顶点}；弹出已确定点则跳过；成功松弛后压入新项。

### 为什么正确

与朴素Dijkstra相同，堆只优化最小候选选择。

### 复杂度

懒删除实现O((n+m)log(n+m))时间，O(n+m)空间。

### 使用条件与易错点

仍要求非负边；dist与堆距离类型一致，推荐long long；并行边多时不能无条件将log m写成log n。

### 小例子

旧堆项{8,3}会在{5,3}确定后被跳过。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
时间复杂度 O(mlogn)O(mlogn), nn 表示点数，mm 表示边数
typedef pair<int, int> PII;

int n;      // 点的数量
int h[N], w[N], e[N], ne[N], idx;       // 邻接表存储所有边
int dist[N];        // 存储所有点到1号点的距离
bool st[N];     // 存储每个点的最短距离是否已确定

// 求1号点到n号点的最短距离，如果不存在，则返回-1
int dijkstra()
{
    memset(dist, 0x3f, sizeof dist);
    dist[1] = 0;
    priority_queue<PII, vector<PII>, greater<PII>> heap;
    heap.push({0, 1});      // first存储距离，second存储节点编号

    while (heap.size())
    {
        auto t = heap.top();
        heap.pop();

        int ver = t.second, distance = t.first;

        if (st[ver]) continue;
        st[ver] = true;

        for (int i = h[ver]; i != -1; i = ne[i])
        {
            int j = e[i];
            if (dist[j] > distance + w[i])
            {
                dist[j] = distance + w[i];
                heap.push({dist[j], j});
            }
        }
    }

    if (dist[n] == 0x3f3f3f3f) return -1;
    return dist[n];
}
```

```text

                    st[j] = true;
                }
```

## spfa判断图中是否存在负环

来源：`第三章.txt` 第 227 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 852。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

给所有顶点零距离起点检测任意连通分量的负环。

### 代码与步骤解读

所有点先入队，dist全置0，cnt[j]=cnt[t]+1；cnt>=n判负环。

### 为什么正确

严格改善的路径含至少n条边时重复顶点并包含负环。

### 复杂度

最坏O(nm)时间，O(n+m)空间。

### 使用条件与易错点

不能仅从1入队，否则漏不连通负环；cnt数的是边数；原不初始化依赖全局零值，复用时显式清零。

### 小例子

孤立点1之外，2→3权-1与3→2权0也要发现。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
时间复杂度是 O(nm)O(nm), nn 表示点数，mm 表示边数
int n;      // 总点数
int h[N], w[N], e[N], ne[N], idx;       // 邻接表存储所有边
int dist[N], cnt[N];        // dist[x]存储1号点到x的最短距离，cnt[x]存储1到x的最短路中经过的点数
bool st[N];     // 存储每个点是否在队列中

// 如果存在负环，则返回true，否则返回false。
bool spfa()
{
    // 不需要初始化dist数组
    // 原理：如果某条最短路径上有n个点（除了自己），那么加上自己之后一共有n+1个点，由抽屉原理一定有两个点相同，所以存在环。

    queue<int> q;
    for (int i = 1; i <= n; i ++ )
    {
        q.push(i);
        st[i] = true;
    }

    while (q.size())
    {
        auto t = q.front();
        q.pop();

        st[t] = false;

        for (int i = h[t]; i != -1; i = ne[i])
        {
            int j = e[i];
            if (dist[j] > dist[t] + w[i])
            {
                dist[j] = dist[t] + w[i];
                cnt[j] = cnt[t] + 1;
                if (cnt[j] >= n) return true;       // 如果从1号点到x的最短路中包含至少n个点（不包括自己），则说明存在环
                if (!st[j])
                {
                    q.push(j);
                    st[j] = true;
                }
            }
        }
    }

    return false;
}
```

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
时间复杂度是 O(n3)O(n3), nn 表示点数
初始化：
    for (int i = 1; i <= n; i ++ )
        for (int j = 1; j <= n; j ++ )
            if (i == j) d[i][j] = 0;
            else d[i][j] = INF;

// 算法结束后，d[a][b]表示a到b的最短距离
void floyd()
{

        for (int i = 1; i <= n; i ++ )
            for (int j = 1; j <= n; j ++ )
                d[i][j] = min(d[i][j], d[i][k] + d[k][j]);
}
```

## 朴素版prim算法

来源：`第三章.txt` 第 289 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 858。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

维护所有未入树点到当前生成树的最小连接权。

### 代码与步骤解读

dist[j]=min(dist[j],g[t][j])；每次选最小连接点，累加连接边。

### 为什么正确

割性质保证跨当前树与外部的最小边可加入某棵MST。

### 复杂度

O(n²+m)时间，O(n²)空间。

### 使用条件与易错点

适用无向图，允许负边；dist不是从起点的路径长度；不连通返回失败；总权值用long long。

### 小例子

三角形权1、2、4，选1和2得到总权3。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
时间复杂度是 O(n2+m)O(n2+m), nn 表示点数，mm 表示边数
int n;      // n表示点数
int g[N][N];        // 邻接矩阵，存储所有边
int dist[N];        // 存储其他点到当前最小生成树的距离
bool st[N];     // 存储每个点是否已经在生成树中


// 如果图不连通，则返回INF(值是0x3f3f3f3f), 否则返回最小生成树的树边权重之和
int prim()
{
    memset(dist, 0x3f, sizeof dist);

    int res = 0;
    for (int i = 0; i < n; i ++ )
    {
        int t = -1;
        for (int j = 1; j <= n; j ++ )
            if (!st[j] && (t == -1 || dist[t] > dist[j]))
                t = j;

        if (i && dist[t] == INF) return INF;

        if (i) res += dist[t];
        st[t] = true;

        for (int j = 1; j <= n; j ++ ) dist[j] = min(dist[j], g[t][j]);
    }

    return res;
}
```

## Kruskal算法

来源：`第三章.txt` 第 320 行起。以下原文未改写，修正建议单独列出。

练习题号：AcWing 859。题号来自本地资料，未声称通过在线评测。

### 知识点与用途

按边权排序，用并查集过滤成环边。

### 代码与步骤解读

find两端根，不同根则合并并计边；选到n-1条完成。

### 为什么正确

按割性质，当前最小连接不同连通块的边安全。

### 复杂度

O(m log m+mα(n))（按秩并查集），空间O(n+m)。

### 使用条件与易错点

无向图；重边、自环可自然过滤；不足n-1条说明不连通；原仅路径压缩应谨慎表述DSU界。

### 小例子

三角形先选权1、2，权4两端已连通。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
时间复杂度是 O(mlogm)O(mlogm), nn 表示点数，mm 表示边数
int n, m;       // n是点数，m是边数
int p[N];       // 并查集的父节点数组

struct Edge     // 存储边
{
    int a, b, w;

    bool operator< (const Edge &W)const
    {
        return w < W.w;
    }
}edges[M];

int find(int x)     // 并查集核心操作
{
    if (p[x] != x) p[x] = find(p[x]);
    return p[x];
}

int kruskal()
{
    sort(edges, edges + m);

    for (int i = 1; i <= n; i ++ ) p[i] = i;    // 初始化并查集

    int res = 0, cnt = 0;
    for (int i = 0; i < m; i ++ )
    {
        int a = edges[i].a, b = edges[i].b, w = edges[i].w;

        a = find(a), b = find(b);
        if (a != b)     // 如果两个连通块不连通，则将这两个连通块合并
        {
            p[a] = b;
            res += w;
            cnt ++ ;
        }
    }

    if (cnt < n - 1) return INF;
    return res;
}
```

## 匈牙利算法

来源：`第三章.txt` 第 400 行起。以下原文未改写，修正建议单独列出。

寻找交替路径以增加二分图匹配数。

### 代码与步骤解读

### 为什么正确

增广路径反转后匹配数加1；无增广路径时匹配最大。

### 复杂度

简单DFS增广O(n1·m)时间，O(n+m)空间。

### 使用条件与易错点

原注释边方向写反，实际存左集合→右集合；每轮清空右侧st；此实现是二分图无权最大匹配，非带权指派算法。

### 小例子

L1接R1,R2，L2只接R1，可让L1改配R2得到2对。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
时间复杂度是 O(nm)O(nm), nn 表示点数，mm 表示边数
int n1, n2;     // n1表示第一个集合中的点数，n2表示第二个集合中的点数
int h[N], e[M], ne[M], idx;     // 邻接表存储所有边，匈牙利算法中只会用到从第二个集合指向第一个集合的边，所以这里只用存一个方向的边
int match[N];       // 存储第二个集合中的每个点当前匹配的第一个集合中的点是哪个

bool find(int x)
{
    for (int i = h[x]; i != -1; i = ne[i])
    {
        int j = e[i];
        if (!st[j])
        {
            st[j] = true;
            if (match[j] == 0 || find(match[j]))
            {
                match[j] = x;
                return true;
            }
        }
    }

    return false;
}

// 求最大匹配数，依次枚举第一个集合中的每个点能否匹配第二个集合中的点
int res = 0;
for (int i = 1; i <= n1; i ++ )
{
    memset(st, false, sizeof st);
    if (find(i)) res ++ ;
}
```

### 复杂度

```text
int phi(int x)
{
    int res = x;
    for (int i = 2; i <= x / i; i ++ )
        if (x % i == 0)
        {
            res = res / i * (i - 1);
            while (x % i == 0) x /= i;
        }
    if (x > 1) res = res / x * (x - 1);

    return res;
}
```

```text

int euler[N];           // 存储每个数的欧拉函数
bool st[N];         // st[x]存储x是否被筛掉


void get_eulers(int n)
{
    euler[1] = 1;
    for (int i = 2; i <= n; i ++ )
    {
        if (!st[i])
        {
            primes[cnt ++ ] = i;
            euler[i] = i - 1;
        }
        for (int j = 0; primes[j] <= n / i; j ++ )
        {
            int t = primes[j] * i;
```

用等价行变换将增广矩阵化为阶梯形。

### 代码与步骤解读

### 为什么正确

交换、非零倍乘与加减其他行保持解集合。

### 复杂度

### 使用条件与易错点

double与eps按尺度选择；0=非零为无解；原实现为方程数=未知数的方阵；精度误差可能需要残差复核。

### 小例子

x+y=3、x-y=1得到x=2,y=1。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
// a[N][N]是增广矩阵
int gauss()
{
    int c, r;
    for (c = 0, r = 0; c < n; c ++ )
    {
        int t = r;
        for (int i = r; i < n; i ++ )   // 找到绝对值最大的行
            if (fabs(a[i][c]) > fabs(a[t][c]))
                t = i;

        if (fabs(a[t][c]) < eps) continue;

        for (int i = c; i <= n; i ++ ) swap(a[t][i], a[r][i]);      // 将绝对值最大的行换到最顶端
        for (int i = n; i >= c; i -- ) a[r][i] /= a[r][c];      // 将当前上的首位变成1
        for (int i = r + 1; i < n; i ++ )       // 用当前行将下面所有的列消成0
            if (fabs(a[i][c]) > eps)
                for (int j = n; j >= c; j -- )
                    a[i][j] -= a[r][j] * a[i][c];

        r ++ ;
    }

    if (r < n)
    {
        for (int i = r; i < n; i ++ )
            if (fabs(a[i][n]) > eps)
                return 2; // 无解
        return 1; // 有无穷多组解
    }

    for (int i = n - 1; i >= 0; i -- )
        for (int j = i + 1; j < n; j ++ )
            a[i][n] -= a[i][j] * a[j][n];

    return 0; // 有唯一解
}
```

```text
若p是质数，则对于任意整数 1 <= m <= n，有：

{
```

## 分解质因数法求组合数

来源：`第四章.txt` 第 245 行起。以下原文未改写，修正建议单独列出。

### 为什么正确

0<=b<=a；不是固定模数算法；中间乘积用long long，特别是大素数。

### 小例子

C(5,2)=2×5=10。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
当我们需要求出组合数的真实值，而非对某个数的余数时，分解质因数的方式比较好用：
    1. 筛法求出范围内的所有质数
    2. 通过 C(a, b) = a! / b! / (a - b)! 这个公式求出每个质因子的次数。 n! 中p的次数是 n / p + n / p^2 + n / p^3 + ...
    3. 用高精度乘法将所有质因子相乘

int primes[N], cnt;     // 存储所有质数
int sum[N];     // 存储每个质数的次数
bool st[N];     // 存储每个数是否已被筛掉


void get_primes(int n)      // 线性筛法求素数
{
    for (int i = 2; i <= n; i ++ )
    {
        if (!st[i]) primes[cnt ++ ] = i;
        for (int j = 0; primes[j] <= n / i; j ++ )
        {
            st[primes[j] * i] = true;
            if (i % primes[j] == 0) break;
        }
    }
}


int get(int n, int p)       // 求n！中的次数
{
    int res = 0;
    while (n)
    {
        res += n / p;
        n /= p;
    }
    return res;
}


vector<int> mul(vector<int> a, int b)       // 高精度乘低精度模板
{
    vector<int> c;
    int t = 0;
    for (int i = 0; i < a.size(); i ++ )
    {
        t += a[i] * b;
        c.push_back(t % 10);
        t /= 10;
    }

    while (t)
    {
        c.push_back(t % 10);
        t /= 10;
    }

    return c;
}

get_primes(a);  // 预处理范围内的所有质数

for (int i = 0; i < cnt; i ++ )     // 求每个质因数的次数
{
    int p = primes[i];
    sum[i] = get(a, p) - get(b, p) - get(a - b, p);
}

vector<int> res;
res.push_back(1);

for (int i = 0; i < cnt; i ++ )     // 用高精度乘法将所有质因子相乘
    for (int j = 0; j < sum[i]; j ++ )
        res = mul(res, primes[i]);
```

## NIM游戏

来源：`第四章.txt` 第 319 行起。以下原文未改写，修正建议单独列出。

### 为什么正确

零局面任一步变非零，非零局面可选最高位把某堆变小使异或归零。

### 复杂度

O(n)时间，O(1)空间。

### 使用条件与易错点

每次仅一堆、任意正数量、取最后者胜；misère版本或限制取法不能直接套；有限无环公平游戏才能直接用SG递推。

[1,2,3]异或0，先手败。

### 原始模板与公式

以下为教学片段，可能包含伪代码、缺少的全局变量或原文笔误，不能整段直接编译。

```text
给定N堆物品，第i堆物品有Ai个。两名玩家轮流行动，每次可以任选一堆，取走任意多个物品，可把一堆取光，但不能不取。取走最后一件物品者获胜。两人都采取最优策略，问先手是否必胜。

我们把这种游戏称为NIM博弈。把游戏过程中面临的状态称为局面。整局游戏第一个行动的称为先手，第二个行动的称为后手。若在某一局面下无论采取何种行动，都会输掉游戏，则称该局面必败。
所谓采取最优策略是指，若在某一局面下存在某种行动，使得行动后对面面临必败局面，则优先采取该行动。同时，这样的局面被称为必胜。我们讨论的博弈问题一般都只考虑理想情况，即两人均无失误，都采取最优策略行动时游戏的结果。
NIM博弈不存在平局，只有先手必胜和先手必败两种情况。

定理： NIM博弈先手必胜，当且仅当 A1 ^ A2 ^ … ^ An != 0

公平组合游戏ICG
若一个游戏满足：

由两名玩家交替行动；
在游戏进程的任意时刻，可以执行的合法行动与轮到哪名玩家无关；
不能行动的玩家判负；
则称该游戏为一个公平组合游戏。
NIM博弈属于公平组合游戏，但城建的棋类游戏，比如围棋，就不是公平组合游戏。因为围棋交战双方分别只能落黑子和白子，胜负判定也比较复杂，不满足条件2和条件3。

有向图游戏
给定一个有向无环图，图中有一个唯一的起点，在起点上放有一枚棋子。两名玩家交替地把这枚棋子沿有向边进行移动，每次可以移动一步，无法移动者判负。该游戏被称为有向图游戏。
任何一个公平组合游戏都可以转化为有向图游戏。具体方法是，把每个局面看成图中的一个节点，并且从每个局面向沿着合法行动能够到达的下一个局面连有向边。

Mex运算
设S表示一个非负整数集合。定义mex(S)为求出不属于集合S的最小非负整数的运算，即：
mex(S) = min{x}, x属于自然数，且x不属于S

SG函数
在有向图游戏中，对于每个节点x，设从x出发共有k条有向边，分别到达节点y1, y2, …, yk，定义SG(x)为x的后继节点y1, y2, …, yk 的SG函数值构成的集合再执行mex(S)运算的结果，即：
SG(x) = mex({SG(y1), SG(y2), …, SG(yk)})
特别地，整个有向图游戏G的SG函数值被定义为有向图游戏起点s的SG函数值，即SG(G) = SG(s)。
```

# 清单专有题目补充

[返回 104 道题目索引](题目索引.md)

这些题号出现在 Word 清单，但没有对应的完整模板条目。以下为补充知识点与解法方向，没有复制题面，也没有声称在线评测通过。题号与分类来自本地文档。

## AcWing 786 · 快速选择

寻找第 k 小元素时，快速分区后只递归包含目标排名的一侧。若左段有 s 个元素，k<=s 就进左段，否则进右段并把 k 减 s。正确性来自两侧有序关系而非侧内已经排序。随机枢轴期望 O(n)，最坏 O(n²)，原地版本额外空间取决于递归。必须明确 k 从1计，重复元素也占排名；迭代版能减少栈风险。

## AcWing 788 · 逆序对

归并左右两段时，如果 q[i]>q[j]，左段从 i 到 mid 全部大于右段当前值，贡献 mid-i+1。相等元素不算逆序，应先取左段；其余情况正常合并。各逆序对按两端第一次分到不同子区间被计数一次。时间 O(n log n)，空间 O(n)，计数用 long long。例：[3,1,2]有(3,1)、(3,2)两对。

## AcWing 842 · 排列 DFS

depth 表示当前填第几位，used[x] 表示数字是否使用。逐个尝试未用数字，设置标记、递归、撤销标记。depth==n 时输出。搜索树涵盖每个合法排列恰好一次。输出成本 O(n·n!)，辅助空间 O(n)。忘记撤销会漏解；n=3 应有6个排列。

## AcWing 843 · N 皇后

每行恰放一个皇后，列、主对角线、反对角线分别维护占用。行 r 列 c 的对角线编号可用 r+c 与 r-c+n-1（从0计）。尝试合法列再回溯，所有行填完输出棋盘。排列式搜索上界 O(n!)（逐列判定会有额外循环成本），状态空间 O(n)，输出棋盘另占 O(n²)。不要把两个对角线编号混用。

## AcWing 844 · 迷宫 BFS

格子为状态，四方向相邻且可通行的移动为单位权边。dist 全设-1，起点设0，首次入队时设置邻格距离。BFS 首次到达保证最少步数，时间空间 O(RC)。先检查边界再访问数组；起点终点可通行，无法到达按题意输出。1×1可通行迷宫距离为0。

## AcWing 845 · 八数码

把九个格子的排列编码为字符串，空格每次与邻居交换产生下一状态。用队列与哈希距离表 BFS，遇目标即得最少步数；还可先按逆序对奇偶性判断可解性。最多9!个排列状态，每个状态至多4个后继，计入字符串复制为 O(9·9!) 时间与空间上界。起点即目标返回0；状态还原必须避免交换后未撤销。

## AcWing 143 · 最大异或对

二进制 Trie 存储每个数的各位。查询时优先走当前位相反的分支，因为高位1的贡献超过所有低位总和；不存在才走同位。对非负、固定 B 位整数构建与查询均 O(nB)，空间 O(nB)。从最高有效位开始，位移使用 unsigned，别直接用26字母 Trie。

## AcWing 240 · 带权并查集与食物链

令 d[x] 记录节点到父节点的关系差，模3表示同类与循环捕食关系。路径压缩累加偏移并对3规范化。同根时检查 d[a]-d[b] 是否等于输入关系；异根时按 d[ra]=w-d[a]+d[b] 挂接。无效编号与自相矛盾陈述单独统计。若按秩合并，反向挂接须取相反偏移。摊还 O(α(n)) 需同时满足合并优化与压缩。

## AcWing 876 · 模逆元

逆元 x 满足 a·x≡1(mod p)。当 p 是素数且 a 不被 p 整除，用费马小定理得到 a^(p-2) mod p，快速幂 O(log p)、空间 O(1)。一般模数存在逆元当且仅当 gcd(a,p)=1，使用扩展欧几里得。模数1的场景需按题目定义处理；不能把费马小定理用于任意合数模。

## AcWing 878 · 线性同余方程

解 ax≡b(mod m)，等价 ax+my=b。exgcd 得到 g=gcd(a,m) 和一组 ax0+my0=g；若 b%g!=0则无解，否则 x=x0·(b/g)，再模 m/g 规范化。解的周期为 m/g。时间 O(log m)，使用 long long，乘法可能还需要更宽类型。例：4x≡2(mod6)，x≡2(mod3)。

## AcWing 204 · 扩展中国剩余定理

合并 x≡r1(mod m1) 与 x≡r2(mod m2)：令 x=r1+m1·t，则 m1·t≡r2-r1(mod m2)。用 exgcd，要求 gcd(m1,m2) 整除差值，再求 t 模 m2/g；合并模数是 m1/g·m2。逐条合并给出全部约束的交集。每次 O(log 模数)，总复杂度随模数位数变化；乘积与中间乘法可能超64位，需按数据范围选择宽整数。例：x≡1(mod2)、x≡2(mod3)得到x≡5(mod6)。

## AcWing 884 · 异或线性方程

在 GF(2) 上进行高斯消元：主元只能为1，行相加就是异或，不做浮点除法。每列找主元并交换，消除其余行的该列；零系数行常数为1判无解，秩小于未知数且无矛盾则多解。朴素 O(n³) 时间、O(n²) 空间，用 bitset 能批量异或。例：x⊕y=1与x⊕y=0矛盾。

## AcWing 890 · 容斥原理

若要计算1..n中能被指定数至少一个整除的整数，枚举非空子集，奇数大小加 floor(n/lcm)，偶数大小减。贡献重叠次数按二项式抵消后恰好为1。互异质数时 lcm 为乘积；一般数必须用 lcm。k 项的直接实现 O(k·2^k)，空间 O(k)。每次乘前用当前乘积>n/因子检查并提前结束，避免溢出。例：1..10被2或3整除有5+3-1=7个。

## AcWing 892 · 台阶 Nim

台阶石子只能向相邻较低台阶移动时，按题意的1基编号取奇数层石子数异或。偶数层向奇数层的移动可以在下一回合配对移走，从而抵消；奇数层的动作对应改变等价 Nim 堆。时间 O(n)，空间 O(1)。这个结论依赖移动规则与地面状态，不能直接用于任意台阶游戏。应先确认奇偶编号约定。

## AcWing 894 · 拆分 Nim

允许将一堆规模 x 拆成两堆较小规模 i,j 时，SG(x)=mex{SG(i)⊕SG(j)}，枚举题意允许的 i,j（如0<=j<=i<x）。因为两堆是独立游戏，其SG取异或；把转移值集合求mex得到当前值。若计算规模至M，直接方法 O(M³) 时间，O(M²) 临时集合上界可优化，持久SG数组 O(M)。严格变小保证递归终止；空堆通常SG=0，重复的(i,j)可按对称性减少。
