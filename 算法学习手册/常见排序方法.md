## 1. 先理解排序在做什么

升序排序就是重新排列元素，使 `a[0] <= a[1] <= ... <= a[n-1]`，同时每个元素出现的次数不变。排序经常是二分、双指针、去重、区间合并和贪心的前置步骤。

**稳定性**：只按成绩排序时，原来的 `(80,张三)、(80,李四)` 排序后仍保持张三在李四前面，称为稳定。稳定性与“能否排对大小”不同；即使最终数字序列相同，相同键对应的记录顺序也可能改变。

**额外空间**：下表包括辅助数组和递归栈，不包括输入数组。`n` 为元素个数，`K = 最大值 - 最小值 + 1` 为值域大小，`d` 为数字位数，`B` 为基数。稳定性和复杂度针对本文描述的实现。

| 方法 | 最好时间 | 平均/期望时间 | 最坏时间 | 额外空间 | 稳定 |
|---|---|---|---|---|---|
| 冒泡（提前退出） | O(n) | O(n²) | O(n²) | O(1) | 是 |
| 选择（交换最小值） | O(n²) | O(n²) | O(n²) | O(1) | 否 |
| 插入 | O(n) | O(n²) | O(n²) | O(1) | 是 |
| 希尔（间隔每次减半） | O(n log n) | 与分布有关，不给统一紧确界 | O(n²) | O(1) | 否 |
| 归并 | O(n log n) | O(n log n) | O(n log n) | O(n) | 是 |
| 随机三路快排 | O(n)，全相等时 | O(n log n) 期望 | O(n²) | 期望 O(log n)，最坏 O(n) | 否 |
| 堆排序 | O(n)，全相等且下沉提前停止时 | O(n log n) | O(n log n) | O(1) | 否 |
| 计数（前缀和定位） | O(n+K) | O(n+K) | O(n+K) | O(n+K) | 是 |
| LSD 基数 | O(d(n+B)) | O(d(n+B)) | O(d(n+B)) | O(n+B) | 是 |

基数排序的表格按执行 `d` 轮计算；本文实现对全零数组直接结束。常见的堆排序复杂度统一上界写作 O(n log n)，仍然正确。

对于任意互异元素，仅靠比较决定次序的排序，在最坏情况下需要 Ω(n log n) 次比较：有 `n!` 种排列，二元比较决策树至少需要 `log₂(n!)` 层。计数和基数排序利用了整数值域或位信息，因此不受这个比较模型下界限制。

下文函数片段可放进同一个 `.cpp` 文件，共用以下头文件；调用范例见文末。数组长度约定能用 `int` 表示。

```cpp

```

## 2. 冒泡排序：每一轮把最大值送到右端

从左往右比较相邻元素，前一个更大就交换。第一轮后，整个数组的最大值在最后；第二轮只处理前 `n-1` 个元素。已经排好的后缀不再参与比较。

例如 `[3,1,4,2]`：第一轮依次变成 `[1,3,4,2]`、`[1,3,4,2]`、`[1,3,2,4]`；第二轮得到 `[1,2,3,4]`。若一整轮没有交换，说明所有相邻元素都满足升序，可以提前退出。

```cpp
void bubble_sort(vector<int>& a) {
    for (int end = (int)a.size() - 1; end > 0; --end) {
        bool changed = false;
        for (int j = 0; j < end; ++j) {
            if (a[j] > a[j + 1]) {
                swap(a[j], a[j + 1]);
                changed = true;
            }
        }
        if (!changed) break;
    }
}
```

正确性来自每轮固定一个最大值。相等时不交换，所以稳定。不要将 `>` 写成 `>=`，否则会破坏稳定性，也让全相等数组无法提前退出。适合入门理解交换过程，大数据排序不优先选它。

## 3. 选择排序：每一轮挑出剩下的最小值

第 `i` 轮扫描 `[i,n)`，找到最小值，与 `a[i]` 交换。处理后前缀 `[0,i]` 就是最小的 `i+1` 个数，并且有序。

`[3,1,4,2] → [1,3,4,2] → [1,2,4,3] → [1,2,3,4]`。

```cpp
void selection_sort(vector<int>& a) {
    int n = (int)a.size();
    for (int i = 0; i < n; ++i) {
        int p = i;
        for (int j = i + 1; j < n; ++j)
            if (a[j] < a[p]) p = j;
        if (p != i) swap(a[i], a[p]);
    }
}
```

即使输入有序，仍要比较 `n(n-1)/2` 次，因此时间始终为 O(n²)，但交换次数最多为 `n-1`。它不稳定：`[2甲,2乙,1]` 第一次交换后变成 `[1,2乙,2甲]`。

## 4. 插入排序：像整理手中的扑克牌

维护一个有序前缀。拿出下一个元素 `x`，把前缀中大于 `x` 的元素逐个向右移，再把 `x` 放到空出来的位置。

`[3 | 1,4,2] → [1,3 | 4,2] → [1,3,4 | 2] → [1,2,3,4]`。竖线左边始终有序；插入新元素不会破坏已有元素的相对顺序。

```cpp
void insertion_sort(vector<int>& a) {
    for (int i = 1; i < (int)a.size(); ++i) {
        int x = a[i], j = i - 1;
        while (j >= 0 && a[j] > x) {
            a[j + 1] = a[j];
            --j;
        }
        a[j + 1] = x;
    }
}
```

必须先保存 `x`，否则移动时会覆盖它；必须先检查 `j >= 0` 再访问 `a[j]`。只移动严格大于 `x` 的元素，保证稳定。

一个逆序对是满足 `i < j` 且 `a[i] > a[j]` 的下标对。这里每次右移消除一个逆序对，所以时间为 O(n+逆序对数)：接近有序时往往很好，逆序时退化为 O(n²)。

## 5. 希尔排序：先隔着距离插入，最后相邻插入

将间隔为 `gap` 的元素看成一组，分别做插入排序，逐渐减小间隔，最后必须处理 `gap=1`。

例如 `[8,5,3,1]`：`gap=2` 时分别整理下标 `(0,2)` 和 `(1,3)`，得到 `[3,1,8,5]`；`gap=1` 时做普通插入，得到 `[1,3,5,8]`。最后一轮就是全数组插入排序，因此保证结果有序。

```cpp
void shell_sort(vector<int>& a) {
    int n = (int)a.size();
    for (int gap = n / 2; gap > 0; gap /= 2) {
        for (int i = gap; i < n; ++i) {
            int x = a[i], j = i;
            while (j >= gap && a[j - gap] > x) {
                a[j] = a[j - gap];
                j -= gap;
            }
            a[j] = x;
        }
    }
}
```

间隔序列会影响复杂度，不能把所有希尔排序都记成 O(n log n)。本文采用减半间隔，最坏 O(n²)。跨位置移动会改变相同键的顺序，因此不稳定。竞赛中通常了解思想即可。

## 6. 归并排序：先排好两半，再线性合并

使用左闭右开区间 `[l,r)`，长度小于等于 1 时已经有序。递归排好 `[l,m)` 与 `[m,r)`，然后用两个指针，每次取两段当前较小的数。

`[3,1,4,2]` 拆成 `[3,1]`、`[4,2]`，分别得到 `[1,3]`、`[2,4]`；合并依次取出 `1、2、3、4`。因为两段各自有序，段首较小的元素就是所有剩余元素的最小值。

```cpp
void merge_sort_impl(vector<int>& a, vector<int>& tmp, int l, int r) {
    if (r - l <= 1) return;
    int m = l + (r - l) / 2;
    merge_sort_impl(a, tmp, l, m);
    merge_sort_impl(a, tmp, m, r);
    int i = l, j = m, k = l;
    while (i < m && j < r)
        tmp[k++] = (a[i] <= a[j] ? a[i++] : a[j++]);
    while (i < m) tmp[k++] = a[i++];
    while (j < r) tmp[k++] = a[j++];
    for (int p = l; p < r; ++p) a[p] = tmp[p];
}
void merge_sort(vector<int>& a) {
    vector<int> tmp(a.size());
    merge_sort_impl(a, tmp, 0, (int)a.size());
}
```

每层合并总计 O(n)，共 O(log n) 层，时间 O(n log n)；缓冲数组 O(n)，递归栈 O(log n)，总额外空间 O(n)。相等时用 `<=` 优先取左边，才能稳定。不要混用闭区间模板的边界。

**竞赛延伸：逆序对。** 合并时若 `a[i] > a[j]`，左段剩余的 `m-i` 个数都大于 `a[j]`，答案加 `m-i`；相等不能计入。最大答案是 `n(n-1)/2`，应使用 `long long`。这也是为什么要理解归并，而不只是记住 `sort`。

## 7. 快速排序：先按枢轴分组，再递归

选一个枢轴值 `x`，把元素分成小于、等于、大于 `x` 三部分。中间一组已经位于正确的值域位置，只递归左右两组。三路划分特别适合大量重复值。

例如 `[3,1,3,2,4]` 以 `3` 为枢轴，可分成 `[1,2] | [3,3] | [4]`，左右各排好后整体有序；每组内部的临时顺序不固定。

```cpp
void quick_sort_impl(vector<int>& a, int l, int r, mt19937& rng) {
    if (r - l <= 1) return;
    int x = a[uniform_int_distribution<int>(l, r - 1)(rng)];
    int lt = l, i = l, gt = r;
    while (i < gt) {
        if (a[i] < x) {
            swap(a[lt++], a[i++]);
        } else if (a[i] > x) {
            swap(a[i], a[--gt]);
        } else {
            ++i;
        }
    }
    quick_sort_impl(a, l, lt, rng);
    quick_sort_impl(a, gt, r, rng);
}
void quick_sort(vector<int>& a) {
    mt19937 rng(random_device{}());
    quick_sort_impl(a, 0, (int)a.size(), rng);
}
```

循环始终维护四段：`[l,lt)` 小于 `x`，`[lt,i)` 等于 `x`，`[i,gt)` 尚未处理，`[gt,r)` 大于 `x`。每步未知区间都缩短，循环结束后分组成立。

最容易错的是“大于”分支：右边换来的元素尚未检查，因此此时不能 `++i`。枢轴必须保存成值，不能引用一个会被交换的位置。

随机选枢轴使任意固定输入的期望时间为 O(n log n)，但不保证每次划分平衡，最坏仍为 O(n²)，递归栈最坏 O(n)。全相等时一次划分就结束，时间 O(n)。交换会破坏稳定性。比赛里单纯排序一般直接用 `std::sort`；手写快排主要用来学习划分思想。

## 8. 堆排序：用最大堆反复取出最大值

最大堆要求父节点不小于子节点，根节点因此是最大值。下标从 0 开始时，左右孩子是 `2u+1`、`2u+2`。注意堆只保证父子大小关系，并不意味着整个数组已经有序。

先自底向上建最大堆，再将堆顶与末尾交换，将末尾划入有序后缀；只对剩余堆执行下沉。例如 `[3,1,4,2]` 建堆可得 `[4,2,3,1]`，取出 `4` 并修复剩余堆后得到 `[3,2,1 | 4]`。

```cpp
void sift_down(vector<int>& a, int u, int n) {
    while (u < n / 2) { // 只在有孩子时计算孩子下标
        int v = 2 * u + 1;
        if (v + 1 < n && a[v + 1] > a[v]) ++v;
        if (a[u] >= a[v]) break;
        swap(a[u], a[v]);
        u = v;
    }
}
void heap_sort(vector<int>& a) {
    int n = (int)a.size();
    for (int u = n / 2 - 1; u >= 0; --u) sift_down(a, u, n);
    for (int end = n - 1; end > 0; --end) {
        swap(a[0], a[end]);
        sift_down(a, 0, end);
    }
}
```

下沉时选择较大的孩子交换，保证父节点最终不小于两个孩子。自底向上建堆是 O(n)：约一半节点不用下沉，四分之一最多下一层，八分之一最多下两层，总工作量是线性级别。后续 `n-1` 次取最大值，每次最多 O(log n)，最坏总时间 O(n log n)。额外空间 O(1)，不稳定。

不要将“排序整个数组”和“动态维护最值”混为一谈：后者通常用 `priority_queue`，例如维护前 k 大、小根堆合并等。

## 9. 计数排序：用值作下标，统计每个值出现几次

当整数范围小，可以统计次数再决定位置。例如 `[3,1,2,1]` 的计数是 `1:2、2:1、3:1`，升序结果自然是 `[1,1,2,3]`。

如果只是输出整数，按频次依次输出就够了；若要保留记录的其他字段，并保证稳定，应使用前缀和分配位置。以下采用后一种结构：`cnt[v]` 做前缀和后表示“不大于 v 的元素个数”，于是该值的最后可用位置是 `cnt[v]-1`。

```cpp
void counting_sort(vector<int>& a) {
    if (a.empty()) return;
    auto bounds = minmax_element(a.begin(), a.end());
    long long low = *bounds.first;
    long long range = (long long)*bounds.second - low + 1;
    // 教学用内存保护阈值，实际应按题目内存限制选择。
    if (range > 1000000) throw length_error("counting sort range too large");
    vector<int> cnt((size_t)range, 0), out(a.size());
    for (int x : a) ++cnt[(size_t)((long long)x - low)];
    for (size_t v = 1; v < cnt.size(); ++v) cnt[v] += cnt[v - 1];
    for (int i = (int)a.size() - 1; i >= 0; --i) {
        size_t v = (size_t)((long long)a[i] - low);
        out[--cnt[v]] = a[i];
    }
    a.swap(out);
}
```

减去最小值后可以处理负数。值域跨度必须先转 `long long` 再相减，否则极端整数可能溢出。倒序扫描输入，是为了让原来靠后的相同键放到靠后的位置；若改成记录类型，要将整条记录写入 `out`。

时间 O(n+K)，额外空间 O(n+K)。只有 10 个数但值域跨度 10⁹ 时，计数排序通常不合适；不能只看 n 小就开计数数组。此函数遇到跨度超过阈值会抛出异常，应换用比较排序。

## 10. 基数排序：从低位到高位，每一轮稳定排序

LSD 基数排序先按个位稳定排序，再按十位、百位排序。稳定性让高位相同的元素保留已经排好的低位顺序，最终得到完整数字的大小顺序。

例如 `[21,13,12]`：按个位得到 `[21,12,13]`，再按十位得到 `[12,13,21]`。第二轮必须保留十位同为 1 的 `12、13` 的顺序。

```cpp
void radix_sort(vector<int>& a) {
    if (a.empty()) return;
    for (int x : a)
        if (x < 0) throw invalid_argument("radix sort requires nonnegative ints");
    int maximum = *max_element(a.begin(), a.end());
    vector<int> out(a.size());
    for (long long place = 1; maximum / place > 0; place *= 10) {
        array<int, 10> cnt{};
        for (int x : a) ++cnt[(x / place) % 10];
        for (int d = 1; d < 10; ++d) cnt[d] += cnt[d - 1];
        for (int i = (int)a.size() - 1; i >= 0; --i) {
            int d = (a[i] / place) % 10;
            out[--cnt[d]] = a[i];
        }
        a.swap(out);
    }
}
```

这里基数 B=10，只处理非负 `int`；不要直接用负数的余数作为下标。`place` 用 `long long`，处理到 `INT_MAX` 的最高位之后乘 10 仍不会溢出。每轮 O(n+B)，共 d 轮。对于记录，每轮必须移动整条记录，才能保留关联数据。

**桶排序是另一种思路。** 把值域分成多个有序区间，将元素分配到桶里，桶内排序后按桶编号拼接。例如将 `[0,1)` 内的小数按十分位分桶。桶数量、映射规则和桶内算法决定性能：采用插入排序且输入近似均匀分布、桶数与 n 同阶时，期望可达 O(n)；若都落入同一桶，可能退化到 O(n²)。稳定性也取决于桶内算法和收集方式，不能无条件写成“线性且稳定”。

计数排序直接统计每个键，桶排序把一段值域装进一个桶，基数排序对数字的各个位多轮处理，三者不要混淆。

## 11. 比赛时怎样选、怎样写

| 需求 | 通常选择 | 原因 |
|---|---|---|
| 普通数组或结构体排序 | `std::sort` | 写法短，O(n log n) 比较复杂度，不保证稳定 |
| 同键必须保持原顺序 | `std::stable_sort` | 提供稳定性；C++17 中有足够额外内存时 O(n log n)，否则可为 O(n log² n) 次比较 |
| 求逆序对 | 归并排序 | 合并时批量计数 |
| 数量小或接近有序，学习手写 | 插入排序 | 实现简单，移动次数与逆序对数相关 |
| 整数值域很小 | 计数排序 | 可用 O(n+K) 完成 |
| 非负整数、位数有限 | 基数排序 | 利用位信息，需要每轮稳定 |
| 原地排序且要求最坏 O(n log n) | 堆排序 | 不需要线性辅助数组 |
| 只需第 k 小 | `nth_element` | 平均线性；不保证两侧各自有序 |
| 动态插入并反复取最值 | `priority_queue` | 维护堆，不必每次重排全部数据 |

普通升序和降序：

```cpp
void stl_examples(vector<int>& a) {
    sort(a.begin(), a.end());
    sort(a.begin(), a.end(), greater<int>());
}
```

结构体按“分数降序，分数相同按编号升序”排列：

```cpp
struct Student { int score, id; };
void sort_students(vector<Student>& students) {
    sort(students.begin(), students.end(), [](const Student& x, const Student& y) {
        if (x.score != y.score) return x.score > y.score;
        return x.id < y.id;
    });
}
```

比较器表达的是“x 是否严格排在 y 前面”。不能使用 `>=` 或 `<=`，因为相等对象与自身比较必须为假；还必须满足传递性。不要用 `x.score-y.score` 判断正负，减法可能溢出。若需求是同分保持输入顺序，应使用 `stable_sort` 并只比较分数，而不是额外按编号排序。

STL 区间是 `[begin,end)`。对普通数组 `a` 的下标 `[l,r]` 排序，写 `sort(a+l,a+r+1)`；对长度 n 的数组写 `sort(a,a+n)`。

下面是可搭配前文头文件与任意排序函数的完整输入输出入口。默认调用归并排序；替换成其他函数时，注意计数排序的值域限制和基数排序的非负限制。

```cpp
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    if (!(cin >> n) || n < 0) return 0;
    vector<int> a(n);
    for (int& x : a) cin >> x;
    merge_sort(a);
    for (int i = 0; i < n; ++i) {
        if (i) cout << ' ';
        cout << a[i];
    }
    cout << '\n';
}
```

输入 `5` 和 `3 -1 3 0 2`，输出应为 `-1 0 2 3 3`。
