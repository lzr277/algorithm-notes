# 验证报告

验证日期：2026-10-12（Asia/Shanghai）。

## 范围

内容检查覆盖四章全部63个原文条目、23个动态规划/贪心补充专题和104个原清单题号；另有15个清单专有题目说明，补足没有原模板的题号。

`verify_handbook.py` 检查每个条目的目录锚点、片段文件、全部本地 Markdown 链接、104个题号的讲解覆盖，以及重新生成前后的 SHA-256 一致性。

`verify_programs.py` 使用 C++17、`-O2 -Wall -Wextra -pedantic` 编译8个完整程序。固定随机种子为20261012；快速排序对照标准排序、二分对照线性查找、并查集对照朴素集合标签、BFS对照分层集合搜索、快速幂对照Python模幂、背包和LIS对照穷举、区间选点对照穷举端点子集。还覆盖空数组、单点图、不可达图、重复值、负数、大模数、重复合并和闭区间端点相接等情形。

## 本地结果

**通过**：86个讲解条目、104个题号、446个本地链接检查与重复生成一致性检查；8个程序编译无警告，424个测试用例全部通过。

编译器：MinGW GNU g++ 15.2.0。实际结果记录在 [程序测试结果.json](程序测试结果.json)。文件包含编译器版本、每个程序测试数、总用例数及PASS状态；生成失败或测试失败会抛出错误，不能视为通过。

内容与程序验证的最后一次命令输出见根目录 `验证输出.txt`。本报告只在两组验证都通过后随项目发布。

## 限制

原文片段是原样存档，其中有缺失全局变量、公式和伪代码，不参与编译；本地测试只覆盖8个完整程序，不证明其余算法片段正确。所有程序均未进行在线OJ提交，没有“AcWing已AC”的结论。补充专题为学习讲解，部分复杂算法尚无完整程序。
