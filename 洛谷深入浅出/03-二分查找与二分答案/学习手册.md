> 本章主线：不是背住几行循环，而是始终知道“答案还可能在哪里”。

## 01 二分查找：把书一半一半地排除

### 先从一个能想象的场景开始

你在一本按字母排序的通讯录里找名字，会从第一页逐个看吗？通常会翻到中间：若目标在当前名字后面，前半本都不用看了。二分就是把这个动作变成程序。

用数组 `[1,3,3,3,7,9]` 查3。我们想要的是**第一次出现**，所以在中间看见3时，不能马上满足：左边可能还有3。

```text
下标       1   2   3   4   5   6    7
数值       1   3   3   3   7   9   哨兵位置
>=3？      否  是  是  是  是  是    是（逻辑约定）
               ↑ 要找第一个“是”
```

哨兵位置只是“没找到合格元素”的返回位置，不是真的给数组填了一个值。

### 概念与原理

二分通过一次比较排除一整段候选。它依赖的不是“数组”这个容器，而是顺序带来的推理：中间的数都小于3，前面的更不可能够大；中间已经>=3，后面也都>=3，但最靠左的答案可能还在左侧。

每次候选长度大约减半。100万项最多约20次判断就能压到一个位置。时间O(log n)，额外空间O(1)；若每次二分前都重新排序，会把准备工作的代价漏算。

### C++ 实现与逐步手推

本章的查找统一用下标1..n，初始l=1、r=n+1。目标是返回第一个>=x的位置，允许返回n+1。

```cpp
int first_ge(int n,int x)
{
    int l=1,r=n+1;
    while(l<r)
    {
        int mid=l+(r-l)/2;
        if(a[mid]>=x) r=mid;
        else l=mid+1;
    }
    return l;
}
```

| 轮次 | l | r | mid | 看见什么 | 下一步 |
|---|---:|---:|---:|---|---|
| 1 | 1 | 7 | 4 | a[4]=3，已经够大 | r=4，仍保留它 |
| 2 | 1 | 4 | 2 | a[2]=3，已经够大 | r=2 |
| 3 | 1 | 2 | 1 | a[1]=1，不够大 | l=2，排除它 |
| 结束 | 2 | 2 | — | 候选只剩位置2 | 返回2 |

### 作用与使用场景

适合已排序数组的多次查找、插入位置、重复值边界。若原数组无序，要先判断能否排序：P2249要求原编号且输入本就有序，不能随意打乱原顺序。核心不是“找到了一个3”，而是“找到了最左边的合格位置”。

## 02 边界与不变量：给左右手规定清楚职责

### 概念：答案位置不是目标值

查4时，first_ge返回5，因为a[5]=7是第一个>=4的数；但数组里根本没有4。**找到插入位置不等于找到相等元素。** 查询精确值还要检查位置合法且a[pos]==x。

### 原理：每一轮都要保住答案

设p是第一个>=x的位置，不存在就令p=n+1。始终保持p在闭区间[l,r]里：

- a[mid]>=x：p<=mid，因此r=mid，不能写mid-1把潜在答案删掉。
- a[mid]<x：mid以及它左边都不合格，因此l=mid+1。

每轮l<r，向下取整保证mid<r，所以mid最多为n，不会读取a[n+1]。当两手碰面时，p就无处可藏了。

```text
只剩两个候选：[l] [r]
mid取左边l
如果a[mid]不够：l=mid+1，确实向右走
如果够了：r=mid，确实向左收
两种情况都会缩短，才不会原地打转
```

### 实现：先检查下标，再读数组

```cpp
int pos=first_ge(n,x);
if(pos<=n&&a[pos]==x) cout<<pos;
else cout<<-1;
```

&&从左到右短路：位置超出就不读数组。若把两项倒过来，就可能先越界。`mid=l+(r-l)/2`在本章非负下标范围也避免了l+r直接相加的风险。

### 使用场景与易错点

全小于x时返回n+1，全大于x时返回1，n=1也应能结束。初始化、循环条件、中点取法、更新规则是一整套约定，不要从不同模板各抄一句。初学时先固定这套，理解后再比较其他区间写法。

## 03 lower_bound 与 upper_bound：给同一个值拍集体照

### 概念与直觉

数组 `[1,3,3,3,7,9]` 中三个3站成一排。lower_bound站到这排人的左边，upper_bound站到这排人的右边：

```text
1 | 3  3  3 | 7  9
    ↑         ↑
    lower(3)  upper(3)
位置2         位置5
人数=5-2=3
```

lower_bound找第一个>=x；upper_bound找第一个>x。名字别按“上界=最后一个相等”硬翻：upper指向的是最后一个相等元素的**后一个位置**。

### 原理与实现

对有序升序数组，它们分别找两条单调判断线的第一个真：a[i]>=x，与a[i]>x。

```cpp
int l=lower_bound(a+1,a+n+1,x)-a;
int r=upper_bound(a+1,a+n+1,x)-a;
int cnt=r-l;
```

a+1指第一个参与查找的元素，a+n+1是尾后位置、不参与查找；返回的是指针，减a才转成从1开始的下标。查4时两个位置都是5，数量为0。查10时两个位置都是n+1，仍然数量为0，不必访问那个位置。

### 作用与使用场景

统计重复值、求第一个>=x、最后一个<=x（upper位置减1）和区间计数。数组上每次O(log n)。输入必须符合相应的有序/划分条件；本章直接要求先升序排列。尾后指针可以做减法，不能拿来解引用。

## 04 A-B数对：固定一个人，统计他的搭档

### 概念与策略

不必同时猜A、B。固定当前位置的B，则A必须等于B+C。对每个B，找目标值出现了多少次，加起来即可。

例如 `[1,1,2,2,2]`，C=1。两个位置上的1，各能与三个位置上的2配对，所以共有2×3=6对。值相等但位置不同，题目仍算不同数对。

### 为什么不会重算

每一对都有唯一的B所在位置，循环恰好处理它一次。C是正数，所以A与B不可能来自同一个位置，不需要额外减去自己。如果把题目改成C=0，计数定义和自配对问题必须另行分析，不能照抄结论。

### 实现、复杂度与用途

完整程序P1102见后文，核心是对每个a[i]+C调用两次边界查询。排序O(n log n)，n次查询O(n log n)，空间O(n)。答案可能达到约10^10，要用64位；你的int宏已经提供64位，但仍应知道为什么需要它。这是“固定一维，把另一维交给查找”的常见降复杂度方法。

## 05 二分答案：先问“这个数能不能做到”

### 概念：从问答题换成判断题

直接问“锯子最高能设多少”很难；换成“设为15米，木材够不够”就只需算一遍。二分答案先猜目标值，再用check判断，利用真假分界缩小范围。

```text
候选高度    0  1  2 ... 15 | 16 ... 20
木材够吗    是 是 是 ... 是 | 否 ... 否
                         ↑ 最大可行值
```

不是看到“最大”“最小”就能二分，必须证明真假只变一次。像“是否恰好砍到7单位”可能不是一条前真后假的线；本题问至少需要多少，因此可以。

### 原理：单调的是可行性

若高度h能取得足够木材，再降低锯子只会取得更多，仍可行。这证明check(h)从真到假。原数据的树高可以无序，二分的是高度的数轴，根本不要求先排序树高。

### 实现：最大可行值统一使用ans记录法

```cpp
int l=L,r=R,ans=-1;
while(l<=r)
{
    int mid=l+(r-l)/2;
    if(check(mid))
    {
        ans=mid;
        l=mid+1;
    }
    else r=mid-1;
}
```

mid可行就把它记入ans，再大胆去右侧找更大的；不可行就往左缩。这里已经把mid保存了，更新可以排除它。与first_ge保留mid的模板不同，不要混用。ans=-1表示没有发现任何可行值；若题目保证有解，它最终会被更新。

### 使用场景与复杂度

“最大化最小距离”“最小化最大负载”“满足需求的最大高度”经常出现，但都要先画真假线。若一次check要O(n)，总复杂度是O(n log V)，不是O(log V)；V为候选范围大小。

## 06 check怎么写：把复杂目标拆成一次扫描

### 砍树：直接累计就够了

树高20、15、10、17，需求7。设h=15，每棵贡献5、0、0、2，共7，恰好够；h=16贡献4、0、0、1，共5，不够，所以最佳高度在15这条分界处。

| 猜的高度 | 四棵树的贡献 | 总木材 | 可行性 |
|---:|---|---:|---|
| 10 | 10、5、0、7 | 22 | 真 |
| 15 | 5、0、0、2 | 7 | 真 |
| 16 | 4、0、0、1 | 5 | 假 |

实现就是累加max(0,a[i]-h)。达到需求后可以提前返回true，因为后面只会继续增加。总木材比单棵树高大很多，要用64位。木材判断与二分移动方向分开写，排错时先单独核对check。

### 奶牛：贪心负责判断，二分负责找边界

牛舍位置1、2、4、8、9，放3头牛。猜最近距离d=3：先放1，再放4，再放8，成功。猜d=4：先放1，下一个最早能放8，之后没有第三间合格牛舍，失败。

```text
d=3：1(牛)  2  4(牛)       8(牛) 9
d=4：1(牛)  2  4           8(牛) 9   放不够
```

为什么每次放在最早满足距离的位置？把某个方案里的当前牛向左挪到这个位置，不会影响前面的距离约束，也只会给后面的牛留出更多空间。逐头交换，贪心可以放下的数量不少于任意方案。因此check的贪心判定本身也有正确性依据。

如果距离d能放下m头，要求更小距离时当然还能放下，所以仍是真→假，找最大真。check里比较的是“当前牛舍与上一头已放奶牛的距离”，不是与数组上一项的距离。

### 实现与适用场景

完整check分别在P1873和P1824程序中，前者直接求和，后者先排序再贪心。奶牛排序O(n log n)，二分部分O(n log V)，空间O(n)。这里的m至少为2且不超过n；若改成单牛，最小两牛距离没有同样含义，需要重新定义。

## 07 实数二分：在异号端点中间越夹越紧

### 概念：没有“下一个实数”

整数候选可以+1跳过已检查位置，实数却没有紧邻的下一个值。对一个已经夹住根的连续函数区间，我们每次取中点，再保留仍然异号的半段，像两只手一点点夹住根。

```text
f(l)<0             根             f(r)>0
   l------------------------------r
                 mid
若f(mid)<0：把左手移到mid
若f(mid)>0：把右手移到mid
```

这个图里函数朝上穿过轴，但程序不能只写“f(mid)>0就往左”。若函数朝下穿过，符号方向会反过来。正确做法是比较f(mid)与左端f(l)是否同号，同号就替换左端。

### 原理与边界

连续函数两端异号，保证内部至少有一个根，这是连续性而不是全局单调性提供的保证。一元三次函数在[-100,100]整体可能有拐弯，也有3个根，不能对全区间只二分一次。

P1024额外保证三根不同且根距>=1。因此先逐个检查整点根，再扫描每个(i,i+1)；在这种宽度内最多有一个根，端点异号时再局部夹逼。不是所有方程都能这样扫描：偶重根可能两边同号，根距太近也可能一格里挤入多个根。

### 实现与精度

```cpp
for(int i=1;i<=60;i++)
{
    double mid=(l+r)/2;
    if((f(l)>0)==(f(mid)>0)) l=mid;
    else r=mid;
}
```

这段要求初始端点严格异号、端点根已单独处理；若中点正好为零，后续也会朝这个根收缩。完整程序缓存左端函数值，避免重复计算。单个初始宽度1的区间缩60次，理论宽度为2^-60；实际受double精度限制，足以用于本题两位小数。固定次数比while(l!=r)可靠，因为浮点数通常不会刚好相等，也可能因舍入停止移动。

### 作用与使用场景

适合连续函数的局部求根，或实数上的单调可行性边界。先说明连续性/单调性依据，再讨论停止标准。输出两位不代表只迭代两次；内部应保留更高精度，最后再格式化。

## 08 五道例题与完整程序

下面先按例题手算，再对照代码。所有程序使用C++17和你的格式。代码目录只是方便单独编译，平时直接读本手册即可。

### P2249 有序列中查找元素

[洛谷原题](https://www.luogu.com.cn/problem/P2249)

输入本就单调不减，输出第一次出现的编号。用first_ge找到>=x的最左位置，再判断相等；未命中返回-1。对1、3、3、3、7、9查询3、4、10，答案2、-1、-1。单次O(log n)，总O(n+m log n)，空间O(n)。不需要排序，也不能把找到任意一个3当作正确。

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

int a[1000005];
int find_first(int n,int x)
{
    int l=1,r=n+1;
    while(l<r)
    {
        int mid=l+(r-l)/2;
        if(a[mid]>=x) r=mid;
        else l=mid+1;
    }
    if(l<=n&&a[l]==x) return l;
    return -1;
}
signed main()
{
    ios::sync_with_stdio(false);
    cin.tie(0);
    int n,m;
    cin>>n>>m;
    for(int i=1;i<=n;i++) cin>>a[i];
    for(int i=1;i<=m;i++)
    {
        int x;
        cin>>x;
        cout<<find_first(n,x)<<(i==m?'\n':' ');
    }
    return 0;
}
```

### P1102 A-B数对

[洛谷原题](https://www.luogu.com.cn/problem/P1102)

先排序，对每个B查B+C的左右边界。用1、1、2、2、2和C=1，左右边界3与6相减得3，两个B各贡献3，总6。边界返回尾后位置也能相减，不访问它。总O(n log n)，空间O(n)。

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

int a[200005];
signed main()
{
    int n,c,ans=0;
    cin>>n>>c;
    for(int i=1;i<=n;i++) cin>>a[i];
    sort(a+1,a+n+1);
    for(int i=1;i<=n;i++)
    {
        int x=a[i]+c;
        int l=lower_bound(a+1,a+n+1,x)-a;
        int r=upper_bound(a+1,a+n+1,x)-a;
        ans+=r-l;
    }
    cout<<ans<<'\n';
    return 0;
}
```

### P1873 砍树

[洛谷原题](https://www.luogu.com.cn/problem/P1873)

把答案范围设为0..最高树高，找最大可行锯高。20、15、10、17需要7时，mid=10可行→去11..20；mid=15可行→去16..20；mid=18不可行→去16..17；mid=16不可行→结束，ans仍是15。sum统计木材，ans记录已经验证过的候选，二者不能混用。时间O(n log H)，空间O(n)。

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

int a[1000005],n,m;
bool check(int h)
{
    int sum=0;
    for(int i=1;i<=n;i++)
    {
        if(a[i]>h) sum+=a[i]-h;
        if(sum>=m) return true;
    }
    return sum>=m;
}
signed main()
{
    cin>>n>>m;
    int high=0;
    for(int i=1;i<=n;i++)
    {
        cin>>a[i];
        high=max(high,a[i]);
    }
    int l=0,r=high,ans=-1;
    while(l<=r)
    {
        int mid=l+(r-l)/2;
        if(check(mid))
        {
            ans=mid;
            l=mid+1;
        }
        else r=mid-1;
    }
    cout<<ans<<'\n';
    return 0;
}
```

### P1824 进击的奶牛

[洛谷原题](https://www.luogu.com.cn/problem/P1824)

先排序牛舍，再二分最小间距。1、2、4、8、9放3头，d=3可行、d=4不可行，答案3。上界取最大位置减最小位置，不是坐标最大值本身。check最后cnt>=m就成功，不要求恰好m，因为能放更多时也能只放其中m头。时间O(n log n+n log V)，空间O(n)。

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

int a[100005],n,m;
bool check(int d)
{
    int last=a[1],cnt=1;
    for(int i=2;i<=n;i++)
    {
        if(a[i]-last>=d)
        {
            last=a[i];
            cnt++;
        }
    }
    return cnt>=m;
}
signed main()
{
    cin>>n>>m;
    for(int i=1;i<=n;i++) cin>>a[i];
    sort(a+1,a+n+1);
    int l=0,r=a[n]-a[1],ans=0;
    while(l<=r)
    {
        int mid=l+(r-l)/2;
        if(check(mid))
        {
            ans=mid;
            l=mid+1;
        }
        else r=mid-1;
    }
    cout<<ans<<'\n';
    return 0;
}
```

### P1024 一元三次方程求解

[洛谷原题](https://www.luogu.com.cn/problem/P1024)

先处理整点根，再扫描严格异号的小区间，避免边界根被重复计数或漏掉。x³-6x²+11x-6的三根是1、2、3，全部是整点，因此不应只依靠乘积<0去寻找。另一个例子根为-2.5、0.25、3.75，需要在局部区间二分。收集后排序、去重，再输出两位小数。扫描固定200格，每格最多60轮，存储仅少量根。

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

double a,b,c,d;
vector<double> roots;
double f(double x)
{
    return ((a*x+b)*x+c)*x+d;
}
signed main()
{
    cin>>a>>b>>c>>d;
    // 单独收集整点根，含-100和100。
    for(int i=-100;i<=100;i++)
    {
        if(fabs(f(i))<1e-9) roots.push_back(i);
    }
    for(int i=-100;i<100;i++)
    {
        double l=i,r=i+1,fl=f(l),fr=f(r);
        if(fabs(fl)<1e-9||fabs(fr)<1e-9) continue;
        if((fl>0)==(fr>0)) continue;
        for(int j=1;j<=60;j++)
        {
            double mid=(l+r)/2,fm=f(mid);
            if((fl>0)==(fm>0))
            {
                l=mid;
                fl=fm;
            }
            else r=mid;
        }
        roots.push_back((l+r)/2);
    }
    sort(roots.begin(),roots.end());
    vector<double> ans;
    for(double x:roots)
    {
        if(fabs(x)<1e-8) x=0;
        if(ans.empty()||fabs(x-ans.back())>1e-6) ans.push_back(x);
    }
    for(int i=0;i<(int)ans.size();i++)
        cout<<fixed<<setprecision(2)<<ans[i]<<(i+1==(int)ans.size()?'\n':' ');
    return 0;
}
```

## 10 复习与延伸

先遮住代码，口述“我找的是什么边界”“check的真代表什么”“这一步排除谁”。能回答这三句话，再写循环。

练习一：手写第一个>x的位置，只把first_ge条件从>=改成>是否足够？答：在同一套区间约定下足够。

练习二：最后一个<=x的位置如何求？答：upper_bound返回位置减1；可能得到0，仍要判断是否有合法元素。

练习三：若目标是找最小可行值、真假为假→真，怎么改ans记录法？答：可行时记ans并r=mid-1，不可行时l=mid+1。

练习四：砍树和奶牛哪个check用了贪心？答：奶牛。砍树只需按固定高度直接统计。

练习五：f(x)=x²在[-1,1]两端同号，是否没有根？答：有根0；“异号保证有根”不能倒过来读成“同号保证没根”。
