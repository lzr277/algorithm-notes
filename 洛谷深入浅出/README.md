# 洛谷《深入浅出》学习记录

## 递推与递归

- [学习手册](01-递推与递归/学习手册.md)：先学递推、递归、记忆化的概念与简单例子，再进入图片中的六个例题。
- [动画学习手册](01-递推与递归/index.html)：下载后用浏览器打开，离线使用；包含六组可单步播放的图解、手册全文与代码。
- [知识点全解](01-递推与递归/知识点全解.md)：覆盖图片全部节点，12 节分别讲概念、原理、实现与使用场景；包含独立卡特兰数专题。
- [学习日志](学习日志.md)：记录学习、复盘与验证情况。

建议先完成手册的“入门自测”，再按“看图 → 手推 → 独立写代码 → 做题 → 记录错因”学习。入门可运行 [00-入门.cpp](01-递推与递归/代码/00-入门.cpp)，输入 0..20，依次输出求和、阶乘和三种斐波那契结果。GitHub 文件页不执行 HTML，请先下载仓库，再双击动画学习手册。

后续学习内容统一放在本目录，完成后提交并推送当前 GitHub 仓库；具体约定见 [AGENTS.md](AGENTS.md)。

维护动画版：修改学习手册后，在章节目录运行 `python render_handbook.py`（需 `pip install markdown`）；脚本保留原有动画并更新正文和目录。

代码约定：统一使用 `bits/stdc++.h`、`#define int long long`、`signed main()`，大括号单独换行。此处的 `int` 会由宏展开为 `long long`；函数片段放在同样的头文件与宏定义之后使用。

- [带括号的递归解析笔记](01-递推与递归/带括号的递归解析.md)：全局下标、父层跳过右括号、完整代码与逐层模拟。总手册开头已有章节目录。
