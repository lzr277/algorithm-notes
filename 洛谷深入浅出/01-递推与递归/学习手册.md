# 递推与递归：从零开始的 C++ 学习手册

先学基础，再做六道例题。默认你会变量、循环、数组和函数；所有程序使用 C++17。动画版与本手册配套，双击同目录的 `index.html` 即可离线学习。

## 先认识三个概念

| 方法 | 直观理解 | 谁决定先算什么 | 常见工具 |
|---|---|---|---|
| 递推 | 从已知答案，一格一格推出后面的答案 | 程序员安排循环顺序 | 循环、数组 |
| 递归 | 函数把任务交给规模更小的自己，等结果回来再处理 | 函数调用关系 | 终止条件、调用栈 |
| 记忆化搜索 | 递归时带一个答案本，遇到旧问题直接查 | 仍由递归按需访问 | 递归、缓存数组 |

递推和递归可以计算同一个数学关系。递归是一种程序组织方式；记忆化搜索是在递归搜索中保存状态答案的技巧。判断能不能缓存，要看“同一个状态的答案是否固定”，不能只看函数有没有重复调用。

## 入门 1：递推——像推倒一排多米诺骨牌

任务：求 1 到 n 的和。定义 s[i] 为前 i 个正整数的和。

```text
起点 s[0]=0
       +1       +2       +3        +4
   0 ─────→ 1 ─────→ 3 ─────→ 6 ─────→ 10
```

关系是 `s[i]=s[i-1]+i`。三个步骤：先定义状态，找出初始条件，再确定计算顺序。循环到 i 时，必须已经知道 s[i-1]。

```cpp
#include <iostream>
using namespace std;
int main() {
    int n; cin >> n; // 本例约定 0 <= n <= 1000000
    long long s = 0;
    for (int i = 1; i <= n; ++i) s += i;
    cout << s << '\n';
}
```

这个版本只保留前一个答案，时间 O(n)，额外空间 O(1)。若要查询所有前缀和，就保存数组。n=0 时循环不执行，答案仍为 0。循环结束的依据是 i 每次增加并最终超过 n。

**试一试：** 不运行程序，写出 n=5 时 s 的每次变化。答案：0、1、3、6、10、15。

## 入门 2：递归——把大盒子拆成小盒子

任务：计算阶乘。`n! = n × (n-1)!`，并且 `0! = 1`。把 `fact(n)` 理解成一个承诺：它会返回 n 的阶乘。

```cpp
long long fact(int n) { // 0 <= n <= 20
    if (n == 0) return 1;       // 递归出口
    return n * fact(n - 1);     // 缩小问题，等返回后再乘
}
```

```text
向下调用：fact(4) → fact(3) → fact(2) → fact(1) → fact(0)
等待的乘法： 4×?       3×?       2×?       1×?        返回1
向上返回：     24   ←    6   ←    2   ←    1    ←     1
```

调用 `fact(4)` 时，4 不会消失。系统在调用栈里记下“还要乘 4”。最深层返回后，一层一层完成这些未做完的工作。这就是“先递下去，再归回来”。动画中观察进入和返回两个方向。

检查递归的三件事：出口是什么？参数是否越来越接近出口？拿到子问题答案以后怎样组成当前答案？仅有出口不够，`fact(n+1)` 永远走不到 n=0。负数也不符合本例的输入约定。

时间 O(n)，调用栈空间 O(n)。递归不会自动省时间或空间；深度很大时可能栈溢出。20! 能放入有符号 long long，21! 就不能。

**试一试：** 为什么不能写成 `return fact(n);`？因为状态没有缩小，函数不断调用自身直到栈耗尽。

## 入门 3：同一个斐波那契，三种写法

本节约定 `F(0)=0, F(1)=1`，`F(n)=F(n-1)+F(n-2)`。这里只用 0≤n≤90，以免 long long 溢出。注意数楼梯的初始值与这里不同。

### 朴素递归：表达直接，但会重复工作

```cpp
long long fib(int n) {
    if (n <= 1) return n;
    return fib(n - 1) + fib(n - 2);
}
```

```text
                     F(5)
                  /        \
               F(4)        F(3) ← 又算一次
              /    \       /   \
           F(3)   F(2)   F(2)  F(1)
           /  \
        F(2) F(1)   ……相同小问题反复出现
```

F(5)=5，但函数一共进入 15 次。每次重新展开 F(3)，都会重算相同的子树。时间为指数级（上界 O(2^n)），调用栈深度 O(n)。实际体验请先只试 n≤30，不要直接测试 n=90。

### 记忆化搜索：给每个状态一个抽屉

```cpp
long long memo[91];
bool seen[91]{};
long long fibMemo(int n) {
    if (n <= 1) return n;
    if (seen[n]) return memo[n]; // 先查抽屉
    memo[n] = fibMemo(n - 1) + fibMemo(n - 2);
    seen[n] = true;             // 算完后才标记
    return memo[n];
}
```

第一次 F(3) 计算完，把 2 放入编号 3 的抽屉；第二次需要 F(3) 时直接取出。**缓存的是状态 n 的答案，不是整条调用路径。** 对固定问题，n 相同答案就相同，所以能复用。

用 seen 区分“没算过”和“答案为 0”；不能普遍用 `memo[n]!=0` 判断已计算。若函数依赖额外条件，缓存键必须包含这些条件。例如网格换了障碍位置，旧答案就应清空或重新建表。存在环的状态关系还需要额外处理，不能直接照搬本模板。

每个非边界状态只展开一次，每次最多两条转移，因此时间 O(n)，缓存与调用栈合计 O(n)。重复命中缓存仍算函数调用，但不再展开子树。

### 循环递推：按编号主动填表

```cpp
long long fibLoop(int n) {
    if (n <= 1) return n;
    long long a = 0, b = 1;
    for (int i = 2; i <= n; ++i) {
        long long next = a + b;
        a = b;
        b = next;
    }
    return b;
}
```

每轮开始时 a=F(i-2)、b=F(i-1)。先计算 next，再移动 a、b，否则可能覆盖仍要用的旧值。时间 O(n)，额外空间 O(1)。

| 实现 | n=5 的答案 | 时间 | 额外空间 | 适用观察 |
|---|---|---|---|---|
| 朴素递归 | 5 | 指数级 | O(n) | 展示分解，规模很小 |
| 记忆化递归 | 5 | O(n) | O(n) | 状态依赖复杂，适合按需探索 |
| 循环递推 | 5 | O(n) | O(1) | 顺序清楚，可滚动保存 |

这里的空间包括调用栈；整数加法按固定宽度 O(1) 计。递推与记忆化也是以后学习动态规划的两种常见实现方式。现在先掌握“状态、依赖、边界、顺序”，不用急着背术语。

# 对照图片：六个经典例题

以下为原创讲解与实现。题意仅概括，提交前阅读题目原页；不是题面全文复制。P1028 采用洛谷当前修订的“数列”表述，和旧书的拼接数字表述不同，递推关系一致。

## P1255 数楼梯：从最后一步倒推

[洛谷原题](https://www.luogu.com.cn/problem/P1255)

定义 f[i]：到达第 i 级的走法数。把最后一步当作一扇门：从 i-1 跨一步，或者从 i-2 跨两步。两组走法互不重叠，所以相加。

`f[i]=f[i-1]+f[i-2]`，`f[0]=1, f[1]=1`。f[0]=1 表示“什么也不走”的一种方案，它让跨两步到第 2 级的方案也被计入。

```text
第 i-2 级 ─── 跨2级 ───┐
                        ├──→ 第 i 级
第 i-1 级 ─── 跨1级 ───┘
级数       0  1  2  3  4  5
方案数     1  1  2  3  5  8
```

这是斐波那契型递推，但 f[n]=F(n+1)，不要照抄 F(0)=0。题目 n 最大 5000，必须高精度。下面用倒序十进制数组做加法：个位先加、向高位进位。每位最多 9+9+1=19。

若答案位数为 D，总时间 O(nD)，滚动存储 O(D)；这里 D 随 n 线性增长。自测：1→1，2→2，5→8。练习：允许跨 1、2、3 级时怎样改式子？提示：三个来源，越界项不计。

### 完整 C++17 程序

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;
vector<int> add(const vector<int>& a, const vector<int>& b) {
    vector<int> c;
    int carry = 0;
    for (size_t i = 0; i < max(a.size(), b.size()) || carry; ++i) {
        int x = carry;
        if (i < a.size()) x += a[i];
        if (i < b.size()) x += b[i];
        c.push_back(x % 10);
        carry = x / 10;
    }
    return c;
}
int main() {
    int n; cin >> n;
    vector<int> a{1}, b{1}; // f[0], f[1]
    for (int i = 2; i <= n; ++i) {
        auto c = add(a, b);
        a = b; b = c;
    }
    for (auto it = b.rbegin(); it != b.rend(); ++it) cout << *it;
    cout << '\n';
}
```

## P1002 过河卒：在棋盘上填表

[洛谷原题](https://www.luogu.com.cn/problem/P1002)

定义 dp[x][y]：从 (0,0) 到 (x,y) 的合法路径数。最后一步只能来自 (x-1,y) 或 (x,y-1)，所以可走点填两个来源之和；禁止点直接填 0。

```text
     上方 dp[x-1][y]
             ↓
左方 → 当前格 = 上方 + 左方
```

先标记马自身和八个日字跳跃位置，再设置起点。如果先填起点，随后错误覆盖禁区，就可能制造不存在的路径。坐标范围是 0..n、0..m，包含端点，因此数组至少 21×21。第一行和第一列只有一个方向的来源；不要一律初始化为 1，因为中间可能被阻断。

时间 O(nm)，空间 O(nm)。无障碍 20×20 的路径数为 C(40,20)=137846528820，int 不够，使用 long long。自测：`6 6 3 3`→6；`2 2 1 1`→0。练习：在动画中移动马，解释为什么禁区之后仍可能绕路到达。

### 完整 C++17 程序

```cpp
#include <iostream>
using namespace std;
long long dp[21][21]{};
bool blocked[21][21]{};
int main() {
    int n,m,hx,hy; cin >> n >> m >> hx >> hy;
    int dx[]={0,1,1,-1,-1,2,2,-2,-2};
    int dy[]={0,2,-2,2,-2,1,-1,1,-1};
    for(int k=0;k<9;++k) {
        int x=hx+dx[k], y=hy+dy[k];
        if(x>=0 && x<=n && y>=0 && y<=m) blocked[x][y]=true;
    }
    for(int x=0;x<=n;++x) for(int y=0;y<=m;++y) {
        if(blocked[x][y]) continue;
        if(x==0 && y==0) { dp[x][y]=1; continue; }
        if(x>0) dp[x][y]+=dp[x-1][y];
        if(y>0) dp[x][y]+=dp[x][y-1];
    }
    cout << dp[n][m] << '\n';
}
```

## P1044 栈：把合法操作拆成两段

[洛谷原题](https://www.luogu.com.cn/problem/P1044)

把入栈记为左括号，出栈记为右括号。栈不能为空时出栈，所以任意前缀的出栈次数不能多于入栈次数。n=3 时 5 种合法括号串为 `((()))`、`(()())`、`(())()`、`()(())`、`()()()`。

```text
整体 = ( 内部合法序列 A ) 外部合法序列 B
         k 对             n-1-k 对
```

按第一个左括号匹配的右括号划分，每个合法序列的拆法唯一。内部和外部独立选择，方案数相乘；枚举 k 的各类互斥，最后相加：

`C[n] = Σ C[k] * C[n-1-k]`，k=0..n-1，`C[0]=1`。空序列有一种，不能设成 0。这就是卡特兰数。固定输入顺序时，每个可行输出顺序对应唯一的合法进出栈过程，所以可以数这些括号串。

时间 O(n²)，空间 O(n)。n≤18，long long 足够。自测：1→1、3→5、18→477638700。练习：手算 C[4]=5+2+2+5=14，并解释每一项从哪里来。

### 完整 C++17 程序

```cpp
#include <iostream>
using namespace std;
int main() {
    int n; cin >> n;
    long long c[19]{}; c[0]=1;
    for(int i=1;i<=n;++i)
        for(int k=0;k<i;++k) c[i]+=c[k]*c[i-1-k];
    cout << c[n] << '\n';
}
```

## P1028 数的计算：递归分解与循环实现

[洛谷原题](https://www.luogu.com.cn/problem/P1028)

令 f(n) 为从 n 开始的合法数列数量。可以马上停止（贡献 1），也可以选下一个数 k，1≤k≤⌊n/2⌋，之后全部交给 f(k)。

`f(n)=1+Σ f(k)`，k=1..⌊n/2⌋。例如 n=6：停止；接 1；接 2 后可停止或接 1；接 3 后可停止或接 1。总数 1+1+2+2=6。

```text
6
├─ 停止： [6]
├─ 1：    [6,1]
├─ 2：    [6,2]， [6,2,1]
└─ 3：    [6,3]， [6,3,1]
```

递归函数可写 `ans=1; for(k=1;k<=n/2;++k) ans+=solve(k);`，n=1 时循环为空，返回 1。k 总小于 n，所以会终止；加缓存可避免重复。下面按 n 从小到大递推，同样体现子问题思想。

此版时间 O(n²)，空间 O(n)。n≤1000，long long 足够。自测：1→1、6→6、10→14。进阶：利用前缀和把总时间降到 O(n)，但先独立写出基础版。

### 完整 C++17 程序

```cpp
#include <iostream>
#include <vector>
using namespace std;
int main() {
    int n; cin >> n;
    vector<long long> f(n+1,0);
    for(int i=1;i<=n;++i) {
        f[i]=1; // 只保留当前数，立即停止
        for(int k=1;k<=i/2;++k) f[i]+=f[k];
    }
    cout << f[n] << '\n';
}
```

## P1464 Function：给三个参数建立缓存

[洛谷原题](https://www.luogu.com.cn/problem/P1464)

先把题目定义翻译成四个分支，顺序不能改变：

1. 任一参数≤0：返回 1。
2. 否则任一参数>20：转成 w(20,20,20)。
3. 否则 a<b<c：使用三个子问题相加减的公式。
4. 其他情况：使用四个子问题相加减的公式。

第二条必须在第一条之后。例如 (-1,100,100) 应返回 1。只有确认三个参数都在 1..20 后才访问缓存；输入本身可能很大或很小，用 long long 读取，不能直接拿输入当下标。

```text
w(a,b,c) → 边界检查 → 查 memo[a][b][c]
                          ├─ 已有：直接返回
                          └─ 没有：递归计算 → 保存 → 返回
```

最多 20³ 个正参数状态，每个展开常数条转移，预处理总量 O(20³)，T 次查询合计 O(20³+T)。缓存空间 O(21³)，活动递归链 O(20)（参数和下降，常数上界约 60 层）。答案可复用，多组输入不要每行清空。仅三项全是 -1 才结束，输出保留原输入和规定空格。

自测：`1 1 1`→2，`20 20 20`→1048576，`-1 100 100`→1。练习：指出每个分支如何让递归走向边界。

### 完整 C++17 程序

```cpp
#include <iostream>
using namespace std;
long long memo[21][21][21]{};
bool seen[21][21][21]{};
long long w(long long a,long long b,long long c) {
    if(a<=0 || b<=0 || c<=0) return 1;
    if(a>20 || b>20 || c>20) return w(20,20,20);
    if(seen[a][b][c]) return memo[a][b][c];
    long long ans;
    if(a<b && b<c)
        ans=w(a,b,c-1)+w(a,b-1,c-1)-w(a,b-1,c);
    else
        ans=w(a-1,b,c)+w(a-1,b-1,c)+w(a-1,b,c-1)-w(a-1,b-1,c-1);
    seen[a][b][c]=true;
    return memo[a][b][c]=ans;
}
int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    long long a,b,c;
    while(cin>>a>>b>>c) {
        if(a==-1 && b==-1 && c==-1) break;
        cout<<"w("<<a<<", "<<b<<", "<<c<<") = "<<w(a,b,c)<<'\n';
    }
}
```

## P1928 外星密码：每层递归负责一对括号

[洛谷原题](https://www.luogu.com.cn/problem/P1928)

本题像拆套娃。函数 decode 负责读取当前层，遇见字母直接收集，遇见 `[` 先读完整重复次数，再递归解出内部字符串；遇到 `]` 消费它并返回。

```text
输入 A[2B[3C]]
内层 [3C] → CCC
中层 [2BCCC] → BCCCBCCC
外层 → ABCCCBCCC
```

共享下标 pos 就像所有人传递的阅读书签。函数返回后，书签必须在它负责的右括号之后，否则父层可能提前结束。次数可能是两位数，用 while 连续读数字；`k=k*10+数字`，不能只读一个字符。

终止条件是读到本层右括号或输入结束；每次循环都会前进下标。题目保证合法输入，因此本例不负责修复不匹配括号。最大嵌套深度 10，输出长度最多 20000。

设输入长 N、最终输出长 L、深度 H，此实现保守时间 O(N+HL)，因为每层会复制子串；额外空间保守 O(N+HL+H)，含输入、各层字符串和调用栈。自测：`[3AB]`→ABABAB、`A[2B[3C]]`→ABCCCBCCC。练习：把数字读取错误写成只读一位，用 `[12A]` 检查会发生什么。

### 完整 C++17 程序

```cpp
#include <iostream>
#include <string>
#include <cctype>
using namespace std;
string s;
size_t pos=0;
string decode() {
    string result;
    while(pos<s.size()) {
        char ch=s[pos++];
        if(ch==']') return result;
        if(ch=='[') {
            int count=0;
            while(pos<s.size() && isdigit(static_cast<unsigned char>(s[pos])))
                count=count*10+(s[pos++]-'0');
            string inner=decode();
            for(int i=0;i<count;++i) result+=inner;
        } else result+=ch;
    }
    return result;
}
int main() {
    cin>>s;
    cout<<decode()<<'\n';
}
```

## 如何安排学习

第一轮只读三个入门概念并手写简单程序；第二轮做数楼梯和过河卒，练状态与边界；第三轮做栈和数的计算，练分类计数；第四轮做 Function 和外星密码，练缓存与嵌套递归。每次复习先遮住代码，自己写出状态和关系式。

常见错误：初始值照抄、整型溢出、禁止格没清零、递归不缩小、缓存键缺参数、下标越界、忘记多位数字、右括号未消费。遇到错误先用最小例子手推。
