## 先认识三个概念

| 方法    | 直观理解                    | 谁决定先算什么   | 常见工具     |
| ----- | ----------------------- | --------- | -------- |
| 递推    | 从已知答案，一格一格推出后面的答案       | 程序员安排循环顺序 | 循环、数组    |
| 递归    | 函数把任务交给规模更小的自己，等结果回来再处理 | 函数调用关系    | 终止条件、调用栈 |
| 记忆化搜索 | 递归时带一个答案本，遇到旧问题直接查      | 仍由递归按需访问  | 递归、缓存数组  |

递推和递归可以计算同一个数学关系。递归是一种程序组织方式；记忆化搜索是在递归搜索中保存状态答案的技巧。判断能不能缓存，要看“同一个状态的答案是否固定”，不能只看函数有没有重复调用。

## 入门 1：递推——像推倒一排多米诺骨牌

任务：求 1 到 n 的和。定义 s[i] 为前 i 个正整数的和。

```text
起点 s[0]=0
       +1       +2       +3        +4
   0 ─────→ 1 ─────→ 3 ─────→ 6 ─────→ 10
```

关系是 `s[i]=s[i-1]+i`。三个步骤：先定义状态，找出初始条件，再确定计算顺序。循环到 i 时，必须已经知道 s[i-1]。

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;
signed main()
{
    int n;
    cin>>n;// 本例约定 0 <= n <= 1000000
    int s=0;
    for(int i=1;i<=n;++i)
        s+=i;
    cout<<s<<'\n';
    return 0;
}
```

这个版本只保留前一个答案，时间 O(n)，额外空间 O(1)。若要查询所有前缀和，就保存数组。n=0 时循环不执行，答案仍为 0。循环结束的依据是 i 每次增加并最终超过 n。

**试一试：** 不运行程序，写出 n=5 时 s 的每次变化。答案：0、1、3、6、10、15。

<a id="section-4"></a>

## 入门 2：递归——把大盒子拆成小盒子

任务：计算阶乘。`n! = n × (n-1)!`，并且 `0! = 1`。把 `fact(n)` 理解成一个承诺：它会返回 n 的阶乘。

```cpp
int fact(int n)
{                           // 0 <= n <= 20
    if(n==0) return 1;// 递归出口
    return n*fact(n-1);// 缩小问题，等返回后再乘
}
```

```text
向下调用：fact(4) → fact(3) → fact(2) → fact(1) → fact(0)
等待的乘法： 4×?       3×?       2×?       1×?        返回1
向上返回：     24   ←    6   ←    2   ←    1    ←     1
```

调用 `fact(4)` 时，4 不会消失。系统在调用栈里记下“还要乘 4”。最深层返回后，一层一层完成这些未做完的工作。这就是“先递下去，再归回来”。动画中观察进入和返回两个方向。

检查递归的三件事：出口是什么？参数是否越来越接近出口？拿到子问题答案以后怎样组成当前答案？仅有出口不够，`fact(n+1)` 永远走不到 n=0。负数也不符合本例的输入约定。

时间 O(n)，调用栈空间 O(n)。递归不会自动省时间或空间；深度很大时可能栈溢出。20! 能放入有符号 long long，21! 就不能。

**试一试：** 为什么不能写成 `return fact(n);`？因为状态没有缩小，函数不断调用自身直到栈耗尽。

<a id="section-5"></a>

## 入门 3：同一个斐波那契，三种写法

本节约定 `F(0)=0, F(1)=1`，`F(n)=F(n-1)+F(n-2)`。这里只用 0≤n≤90，以免 long long 溢出。注意数楼梯的初始值与这里不同。

### 朴素递归：表达直接，但会重复工作

```cpp
int fib(int n)
{
    if(n<=1) return n;
    return fib(n-1)+fib(n-2);
}
```

```text
                     F(5)
                  /        \
               F(4)        F(3) ← 又算一次
              /    \       /   \
           F(3)   F(2)   F(2)  F(1)
           /  \
        F(2) F(1)   ……相同小问题反复出现
```

F(5)=5，但函数一共进入 15 次。每次重新展开 F(3)，都会重算相同的子树。时间为指数级（上界 O(2^n)），调用栈深度 O(n)。实际体验请先只试 n≤30，不要直接测试 n=90。

### 记忆化搜索：给每个状态一个抽屉

```cpp
int memo[91];
bool seen[91]{};
int fibMemo(int n)
{
    if(n<=1) return n;
    if(seen[n]) return memo[n];// 先查抽屉
    memo[n]=fibMemo(n-1)+fibMemo(n-2);
    seen[n]=true;// 算完后才标记
    return memo[n];
}
```

第一次 F(3) 计算完，把 2 放入编号 3 的抽屉；第二次需要 F(3) 时直接取出。**缓存的是状态 n 的答案，不是整条调用路径。** 对固定问题，n 相同答案就相同，所以能复用。

用 seen 区分“没算过”和“答案为 0”；不能普遍用 `memo[n]!=0` 判断已计算。若函数依赖额外条件，缓存键必须包含这些条件。例如网格换了障碍位置，旧答案就应清空或重新建表。存在环的状态关系还需要额外处理，不能直接照搬本模板。

每个非边界状态只展开一次，每次最多两条转移，因此时间 O(n)，缓存与调用栈合计 O(n)。重复命中缓存仍算函数调用，但不再展开子树。

### 循环递推：按编号主动填表

```cpp
int fibLoop(int n)
{
    if(n<=1) return n;
    int a=0,b=1;
    for(int i=2;i<=n;++i)
    {
        int next=a+b;
        a=b;
        b=next;
    }
    return b;
}
```

每轮开始时 a=F(i-2)、b=F(i-1)。先计算 next，再移动 a、b，否则可能覆盖仍要用的旧值。时间 O(n)，额外空间 O(1)。

| 实现    | n=5 的答案 | 时间   | 额外空间 | 适用观察          |
| ----- | ------- | ---- | ---- | ------------- |
| 朴素递归  | 5       | 指数级  | O(n) | 展示分解，规模很小     |
| 记忆化递归 | 5       | O(n) | O(n) | 状态依赖复杂，适合按需探索 |
| 循环递推  | 5       | O(n) | O(1) | 顺序清楚，可滚动保存    |

这里的空间包括调用栈；整数加法按固定宽度 O(1) 计。递推与记忆化也是以后学习动态规划的两种常见实现方式。现在先掌握“状态、依赖、边界、顺序”，不用急着背术语。

## K01 递推思想

### 概念

递推是根据已经确定的状态值，按依赖顺序计算新状态。状态是对一个子问题的精确描述，例如“到达第 i 级的走法数”，而不是含糊的“答案”。递推不一定只依赖前一项，也可以依赖两个更早项、一整段区间或二维表中的多个格子。

### 原理

像沿着已经铺好的砖走：每次落脚前，那块砖必须存在。若 f[i] 只依赖下标小于 i 的值，从小到大即可；若依赖右侧状态，就可能需要倒着算。正确性通常用数学归纳法说明：初始值正确；假设所依赖的状态正确，转移又完整且无重复，则新状态也正确。

### C++ 实现

用求和作为最简单的例子：s[i]=s[i-1]+i，s[0]=0。

```cpp
int prefixSum(int n)
{ // 0 <= n <= 1000000
    int answer=0;
    for(int i=1;i<=n;++i)
        answer+=i;
    return answer;
}
```

手推 n=4：0→1→3→6→10。时间 O(n)，空间 O(1)。把循环写成从 n 到 1 累加仍能算求和，是因为加法可交换；不能据此认为所有状态表都能倒着填。

### 作用与使用场景

适合数列计算、网格计数、前缀信息和依赖顺序清楚的动态规划。优点是没有递归栈开销，容易控制空间。若某状态的依赖尚未求出，就应重新安排顺序，不能拿数组默认的 0 当作它的答案。

## K02 递推式与递推式的推导

### 概念

递推式是当前状态与较小状态之间的等式，是“怎样由已有答案得到新答案”的数学描述。推导不是猜几个数找规律，而是解释每一种合法方案从哪里来。

### 原理

对计数问题常用“看最后一步”：到第 i 级的方案按最后跨 1 级或 2 级划分。这两个类别互斥，并且覆盖全部方案。删除最后一步后分别对应到 i-1、i-2 的方案，所以 f[i]=f[i-1]+f[i-2]。

```text
所有到第 i 级的走法
├─ 最后跨 1 级 ← 到 i-1 的任意走法
└─ 最后跨 2 级 ← 到 i-2 的任意走法
```

不同情况任选其一，用加法；多个独立部分都要选择，用乘法。卡特兰数会同时用到这两条规则。若类别重叠就不能直接加；若前后选择互相限制，也不能不加分析就乘。

### C++ 实现

```cpp
int stairsSmall(int n)
{ // 0 <= n <= 90
    vector<int>f(n+2,0);
    f[0]=f[1]=1;
    for(int i=2;i<=n;++i)
        f[i]=f[i-1]+f[i-2];
    return f[n];
}
```

n=3 时 `[1,1,1]`、`[1,2]`、`[2,1]` 共 3 种；按最后一步分成 2+1。时间 O(n)，空间 O(n)。这里仅用于小范围演示，P1255 的 n≤5000 要用后文的高精度实现。

### 作用与使用场景

看到“方案数”“最后一次操作”“选择一个分界点”时，可尝试分类建立递推式。写代码前先回答：有没有漏掉一种情况？某个方案会不会被算两次？对于最优值问题，同样可分类，但组合操作可能改为 min 或 max，而不是求和。

## K03 初始条件与边界条件

### 概念

初始条件是直接已知、不再由转移计算的状态。边界条件还包括越界、不合法、障碍和递归停止情形。二者决定整条计算链从哪里开始、哪些地方不能走。

### 原理

只写 f[i]=f[i-1]+f[i-2] 无法唯一确定数列：初值 0、1 产生斐波那契；初值 1、1 产生楼梯计数。空方案常贡献 1，因为它是“完成零个选择”的一种方式；不存在的方案贡献 0。不能凭直觉把所有边界都写成 0 或 1。

```text
F(0)=0：斐波那契数列的定义
楼梯 f(0)=1：在地面什么也不走，是一种走法
卡特兰 C(0)=1：空括号串是一种合法结构
障碍 dp(x,y)=0：没有合法路径能经过这里
```

### C++ 实现

```cpp
int stairsWithBoundary(int n)
{                       // -1 <= n <= 90
    if(n<0) return 0;// 不可能到达负级数
    if(n<=1) return 1;
    int a=1,b=1;
    for(int i=2;i<=n;++i)
    {
        int next=a+b;
        a=b;
        b=next;
    }
    return b;
}
```

例如把 f[0] 错设为 0，则 f[2]=1，只算到 `[1,1]`，漏掉 `[2]`。正确版本时间 O(n)，空间 O(1)。

### 作用与使用场景

每道递推、递归题都应先手推最小输入；网格题还应检查第一行、第一列、起点和终点。初值必须由状态的含义解释，而不是为了让某个样例通过临时调整。

## K04 斐波那契数列

### 概念

斐波那契数列规定 F(0)=0、F(1)=1，之后每项是前两项之和：0、1、1、2、3、5、8、13……“斐波那契型”指相同或相近的依赖关系，初值和答案下标可能不同。

### 原理

F(n) 只需要 F(n-1)、F(n-2)，所以算完新项后，更早项可以丢弃。这是滚动保存状态的原理。楼梯计数 f(n)=F(n+1)，而不是 F(n)；必须先对齐初始条件。

### C++ 实现

```cpp
int fibonacci(int n)
{ // 0 <= n <= 92
    if(n<=1) return n;
    int a=0,b=1;
    for(int i=2;i<=n;++i)
    {
        int next=a+b;// 此时 a=F(i-2), b=F(i-1)
        a=b;
        b=next;
    }
    return b;
}
```

时间 O(n)，空间 O(1)。F(92)=7540113804746346429 仍在有符号 long long 内，F(93) 超出；楼梯 f(91)=F(92) 仍能存下，但教学函数保守限定为 n≤90。若答案要求取模，则每次加法后取模；若要求完整大整数，则改用高精度，不能擅自取模。

### 作用与使用场景

固定步长为 1/2 的路径计数、某些铺砖模型和相邻状态有关的序列经常出现这种结构。先推关系再识别数列，不能看到“楼梯”“兔子”等词就套公式。大下标可进一步学矩阵快速幂或快速倍增，本章先掌握线性算法。

## K05 二维递推

### 概念

二维状态由两个量共同确定。dp[x][y] 不是两个答案，而是“到坐标 (x,y) 的路径数”这一个答案。两个坐标缺少任意一个都无法区分子问题。

### 原理

只准向下、向右时，进入当前格的最后一步只能来自上方或左方。这些来源互斥：dp[x][y]=dp[x-1][y]+dp[x][y-1]。按行从上到下、行内从左到右填表，两个来源都已经算过。障碍格为 0，起点无障碍时为 1。

```text
无障碍 3×3 个格点（目标坐标为 2,2）
1 → 1 → 1
↓   ↓   ↓
1 → 2 → 3
↓   ↓   ↓
1 → 3 → 6
```

### C++ 实现

```cpp
int gridWays(int n,int m,const vector<vector<bool>>&blocked)
{
    // 0 <= n,m <= 20；blocked 的大小必须是 (n+1) × (m+1)
    vector<vector<int>>dp(n+1,vector<int>(m+1,0));
    for(int x=0;x<=n;++x)
    {
        for(int y=0;y<=m;++y)
        {
            if(blocked[x][y]) continue;
            if(x==0&&y==0)
            {
                dp[x][y]=1;
                continue;
            }
            if(x>0) dp[x][y]+=dp[x-1][y];
            if(y>0) dp[x][y]+=dp[x][y-1];
        }
    }
    return dp[n][m];
}
```

无障碍目标 (2,2) 得 6；把中间 (1,1) 设为障碍得 2。时间 O((n+1)(m+1))，空间同阶。P1002 只需先把马与控制点转换为 blocked，即可复用这一过程。

### 作用与使用场景

网格路线、两个序列前缀的关系、两个资源维度的动态规划都可能需要二维状态。但二维数组不等于网格题，也不保证都能按行填；必须检查真实依赖。若允许四向自由走动，可能有环，不能直接使用这个递推。

## K06 栈与“栈题递推式”的推导

### 概念

栈是后进先出的容器，像叠盘子：后放上的先拿走。push 入栈，pop 弹出，top 查看顶部；栈空时不能 pop 或 top。P1044 数的是固定输入顺序下可产生多少种输出顺序。

### 原理

把入栈画作上坡、出栈画作下坡，当前高度就是栈内元素数，不能小于 0。也可记成左右括号。合法操作序列满足“总数匹配、每个前缀出栈不多于入栈”。

```text
操作： 入1 入2 出2 入3 出3 出1
栈高：  1   2   1   2   1   0
输出：          2       3   1
括号： (   (   )   (   )   )
```

推导时找到第一次入栈与它配对的出栈：`(A)B`。内部 A 有 k 对，后面 B 有 n-1-k 对。同一 k 下 A、B 独立组合所以相乘；不同 k 互斥所以相加。每个合法串都有唯一的第一次匹配位置，保证不重不漏。这导出下一节的卡特兰递推。

### C++ 实现

先用真实栈验证一个候选出栈顺序，理解模型；计数程序见 K07 和 P1044。

```cpp
bool validPopOrder(const vector<int>&out)
{ // 输入顺序固定为 1..n
    int n=(int)out.size(),next=1;
    stack<int>st;
    for(int wanted : out)
    {
        if(wanted<1||wanted>n) return false;
        while((st.empty()||st.top()!=wanted)&&next<=n)
            st.push(next++);
        if(st.empty()||st.top()!=wanted) return false;
        st.pop();
    }
    return true;
}
```

`{2,3,1}` 合法，`{3,1,2}` 不合法：3 弹出后顶部是 2，无法跳过它拿到 1。每个数至多进出栈一次，验证时间 O(n)、空间 O(n)。

### 作用与使用场景

栈用于括号匹配、撤销操作、表达式处理和模拟递归调用。栈题不是一律用卡特兰数：只有输入顺序固定、元素互异、容量足够且没有额外约束时，P1044 的计数模型才直接适用；栈容量受限时要额外记录高度。

## K07 卡特兰数：概念、推导、实现与识别

### 概念

卡特兰数是一组反复出现在“有嵌套结构、可唯一拆成左右两部分”的计数问题中的整数，记为 C_n。本章用合法括号解释：C_n 是 n 对括号的合法排列数量。前几项（从 n=0 开始）是 1、1、2、5、14、42、132。

n=3 时合法串恰好五个：`((()))`、`(()())`、`(())()`、`()(())`、`()()()`。`())(()` 不合法，因为第三个位置时右括号比左括号多，等价于空栈出栈。

### 原理：从唯一分解得到卷积递推

任何非空合法括号串都能唯一写成 `(A)B`。第一对外壳用掉一对括号；A 用 k 对，B 用 n-1-k 对。A 有 C_k 种，B 有 C_(n-1-k) 种。它们独立，因此这一类有 C_k×C_(n-1-k) 种。遍历所有 k：

`C_0=1`

`C_n = C_0*C_(n-1) + C_1*C_(n-2) + ... + C_(n-1)*C_0`

```text
n=3：
k=0  () B       1×2=2  → ()(())、()()()
k=1  (()) B     1×1=1  → (())()
k=2  ( A )      2×1=2  → ((()))、(()())
合计                    5
```

C_0=1 的原因：空的 A 或 B 仍是一种选择。若设为 0，所有乘积都会变为 0。这里 C_n 只是卡特兰数记号，不是组合数；组合数在下文用 binom 表示，避免混淆。

### 原理：闭式为什么成立（进阶，可第二遍读）

把左括号看成向上一步，右括号看成向下一步，合法路径从高度 0 出发，2n 步后回到 0，且途中不低于 0。所有含 n 次上坡、n 次下坡的路径共有 binom(2n,n) 条。

对不合法路径，找到它第一次到高度 -1 的位置，将此前路径的上下方向互换。变换后共有 n+1 次上坡、n-1 次下坡。反过来，对这种路径找到第一次到 +1 的位置并翻转前缀，就还原唯一的不合法路径。因此坏路径有 binom(2n,n+1) 条。

`C_n = binom(2n,n) - binom(2n,n+1) = binom(2n,n)/(n+1)`。

由闭式还可整理出 `C_n=C_(n-1)*(4n-2)/(n+1)`。本节实现优先采用结构清楚的卷积；直接计算阶乘容易在中途溢出，最后结果能放下不代表中间值也能放下。若取模，整数除法不能直接换成模后除法；需要另外学习模逆元及其适用条件。

### C++ 实现

```cpp
vector<int>catalanTable(int n)
{ // 0 <= n <= 35，完整整数
    vector<int>c(n+1,0);
    c[0]=1;
    for(int total=1;total<=n;++total)
    {
        for(int left=0;left<total;++left)
        {
            int right=total-1-left;
            c[total]+=c[left]*c[right];
        }
    }
    return c;
}
```

手算 C_4=1×5+1×2+2×1+5×1=14。时间 O(n²)，空间 O(n)。C_35=3116285494907301262 能放进有符号 long long，C_36 超出；本实现所有项非负，各乘积与部分和不超过最终 C_total，因此在约定范围内中间计算也安全。更大 n 用高精度或按题意取模。

### 作用与使用场景

| 模型           | 规模如何对应               | 为什么有相同结构         |
| ------------ | -------------------- | ---------------- |
| 合法括号串        | n 对括号 → C_n          | 唯一拆成 (A)B        |
| 固定顺序入栈的出栈序列  | n 个互异元素 → C_n        | 入/出对应左右括号        |
| 不跌破横轴的上下坡路径  | n 上、n 下 → C_n        | 前缀高度非负           |
| 有序二叉树的形态数    | n 个节点，左右孩子位置不同 → C_n | 根占 1 个，左右子树占其余节点 |
| 二元运算的完全加括号方式 | n+1 个操作数 → C_n       | 最后一次运算分开左右表达式    |
| 凸多边形三角剖分     | n+2 个顶点 → C_n        | 选定边所属三角形分出两侧区域   |

二叉树、完全加括号和多边形模型是拓展，用于识别场景，不要求本章立即实现。其经典对应关系可查阅 [Princeton 的树计数教材](https://aofa.cs.princeton.edu/60trees/) 与 [UCSD 卡特兰数课程讲义](https://mathweb.ucsd.edu/~gptesler/184a/slides/catalan_19-handout.pdf)。不要把任意树的数量、任意括号总数、带高度限制的路径都当作 C_n；先证明模型确实等价。

## K08 递归思想与调用栈

### 概念

递归是函数直接或间接调用自身来处理同类型子问题。每次调用有自己的参数、局部变量和返回位置；调用栈保存尚未结束的各层工作。最深层先完成，外层随后恢复。

### 原理

递归正确性分三部分：边界能直接回答；调用的子问题规模严格下降；假设子问题答案正确，当前层的组合也正确。阶乘的规模是 n，n-1 不断减小，最终到 0。不能仅凭“代码里写了一个 if”就认为它会停止。

### C++ 实现

```cpp
int factorial(int n)
{ // 0 <= n <= 20
    if(n==0) return 1;
    int smaller=factorial(n-1);
    return n*smaller;
}
```

```text
fact(3)：等待 3 × fact(2)
  fact(2)：等待 2 × fact(1)
    fact(1)：等待 1 × fact(0)
      fact(0)：返回 1
返回方向：1 → 1 → 2 → 6
```

时间 O(n)，栈空间 O(n)，不是 O(1)。把 `return n*smaller` 放在递归调用前会得不到子结果；递归函数不是“调用后从头重新跑父函数”，而是从父函数暂停处继续。

### 作用与使用场景

树的遍历、分治、深度优先搜索、嵌套语法解析适合递归，因为问题天然有层次。只有一条很长的依赖链时，循环常更省栈。阶乘没有重复子问题，记忆化不会降低一次查询的渐近复杂度。

## K09 分解成子问题

### 概念

子问题是原问题在更小范围或更少资源下的同类问题。分解的关键是给函数一个精确承诺：例如 countSequences(n) 返回“首项为 n 的合法数列数量”，而不是“随便求一下答案”。

### 原理

对 P1028，第一项 n 后可以停止，也可以接 1..floor(n/2) 中的一个 k。选定 k 后，剩余结构与“首项为 k 的合法数列”完全相同。不同第二项的类别互斥，每条非单项序列都有且只有一个第二项，故不重不漏。

`f(n)=1+f(1)+...+f(floor(n/2))`，所有递归参数都小于 n。这个分解既给出计数规则，也给出终止证明。

### C++ 实现

```cpp
int countSequencesSlow(int n)
{                  // 教学示例：1 <= n <= 20
    int answer=1;// 仅有 n 的单项数列
    for(int k=1;k<=n/2;++k)
        answer+=countSequencesSlow(k);
    return answer;
}
```

n=4 时：只保留 `[4]` 贡献 1，选 1 贡献 1，选 2 贡献 2，共 4。时间与递归树节点数成正比，存在重复状态，不是 O(n)；深度 O(log n)，因为参数每层至少减半。教学版限制小输入，完整范围用 K10 的缓存或后文递推。

### 作用与使用场景

面对“先选一个动作，余下仍是同一类问题”时可这样建模。分治也使用子问题，但常把数据划成独立部分，例如归并排序；本题子问题会重复出现，所以更适合再加记忆化。不要把递归、分治、记忆化当成同义词。

## K10 利用递归求解，并改写成递推

### 概念

关系式是数学模型，递归和递推是两种执行方式。递归按需向下追问；递推按可用依赖顺序主动填表。理解同一关系的两种实现，可以避免只会背某一种代码。

### 原理

P1028 只依赖更小的正整数状态。递归可先算需要的 k，再返回 n；循环可先算 1、2……n。加缓存后各个状态只展开一次，但每个状态仍要枚举至多 n/2 个转移，因此总时间上界 O(n²)，不能因为“记忆化”就宣称 O(n)。

### C++ 实现

```cpp
int sequenceMemoDfs(int n,vector<int>&memo)
{
    if(memo[n]!=-1) return memo[n];// 本题答案 >= 1，-1 可作标记
    int answer=1;
    for(int k=1;k<=n/2;++k)
        answer+=sequenceMemoDfs(k,memo);
    return memo[n]=answer;
}
int sequenceMemo(int n)
{ // 1 <= n <= 1000
    vector<int>memo(n+1,-1);
    return sequenceMemoDfs(n,memo);
}
int sequenceLoop(int n)
{ // 与上面计算相同的关系式
    vector<int>f(n+1,0);
    for(int i=1;i<=n;++i)
    {
        f[i]=1;
        for(int k=1;k<=i/2;++k)
            f[i]+=f[k];
    }
    return f[n];
}
```

二者缓存/表空间 O(n)，递归版本另有 O(log n) 的调用栈。前缀和优化可用 `s[i]=s[i-1]+f[i]`，则 `f[i]=1+s[i/2]`，降为 O(n) 时间；先理解基础转移后再优化。

### 作用与使用场景

依赖复杂、只访问少量状态时，递归加缓存比较自然；状态密集、顺序清楚或栈深度危险时，递推更适合。递推改写不能改变状态含义、初值或转移，只改变求值顺序。

## K11 递归记忆化（记忆化搜索）

### 概念

记忆化搜索在递归中保存每个状态的结果，下一次遇到同一状态就直接返回。它主要解决“不同路径走到了相同子问题”的重复计算，不负责自动修正错误的递归模型。

### 原理

斐波那契递归树中有许多相同的 F(3)、F(2)。缓存把这些重复节点合并成一个依赖图，每个状态只展开一次。Function 需要三个参数共同标识状态，所以必须用 memo[a][b][c]，只记 memo[a] 会把不同问题混在一起。

```text
边界判断 → 是否已计算？ → 是：返回缓存
                         → 否：算所有依赖 → 保存结果 → 标记完成 → 返回
```

### C++ 实现

```cpp
int fibMemoDfs(int n,vector<int>&memo,vector<bool>&seen)
{
    if(n<=1) return n;
    if(seen[n]) return memo[n];
    int answer=fibMemoDfs(n-1,memo,seen)+fibMemoDfs(n-2,memo,seen);
    memo[n]=answer;
    seen[n]=true;
    return answer;
}
int fibonacciMemo(int n)
{ // 0 <= n <= 92
    vector<int>memo(n+1,0);
    vector<bool>seen(n+1,false);
    return fibMemoDfs(n,memo,seen);
}
```

F(5) 的朴素递归进入 15 次；这个版本进入 9 次，但 F(2)..F(5) 只各展开一次，其他重复请求直接命中。时间 O(n)，缓存和栈空间 O(n)。一般分析是“状态数 × 每个状态的转移开销”，更精确可计访问状态数与依赖边数之和。

### 作用与使用场景

适用于状态答案固定、有重复子问题、依赖最终能走向边界的问题，例如 Function、多维计数和 DAG 上的搜索。答案可能为 0 时不能通用地用 0 判断未计算；用 seen 或不可能出现的哨兵值。若参数依赖外部图或障碍，输入改变后应清空缓存。遇到环时需要额外的环处理或重新建模，“正在计算”不等于“已经算完”。

## K12 较复杂的递归：嵌套结构与共享游标

### 概念

嵌套结构指一层内部还能包含相同类型的结构，例如括号里还有括号、目录里还有目录。每个递归调用只负责当前一层，把更内层完整交给子调用。

### 原理

对外星密码，每层处理三个事件：字母直接追加；`[` 后读完整次数并递归解析内部；`]` 结束本层。共享游标 pos 记录下一次要读的位置。函数返回时必须恰好越过自己负责的右括号，父层才能继续读后面的内容。

```text
A[2B[3C]]D
外层： A + repeat(内层,2) + D
内层： B + repeat(C,3) = BCCC
结果： A + BCCCBCCC + D = ABCCCBCCCD
```

### C++ 实现

```cpp
string parseLevel(const string&s,int&pos)
{ // 约定输入语法合法
    string result;
    while(pos<(int)s.size())
    {
        char ch=s[pos++];
        if(ch==']') return result;// 消费本层右括号后返回
        if(ch!='[')
        {
            result+=ch;
            continue;
        }
        int times=0;
        while(pos<(int)s.size()&&s[pos]>='0'&&s[pos]<='9')
            times=times*10+(s[pos++]-'0');
        string inner=parseLevel(s,pos);
        for(int i=0;i<times;++i)
            result+=inner;
    }
    return result;// 最外层读到输入结束
}
string decodeText(const string&s)
{
    int pos=0;
    return parseLevel(s,pos);
}
```

注意 pos 按引用传递；若改为按值，每层只移动自己的副本，父层不会知道内部读到了哪里。两位次数要用循环读取；`[12A]` 应产生 12 个 A。每次读字符都会推进游标，输入有限且嵌套合法，因此会终止。设输入 N、最终输出 L、深度 H，保守时间 O(N+HL)，空间 O(N+HL+H)，含复制与各层字符串。

### 作用与使用场景

压缩串解码、表达式求值、括号语法与树形数据解析都可使用“当前层循环 + 内层递归”。复杂之处是管理层与层之间的边界，而不是把递归函数写得很长。外星密码的不同位置即使都读到同一个字母，也不代表返回范围相同；没有必要像斐波那契一样按字母做缓存。

## P1255 数楼梯：从最后一步倒推

[洛谷原题](https://www.luogu.com.cn/problem/P1255)

定义 f[i]：到达第 i 级的走法数。把最后一步当作一扇门：从 i-1 跨一步，或者从 i-2 跨两步。两组走法互不重叠，所以相加。

`f[i]=f[i-1]+f[i-2]`，`f[0]=1, f[1]=1`。f[0]=1 表示“什么也不走”的一种方案，它让跨两步到第 2 级的方案也被计入。

```text
第 i-2 级 ─── 跨2级 ───┐
                        ├──→ 第 i 级
第 i-1 级 ─── 跨1级 ───┘
级数       0  1  2  3  4  5
方案数     1  1  2  3  5  8
```

这是斐波那契型递推，但 f[n]=F(n+1)，不要照抄 F(0)=0。题目 n 最大 5000，必须高精度。下面用二维数组保存各级答案的十进制数位：`f[i][j]` 表示第 i 级答案的第 j 位（从个位起），`f[i][0]` 保存位数。个位先加、向高位进位。每位最多 9+9+1=19。

若答案最大位数为 D，总时间 O(nD)，保存全部级数的空间 O(nD)；这里 D 随 n 线性增长。当前固定数组约占 42.2 MiB。自测：1→1，2→2，5→8。练习：允许跨 1、2、3 级时怎样改式子？提示：三个来源，越界项不计。

### 完整 C++17 程序

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

// f[i][j] 是第 i 级走法数从低到高的第 j 位。
// f[i][0] 存十进制位数，5000 阶的答案不超过 1100 位。
int f[5005][1105];

signed main()
{
    int n;
    cin>>n;
    f[0][0]=f[1][0]=1;
    f[0][1]=f[1][1]=1;

    for(int i=2;i<=n;i++)
    {
        int len=max(f[i-1][0],f[i-2][0]);
        int carry=0;

        for(int j=1;j<=len;j++)
        {
            int x=f[i-1][j]+f[i-2][j]+carry;
            f[i][j]=x%10;
            carry=x/10;
        }

        if(carry) f[i][++len]=carry;
        f[i][0]=len;
    }

    for(int j=f[n][0];j>=1;j--)
        cout<<f[n][j];
    cout<<'\n';

    return 0;
}
```

## P1002 过河卒：在棋盘上填表

[洛谷原题](https://www.luogu.com.cn/problem/P1002)

定义 dp[x][y]：从 (0,0) 到 (x,y) 的合法路径数。最后一步只能来自 (x-1,y) 或 (x,y-1)，所以可走点填两个来源之和；禁止点直接填 0。

```text
     上方 dp[x-1][y]
             ↓
左方 → 当前格 = 上方 + 左方
```

先标记马自身和八个日字跳跃位置，再设置起点。如果先填起点，随后错误覆盖禁区，就可能制造不存在的路径。坐标范围是 0..n、0..m，包含端点，因此数组至少 21×21。第一行和第一列只有一个方向的来源；不要一律初始化为 1，因为中间可能被阻断。

时间 O(nm)，空间 O(nm)。无障碍 20×20 的路径数为 C(40,20)=137846528820，int 不够，使用 long long。自测：`6 6 3 3`→6；`2 2 1 1`→0。练习：对照固定马位置的动画，解释为什么禁区之后仍可能绕路到达。

### 完整 C++17 程序

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;
int dp[21][21]{};
bool blocked[21][21]{};
signed main()
{
    int n,m,hx,hy;
    cin>>n>>m>>hx>>hy;
    int dx[]={0,1,1,-1,-1,2,2,-2,-2};
    int dy[]={0,2,-2,2,-2,1,-1,1,-1};
    for(int k=0;k<9;++k)
    {
        int x=hx+dx[k],y=hy+dy[k];
        if(x>=0&&x<=n&&y>=0&&y<=m) blocked[x][y]=true;
    }
    for(int x=0;x<=n;++x)
        for(int y=0;y<=m;++y)
        {
            if(blocked[x][y]) continue;
            if(x==0&&y==0)
            {
                dp[x][y]=1;
                continue;
            }
            if(x>0) dp[x][y]+=dp[x-1][y];
            if(y>0) dp[x][y]+=dp[x][y-1];
        }
    cout<<dp[n][m]<<'\n';
    return 0;
}
```

## P1044 栈：把合法操作拆成两段

[洛谷原题](https://www.luogu.com.cn/problem/P1044)

把入栈记为左括号，出栈记为右括号。栈不能为空时出栈，所以任意前缀的出栈次数不能多于入栈次数。n=3 时 5 种合法括号串为 `((()))`、`(()())`、`(())()`、`()(())`、`()()()`。

```text
整体 = ( 内部合法序列 A ) 外部合法序列 B
         k 对             n-1-k 对
```

按第一个左括号匹配的右括号划分，每个合法序列的拆法唯一。内部和外部独立选择，方案数相乘；枚举 k 的各类互斥，最后相加：

`C[n] = Σ C[k] * C[n-1-k]`，k=0..n-1，`C[0]=1`。空序列有一种，不能设成 0。这就是卡特兰数。固定输入顺序时，每个可行输出顺序对应唯一的合法进出栈过程，所以可以数这些括号串。

时间 O(n²)，空间 O(n)。n≤18，long long 足够。自测：1→1、3→5、18→477638700。练习：手算 C[4]=5+2+2+5=14，并解释每一项从哪里来。

### 完整 C++17 程序

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;
signed main()
{
    int n;
    cin>>n;
    int c[19]{};
    c[0]=1;
    for(int i=1;i<=n;++i)
        for(int k=0;k<i;++k)
            c[i]+=c[k]*c[i-1-k];
    cout<<c[n]<<'\n';
    return 0;
}
```

## P1028 数的计算：递归分解与循环实现

[洛谷原题](https://www.luogu.com.cn/problem/P1028)

令 f(n) 为从 n 开始的合法数列数量。可以马上停止（贡献 1），也可以选下一个数 k，1≤k≤⌊n/2⌋，之后全部交给 f(k)。

`f(n)=1+Σ f(k)`，k=1..⌊n/2⌋。例如 n=6：停止；接 1；接 2 后可停止或接 1；接 3 后可停止或接 1。总数 1+1+2+2=6。

```text
6
├─ 停止： [6]
├─ 1：    [6,1]
├─ 2：    [6,2]， [6,2,1]
└─ 3：    [6,3]， [6,3,1]
```

递归函数可写 `ans=1; for(k=1;k<=n/2;++k) ans+=solve(k);`，n=1 时循环为空，返回 1。k 总小于 n，所以会终止；加缓存可避免重复。下面按 n 从小到大递推，同样体现子问题思想。

此版时间 O(n²)，空间 O(n)。n≤1000，long long 足够。自测：1→1、6→6、10→14。进阶：利用前缀和把总时间降到 O(n)，但先独立写出基础版。

### 完整 C++17 程序

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;
signed main()
{
    int n;
    cin>>n;
    vector<int>f(n+1,0);
    for(int i=1;i<=n;++i)
    {
        f[i]=1;// 只保留当前数，立即停止
        for(int k=1;k<=i/2;++k)
            f[i]+=f[k];
    }
    cout<<f[n]<<'\n';
    return 0;
}
```

## P1464 Function：给三个参数建立缓存

[洛谷原题](https://www.luogu.com.cn/problem/P1464)

本题函数命名为 fc，使用 dp[a][b][c] 缓存；main 中用 memset 把 dp 初始化为 -1。本题有效答案不为 -1，因此它可表示“还没计算”。先把题目定义翻译成四个分支，顺序不能改变：

1. 任一参数≤0：返回 1。
2. 否则任一参数>20：转成 w(20,20,20)。
3. 否则 a<b<c：使用三个子问题相加减的公式。
4. 其他情况：使用四个子问题相加减的公式。

第二条必须在第一条之后。例如 (-1,100,100) 应返回 1。只有确认三个参数都在 1..20 后才访问缓存；输入本身可能很大或很小，用 long long 读取，不能直接拿输入当下标。

```text
w(a,b,c) → 边界检查 → 查 dp[a][b][c]
                          ├─ 已有：直接返回
                          └─ 没有：递归计算 → 保存 → 返回
```

最多 20³ 个正参数状态，每个展开常数条转移，预处理总量 O(20³)，T 次查询合计 O(20³+T)。缓存空间 O(22³)，活动递归链 O(20)（参数和下降，常数上界约 60 层）。答案可复用，多组输入不要每行清空。仅三项全是 -1 才结束，输出保留原输入和规定空格。

自测：`1 1 1`→2，`20 20 20`→1048576，`-1 100 100`→1。练习：指出每个分支如何让递归走向边界。

### 完整 C++17 程序

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

int dp[22][22][22];

int fc(int a,int b,int c)
{
    if(a<1||b<1||c<1) return 1;

    if(a>20||b>20||c>20)
        return fc(20,20,20);

    if(dp[a][b][c]!=-1)
        return dp[a][b][c];

    if(a<b&&b<c)
    {
        dp[a][b][c]=fc(a,b-1,c-1)
                   +fc(a,b,c-1)
                   -fc(a,b-1,c);
    }
    else
    {
        dp[a][b][c]=fc(a-1,b,c)
                   +fc(a-1,b-1,c)
                   +fc(a-1,b,c-1)
                   -fc(a-1,b-1,c-1);
    }

    return dp[a][b][c];
}

signed main()
{
    memset(dp,-1,sizeof dp);

    int a,b,c;

    while(cin>>a>>b>>c)
    {
        if(a==-1&&b==-1&&c==-1)
            break;

        cout<<"w("<<a<<", "<<b<<", "<<c<<") = "<<fc(a,b,c)<<'\n';
    }

    return 0;
}
```

## P1928 外星密码：每层递归负责一对括号

[洛谷原题](https://www.luogu.com.cn/problem/P1928)

本题像拆套娃。函数 decode 负责读取当前层，遇见字母直接收集，遇见 `[` 先读完整重复次数，再递归解出内部字符串；遇到 `]` 消费它并返回。

```text
输入 A[2B[3C]]
内层 [3C] → CCC
中层 [2BCCC] → BCCCBCCC
外层 → ABCCCBCCC
```

共享下标 pos 就像所有人传递的阅读书签。函数返回后，书签必须在它负责的右括号之后，否则父层可能提前结束。次数可能是两位数，用 while 连续读数字；`k=k*10+数字`，不能只读一个字符。

终止条件是读到本层右括号或输入结束；每次循环都会前进下标。题目保证合法输入，因此本例不负责修复不匹配括号。最大嵌套深度 10，输出长度最多 20000。

设输入长 N、最终输出长 L、深度 H，此实现保守时间 O(N+HL)，因为每层会复制子串；额外空间保守 O(N+HL+H)，含输入、各层字符串和调用栈。自测：`[3AB]`→ABABAB、`A[2B[3C]]`→ABCCCBCCC。练习：把数字读取错误写成只读一位，用 `[12A]` 检查会发生什么。

### 完整 C++17 程序

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;
string s;
int pos=0;
string decode()
{
    string result;
    while(pos<(int)s.size())
    {
        char ch=s[pos++];
        if(ch==']') return result;
        if(ch=='[')
        {
            int count=0;
            while(pos<(int)s.size()&&s[pos]>='0'&&s[pos]<='9')
                count=count*10+(s[pos++]-'0');
            string inner=decode();
            for(int i=0;i<count;++i)
                result+=inner;
        }
        else result+=ch;
    }
    return result;
}
signed main()
{
    cin>>s;
    cout<<decode()<<'\n';
    return 0;
}
```

# 带括号的递归解析（递归 + 全局下标）

本节根据你提供的学习笔记整理，保留原来的思路与七部分结构；完整代码沿用本手册的 C++ 风格。模板中的自然语言条件是伪代码，不能直接编译。

**本节约定：子层遇到右括号时停下，不消费它；父层在 dfs() 返回后执行 pos++ 跳过右括号。** 前面的 P1928 示例采用“子层消费右括号后返回”，两种方式都正确，但不能混用。下面全部按本节约定讲解。

<a id="section-30"></a>

## 一、核心思想

**一对括号就是一个独立的子问题。** 遇到左括号 `(` 或 `[` 时，可以进入递归处理内部内容；遇到对应右括号时，结束当前层，返回上一层。具体程序要根据题目识别括号类型，本节的完整实现只处理 P1928 的方括号。

例如 `[2A[3BC]]`：最外层读取整个表达式；进入第一个方括号后处理 `A[3BC]`；再进入最内层处理 `BC`。内层结果重复 3 次，得到 `BCBCBC`；加上 A，再重复 2 次，得到 `ABCBCBCABCBCBC`。

大问题拆成小问题，小问题继续使用相同的处理方法。特别注意：递归只返回括号内部的解压结果，重复次数由调用它的父层负责应用。

<a id="section-31"></a>

## 二、通用递归模板

下面是结构示意，其中中文条件和注释里的操作要根据题目补全：

```text
int pos=0;
string s;

string dfs()
{
    string ans;

    while(pos<(int)s.size()&&s[pos]!=']')
    {
        if(当前是普通字符)
        {
            // 处理普通字符
            pos++;
        }
        else
        {
            // 根据输入语法读取括号前的信息（如有）
            pos++;            // 跳过左括号
            // 根据输入语法读取括号后的信息（如有）
            string t=dfs();   // 递归处理括号内部
            pos++;            // 跳过右括号
            // 根据题意处理子结果 t
        }
    }

    return ans;
}
```

| 关键位置        | 作用              |
| ----------- | --------------- |
| 左括号处的 pos++ | 跳过左括号，让解析位置进入内部 |
| dfs()       | 解析当前括号内部的内容     |
| 返回后的 pos++  | 跳过子层停留的右括号      |

每层只负责当前层的内容；遇到自己的右括号就结束；全局 pos 记录下一次要读的位置，不必反复传递或截取字符串。P1928 的重复次数在左括号之后，所以必须先跳过 `[`、读完整次数，再调用 dfs()；不能省略读次数这一步。

<a id="section-32"></a>

## 三、解题步骤

### 1. 确定递归函数的含义

`string dfs()` 表示从全局 pos 开始解析，直到遇到当前层对应的右括号或输入结束，返回本层解压结果。返回时 pos 指向尚未消费的右括号；最外层没有右括号，则停在字符串末尾。

### 2. 确定递归边界

```cpp
while(pos<(int)s.size()&&s[pos]!=']')
```

先检查下标范围，再检查字符；遇到 `]` 停止循环，由 return 返回当前层结果。

### 3. 处理普通字符

```cpp
ans+=s[pos];
pos++;
```

直接加入答案，继续向后解析。

### 4. 处理左括号

```cpp
pos++;            // 跳过左括号
// 如果有次数等前缀信息，在此读完
string t=dfs();   // 内部全部交给下一层
pos++;            // 跳过下一层留下的右括号
```

### 5. 处理递归返回值

字符串解压时重复拼接；表达式求值时结合运算符计算；括号统计时合并计数；树的解析时建立节点、连接子树。这些题只共享“递归处理嵌套”的思路，返回类型和合并规则应按各自题意设计，不能照搬字符串模板。

<a id="section-33"></a>

## 四、例题：P1928 外星密码

### 题意与例子

重复子串 X 可以压缩成 `[DX]`，D 是 1..99 的重复次数，支持多层嵌套。

```text
AC[3FUN] → ACFUNFUNFUN
[2[2CB]] → CBCBCBCB
```

这里使用题目保证输入合法、只含大写字母、数字和方括号的条件；它不是任意括号表达式的校验器。

### 完整代码

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

string s;
int pos=0;

string dfs()
{
    string ans;

    while(pos<(int)s.size()&&s[pos]!=']')
    {
        if(s[pos]>='A'&&s[pos]<='Z')
        {
            ans+=s[pos];
            pos++;
        }
        else
        {
            int num=0;

            // 跳过左括号
            pos++;

            // 读取完整的重复次数
            while(pos<(int)s.size()&&s[pos]>='0'&&s[pos]<='9')
            {
                num=num*10+s[pos]-'0';
                pos++;
            }

            // 子层遇到右括号就停下，将内部结果返回
            string t=dfs();

            // 父层跳过子层停留的右括号
            pos++;

            for(int i=0;i<num;i++)
                ans+=t;
        }
    }

    return ans;
}

signed main()
{
    cin>>s;
    cout<<dfs()<<'\n';

    return 0;
}
```

与 isupper/isdigit 的写法含义相同，这里直接用字符范围判断，便于观察。若同一程序连续解析多个输入，应在每个新输入前把 pos 重置为 0。

设输入长度为 N、输出长度为 L、最大嵌套深度为 H。每层可能复制子串，保守时间 O(N+HL)，额外空间保守 O(N+HL+H)，包含输入、各层字符串与调用栈。重复次数和嵌套会让输出迅速增长，不能只按压缩串长度估计工作量。

<a id="section-34"></a>

## 五、递归过程模拟

以 `[2A[3BC]]` 为例，下标从 0 开始：

```text
下标  0 1 2 3 4 5 6 7 8
字符  [ 2 A [ 3 B C ] ]
```

| 调用层数 | 本层处理内容 | 返回结果           | 返回时 pos   |
| ---- | ------ | -------------- | --------- |
| 第三层  | BC     | BC             | 7，停在内层右括号 |
| 第二层  | A[3BC] | ABCBCBC        | 8，停在外层右括号 |
| 第一层  | 整个输入   | ABCBCBCABCBCBC | 9，到达串尾    |

```text
第一层 dfs()
    跳过 [，读出次数 2
    第二层 dfs()
        读取 A
        跳过 [，读出次数 3
        第三层 dfs()
            读取 B、C
            遇到下标 7 的 ]，返回 BC
        pos++ 跳过下标 7 的 ]
        将 BC 重复 3 次，当前结果为 ABCBCBC
        遇到下标 8 的 ]，返回 ABCBCBC
    pos++ 跳过下标 8 的 ]
    将 ABCBCBC 重复 2 次
    到达串尾，返回最终答案
```

递归的调用顺序不断深入，返回顺序从最内层逐层向外。注意第三层返回的是 BC，重复成 BCBCBC 的工作属于第二层。

<a id="section-35"></a>

## 六、常见错误

### 1. 只读取一位数字

只执行一次 `num=s[pos]-'0'` 读不出 12、99 等两位次数。应循环读取：

```cpp
int num=0;

while(pos<(int)s.size()&&s[pos]>='0'&&s[pos]<='9')
{
    num=num*10+s[pos]-'0';
    pos++;
}
```

例如 `[12A]` 应输出 12 个 A。范围检查要在访问 s[pos] 之前。

### 2. 忘记跳过右括号，或重复跳过

本节的子层返回时 pos 仍在右括号上，所以父层需要 `pos++`。若漏掉，父层也会遇到该右括号并过早结束。若把前文“子层已经消费右括号”的 dfs() 搬过来，还保留父层的 pos++，又会跳过右括号之后的有效字符。

### 3. 不理解递归返回值

`t=dfs()` 保存当前括号内部的完整解压结果，不是整个输入的答案，也不是已经应用本层重复次数的结果。`[2A[3BC]]` 的最深层只返回 BC。

### 4. 没有设置递归边界

如果遇到 `]` 不停止，就会把不同层内容混到一起；若输入结束后还访问字符，则可能越界。循环条件同时处理这两个边界。

### 5. 混淆全局下标

不要在每次 dfs() 内重新定义一个 pos；它会遮蔽全局变量。每次移动下标都明确目的：读取普通字符、跳过左括号、读取数字，或跳过子层的右括号。解析新输入前重置 pos，递归过程中不能重置。

<a id="section-36"></a>

## 七、复习总结

**遇左括号，进入递归；遇右括号，返回上一层；普通字符，正常处理；返回结果，按题意合并。**

解题时依次明确 dfs() 的功能、结束条件、普通字符处理、进入子层的时机和返回结果的合并方式，再明确“谁消费右括号”。

这种分层处理思路适用于嵌套字符串解压、括号解析、数学表达式、树及其他递归定义结构。涉及混合括号或运算优先级时，还需要补充相应语法规则。

最重要的是：不要试图一次性处理所有括号，而是让每一层只处理属于自己的那一部分。

自测：`AC[3FUN]`、`[2[2CB]]`、`[12A]`、`A[2B[3C]]D`。最后一个输入能检查返回后有没有漏读或多跳一个字符，正确结果为 `ABCCCBCCCD`。

## 如何安排学习

第一轮只读三个入门概念并手写简单程序；第二轮做数楼梯和过河卒，练状态与边界；第三轮做栈和数的计算，练分类计数；第四轮做 Function 和外星密码，练缓存与嵌套递归。每次复习先遮住代码，自己写出状态和关系式。

常见错误：初始值照抄、整型溢出、禁止格没清零、递归不缩小、缓存键缺参数、下标越界、忘记多位数字、右括号未消费。遇到错误先用最小例子手推。
