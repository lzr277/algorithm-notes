## 入门：贪心到底在做什么

想象给一条队伍安排接水顺序，当前只决定“下一个让谁接”。贪心每次依据某条规则作一个局部选择，然后把剩余问题继续交给同一条规则。代码往往短，难点在于证明：这一步不会牺牲后面的最优答案。

```text
先读目标 → 提出规则 → 找反例 → 证明可安全选择 → 实现 → 小规模对拍
                     ↑                          |
                     └──── 发现问题就修改规则 ───┘
```

与上一章对照：递推/递归描述计算组织方式，贪心描述决策策略；贪心也可以循环或递归实现。不能把“有排序”当成“就是正确的贪心”。
<a id="c4"></a>
## K01 贪心算法

### 概念

在每一步按固定策略选当前最有利的可行方案，通常不撤销选择。局部最优是当前一步好，全局最优是最终目标最好，二者不能画等号。

### 原理

正确策略必须保留某个最优解的可能性。比如相同代价下先选择收益高的物品，有时安全；但带重量限制时只看总收益可能浪费容量。先明确优化目标和约束。

### C++ 实现

最简单的安全例子：预算 k 次选择，每个物品成本相同、收益非负，取最大的 k 个。
```cpp
sort(a+1,a+n+1,greater<int>());
int ans=0;
for(int i=1;i<=min(k,n);i++)
    ans+=a[i];
```

### 作用与使用场景

资源调度、可分割资源、某些区间选择、最优合并。若当前选择会改变后续约束，必须证明安全，不能看到最大/最小就套贪心。

<a id="c5"></a>
## K02 贪心选择性质与最优子结构

### 概念

贪心选择性质：存在一个最优解包含算法的首个选择。最优子结构：首个选择固定后，余下部分必须是相应剩余问题的最优解。

### 原理

两个条件共同连接“当前选择”与“整题正确”。最优子结构本身不够：0/1 背包也有最优子结构，但按单位价值选通常错误。

### C++ 实现

实现时让变量准确表示剩余问题，例如区间选择：
```cpp
if(a[i].l>=last)
{
    ans++;
    last=a[i].r;
}
```
last 是已经选择的最后结束时间，之后只考虑可衔接区间。完整实现见 P1803。

### 作用与使用场景

用来搭建证明和检查状态。选完一个区间后，剩余目标仍是最大化后续区间个数；若变成总收益最大，则模型改变，不能直接继承结论。

<a id="c6"></a>
## K03 反证法与交换论证

### 概念

反证法是假设结论不成立，推出矛盾；交换论证是把一个最优解中与贪心不同的选择交换成贪心选择，同时不让目标变差。交换是构造手段，反证是逻辑框架。

### 原理

部分背包按单位价值从大到小取。若某最优解先取了低密度物品、却没有取满可用高密度物品，就交换相同重量 δ，价值增加 δ×(高密度-低密度)>0，与最优矛盾。密度相同时交换不变差，说明存在遵守该顺序的最优解。

### C++ 实现

不要用整数除法比较密度，正重量下交叉相乘：
```cpp
bool cmp(node x,node y)
{
    return x.v*y.m>y.v*x.m;
}
```
本题范围下乘积安全；更大范围要另检查溢出。相等时返回 false 符合排序要求，不能写 >=。

### 作用与使用场景

可分割背包、相邻交换排序、树上叶子交换。证明要写明交换后依然可行，以及其他部分的代价为何不变；“显然交换更好”不能代替计算。

## K04 举出反例证伪贪心

### 概念

只需一个合法输入使策略得不到最优解，就能否定“该策略对所有输入都正确”。许多样例通过只能支持猜想，不能证明它。

### 原理

容量 50，物品(重量,价值)为(10,60)、(20,100)、(30,120)。可分割时密度优先得240；不可分割时同策略选前两件得160，但后两件得220。失败原因是不可分割导致容量碎片。

### C++ 实现

可用 0/1 子集枚举作为小数据参照：
```cpp
int best=0;
for(int s=0;s<(1LL<<n);s++)
{
    int weight=0,value=0;
    for(int i=0;i<n;i++)
    {
        if((s>>i)&1)
        {
            weight+=m[i];
            value+=v[i];
        }
    }
    if(weight<=t) best=max(best,value);
}
```
仅用于 n<=20 的小规模验证，时间 O(n×2^n)。

### 作用与使用场景

检查“价值最大优先”“最轻优先”“最短区间优先”等直觉。优先找极端值、容量刚好满、并列与长短相互冲突的输入。对拍发现错误有力，对拍未发现错误仍需证明。

## K05 大胆假设，小心求证：相邻交换

### 概念

先猜一个规则，再精确计算交换的收益。排队接水的目标是等待时间，不包括自己接水时间。

### 原理

相邻两人接水时间 x>y，之前累计时间为 P。原等待之和 P+(P+x)=2P+x，交换后为2P+y，减少x-y>0。后面人开始时间不变，因为 x+y 不变。消去全部逆序后为升序；相同时间按题目要求编号升序。

### C++ 实现

累计时间 now 是当前人真正等待的时间：
```cpp
int now=0,sum=0;
for(int i=1;i<=n;i++)
{
    sum+=now;
    now+=a[i].t;
}
cout<<fixed<<setprecision(2)<<1.0*sum/n;
```

### 作用与使用场景

单机器、所有任务同时到达、最小化总等待/完成时间的等权模型。有到达时间、不同优先权或多个水龙头时要重新建模。sort O(n log n)，扫描 O(n)；sum 用64位整数。

## K06 数学归纳法证明区间贪心

### 概念

归纳法分基础情况和归纳步骤。区间调度选结束最早的可行区间，而不是开始最早或持续最短。

### 原理

基础：没有区间或只有一个时正确。归纳：令 g 为最早结束区间，任一最优解首区间为 o，有 end(g)<=end(o)。用 g 替换 o，之后原来能接上的区间仍可接上，数量不减。选 g 后剩下区间更少，是同型问题，依归纳假设余下也最优。

### C++ 实现

按结束时间排序，扫描一次：
```cpp
int last=-1,ans=0;
for(int i=1;i<=n;i++)
{
    if(a[i].l>=last)
    {
        ans++;
        last=a[i].r;
    }
}
```
P1803 时间非负，因此 last=-1 安全；允许负时间时需改初值。

### 作用与使用场景

不带权、要求最多个数的区间选择；端点衔接允许相等。带权区间不能只选结束最早，通常要动态规划。时间 O(n log n)，空间 O(n)；把 >= 写成 > 会漏掉紧接的比赛。

## K07 小根堆与动态维护最小值

### 概念

堆是一种能快速取极值的容器。小根堆每次 top 返回最小元素，pop 删除，push 插入新元素。

### 原理

合并后产生的新堆也会参与下一次选择。只在开始排序一次、以后顺序取两项是错误的：新元素必须重新放回候选集合。

### C++ 实现

```cpp
priority_queue<int,vector<int>,greater<int>> q;
q.push(3);
q.push(8);
int x=q.top(); // x=3，查看但未删除
q.pop();       // 删除3
```
模板中的 vector<int> 是堆底层存储，greater<int> 使最小值在顶部；默认 priority_queue<int> 则是大根堆。

### 作用与使用场景

反复插入和取最小值的调度、合并、哈夫曼构建。top O(1)，push/pop O(log n)，共 n-1 次合并，所以总 O(n log n)，空间 O(n)。空堆不能 top/pop。

## K08 哈夫曼树的构建与带权路径长度

### 概念

叶子代表原始对象，叶权为频次或重量，内部节点权为孩子权之和。叶深度按边数计算，WPL=Σ(叶权×叶深度)，目标使它最小。

### 原理

每次合并两小权 x,y，新节点权 x+y。一个叶子每上升一层就多被计算一次，所以合并代价总和等于 WPL。最优满二叉树可选最深的一对兄弟叶，把最小两权交换到这里不增加WPL：小权应占更大深度。合并成一叶后问题缩小，归纳证明反复取两小安全。

### C++ 实现

```cpp
int ans=0;
while(q.size()>1)
{
    int x=q.top();
    q.pop();
    int y=q.top();
    q.pop();
    ans+=x+y;
    q.push(x+y);
}
```
只求最小代价无需建树；要生成编码必须保留左右孩子，见例6。

### 作用与使用场景

最优二元合并、文件合并、频次编码。证明依赖非负权、任意两堆可合并且代价等于两权之和；限制相邻合并或改变代价函数后不能照搬。n=1 时无需合并，WPL为0。

## K09 哈夫曼编码与前缀码

### 概念

编码把符号映射到二进制串。前缀码要求没有一个符号的码字是另一个码字的前缀，因此可从左到右即时解码。

### 原理

把符号放在树叶上，左边标0、右边标1，根到叶路径为码字。叶子不可能是另一叶的祖先，因此天然无前缀冲突。总编码位数=Σ频次×码长= WPL；最小化WPL就最小化已知频次下的二元前缀编码长度。

### C++ 实现

生成过程是上一章学过的树形递归：
```cpp
void dfs(int u,string s)
{
    if(ls[u]==0&&rs[u]==0)
    {
        code[u]=s;
        return;
    }
    dfs(ls[u],s+'0');
    dfs(rs[u],s+'1');
}
```

### 作用与使用场景

已知符号频次的无损编码。左右标记可交换、相等权也可有不同树，所以最优编码未必唯一。单符号模型本章允许空码，需外部给定符号个数；实际格式若强制至少一位可约定0，此时输出长度为频次，不能仍称实际位数为0。

## K10 证明与验证形成闭环

### 概念

正确实现、数学证明、测试是不同任务：证明解释所有合法输入为何正确；测试帮助发现实现和推理里的错误。

### 原理

对贪心的证明可以按“找最优解 → 交换成贪心首选 → 剩余问题归纳”组织。验证器则对小规模枚举全部选择、排列或合并方式，检查贪心与最优值一致。

### C++ 实现

在正式程序外用小数据验证，不把暴力写进大规模解法。例如合并权1、2、9：先合1+2，再合3+9，总代价3+12=15；先合2+9则为11+12=23。代码见完整例5与 verify.py。

### 作用与使用场景

遇到新贪心题先证伪再证明；测试包含n=1、全相等、端点相接、容量不足及单符号。不要用一个样例通过代替正确性证明。

## 例1：部分背包问题（P2240）

[洛谷原题](https://www.luogu.com.cn/problem/P2240)

容量50，(10,60)、(20,100)、(30,120)，先装前两件，再装第三件的20/30，答案240.00。注意真正的可分割条件；不能把整数除法所得密度用于排序。

### 完整 C++17 程序

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

struct node
{
    int m,v;
}a[105];

bool cmp(node x,node y)
{
    return x.v*y.m>y.v*x.m;
}

signed main()
{
    int n,t;
    cin>>n>>t;
    for(int i=1;i<=n;i++) cin>>a[i].m>>a[i].v;
    sort(a+1,a+n+1,cmp);

    double ans=0;
    for(int i=1;i<=n&&t>0;i++)
    {
        int take=min(t,a[i].m);
        ans+=1.0*take*a[i].v/a[i].m;
        t-=take;
    }

    cout<<fixed<<setprecision(2)<<ans<<'\n';
    return 0;
}
```

## 例2：排队接水（P1223）

[洛谷原题](https://www.luogu.com.cn/problem/P1223)

时间3、1、2，顺序编号2、3、1；等待分别0、1、3，总和4，平均1.33。若先now+=t再sum+=now，就把自己的接水时间也算进去了。

### 完整 C++17 程序

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

struct node
{
    int t,id;
}a[1005];

bool cmp(node x,node y)
{
    if(x.t!=y.t) return x.t<y.t;
    return x.id<y.id;
}

signed main()
{
    int n;
    cin>>n;
    for(int i=1;i<=n;i++)
    {
        cin>>a[i].t;
        a[i].id=i;
    }
    sort(a+1,a+n+1,cmp);

    int now=0,sum=0;
    for(int i=1;i<=n;i++)
    {
        cout<<a[i].id<<(i==n?'\n':' ');
        sum+=now;
        now+=a[i].t;
    }

    cout<<fixed<<setprecision(2)<<1.0*sum/n<<'\n';
    return 0;
}
```

## 例3：凌乱的yyy（P1803）

[洛谷原题](https://www.luogu.com.cn/problem/P1803)

区间[0,3)、[1,2)、[2,4)、[4,5)，选后三个得3。开始最早的[0,3)会挤掉两个可衔接区间。这里用半开区间理解端点衔接。最短优先也可能错：[0,3)、[3,6)、[2,4)，最短[2,4)只能得1，另两段能得2。

### 完整 C++17 程序

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

struct node
{
    int l,r;
}a[1000005];

bool cmp(node x,node y)
{
    if(x.r!=y.r) return x.r<y.r;
    return x.l<y.l;
}

signed main()
{
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin>>n;
    for(int i=1;i<=n;i++) cin>>a[i].l>>a[i].r;
    sort(a+1,a+n+1,cmp);

    int last=-1,ans=0;
    for(int i=1;i<=n;i++)
    {
        if(a[i].l>=last)
        {
            ans++;
            last=a[i].r;
        }
    }

    cout<<ans<<'\n';
    return 0;
}
```

## 例4：分卷子（拆分教学模型，原题待核对）

明确教学假设：有n个班，各需要给定份数的卷子；从整叠开始，每次把一叠拆成两叠，代价为该叠张数，最终每班得到所需张数，最小化总代价。逆向看就是任意两堆合并，故与最优合并相同。例1、2、9份可先分3和9，再分1和2，代价12+3=15。本模型不保证等同书中“分卷子”，图片没有给出实际发放规则；实际若有顺序/相邻约束，算法可能改变。教学输入n和n个正整数，输出最小代价。

## 例6：哈夫曼编码的制定（教学模型，原题待核对）

明确教学接口：读n和n个正频次（n<=1000，单项<=10^9），按输入编号输出码字，并先输出最小WPL。权1、2、9可编码00、01、1，WPL=15。构造时节点数至多2n-1，数组开2005；pair的第二项节点编号仅用于相等权稳定取出，不是新的贪心标准。单符号输出(empty)，表示空码，并给出WPL=0；此模型假定解码端知道符号个数。若书中要求0编码，应按其接口修改。本例不冒充某个未确认洛谷题号。

### 完整 C++17 程序

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

// 教学输入：n，然后 n 个正整数频次，1<=n<=1000。
// 输出：最小 WPL，然后按原编号输出编码；不是未确认原题的提交格式。
int w[2005],ls[2005],rs[2005];
string code[1005];
priority_queue<pair<int,int>,vector<pair<int,int>>,greater<pair<int,int>>> q;

void dfs(int u,string s)
{
    if(ls[u]==0&&rs[u]==0)
    {
        code[u]=s;
        return;
    }
    dfs(ls[u],s+'0');
    dfs(rs[u],s+'1');
}

signed main()
{
    int n;
    cin>>n;
    for(int i=1;i<=n;i++)
    {
        cin>>w[i];
        q.push({w[i],i});
    }

    int tot=n,ans=0;
    while(q.size()>1)
    {
        int a=q.top().second;
        q.pop();
        int b=q.top().second;
        q.pop();

        tot++;
        ls[tot]=a;
        rs[tot]=b;
        w[tot]=w[a]+w[b];
        ans+=w[tot];
        q.push({w[tot],tot});
    }

    dfs(q.top().second,"");
    cout<<ans<<'\n';
    for(int i=1;i<=n;i++)
    {
        if(n==1) cout<<"(empty)\n";
        else cout<<code[i]<<'\n';
    }
    return 0;
}
```

## P3817 小 A 的糖果

[洛谷原题](https://www.luogu.com.cn/problem/P3817)

### 概念与策略

从左到右维护相邻盒子之和不超过x，只删除必要数量。

### 原理与正确性

先把a[1]压到x以内。处理i时至少要删除相邻超出的 d=a[i-1]+a[i]-x。优先从右盒a[i]删：删除左盒与右盒都能修复当前约束，但删右盒还能给下一对留下空间，不会伤害已处理的前缀；在最优解中把相应删除移到右侧不增加删除总数，因此安全。

### 完整 C++17 实现

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

int a[100005];
signed main()
{
    int n,x,ans=0;
    cin>>n>>x;
    for(int i=1;i<=n;i++) cin>>a[i];
    if(a[1]>x)
    {
        ans=a[1]-x;
        a[1]=x;
    }
    for(int i=2;i<=n;i++)
    {
        int d=max(0LL,a[i-1]+a[i]-x);
        a[i]-=d;
        ans+=d;
    }
    cout<<ans<<'\n';
    return 0;
}
```

### 作用、使用场景与易错点

适合相邻上界、前缀已固定的局部修复。a[1]先压到x，保证后续d不会大于a[i]，不会减出负数；答案可能超过32位。例x=3，盒子4,2,3，先删首盒1，再删第二盒2，总3。时间O(n)，空间O(n)。

## P1106 删数问题

[洛谷原题](https://www.luogu.com.cn/problem/P1106)

### 概念与策略

保留原顺序删除k位，使剩余整数最小。优先删掉首个大于后一位的数字。

### 原理与正确性

在所有剩余长度相同的数串中，首个不同位决定大小。若出现相邻下降a>b，删a能让更小的b尽早到高位，比删后面的位更优；重复这一步。若整串非降，就从末尾删，保留较小前缀。本题仅250位，采用直观O(kL)版本。

### 完整 C++17 实现

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

signed main()
{
    string s;
    int k;
    cin>>s>>k;
    while(k--)
    {
        int pos=0;
        while(pos+1<(int)s.size()&&s[pos]<=s[pos+1]) pos++;
        s.erase(pos,1);
    }
    int pos=0;
    while(pos<(int)s.size()&&s[pos]=='0') pos++;
    if(pos==(int)s.size()) cout<<0;
    else cout<<s.substr(pos);
    cout<<'\n';
    return 0;
}
```

### 作用、使用场景与易错点

字符串高位优先贪心。例178543删4位得13；1000删1位得0。erase删一位，不能转long long导致溢出。此版本O(kL)、空间O(L)；大规模可用单调栈O(L)，本题不必为短代码引入复杂结构。

## P1478 陶陶摘苹果（升级版）

[洛谷原题](https://www.luogu.com.cn/problem/P1478)

### 概念与策略

先过滤够不到的苹果，再按力气成本升序购买“每件收益都是1”的物品。

### 原理与正确性

同样摘k个苹果，最便宜k个的总力气不大于任意其他k个。交换掉更贵的已选苹果，不减少数量且不会增加力气，因此成本升序最优。可达性必须先判断，不能把够不到但便宜的苹果算进去。

### 完整 C++17 实现

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

int cost[5005];
signed main()
{
    int n,s,a,b,cnt=0;
    cin>>n>>s>>a>>b;
    for(int i=1;i<=n;i++)
    {
        int x,y;
        cin>>x>>y;
        if(x<=a+b) cost[++cnt]=y;
    }
    sort(cost+1,cost+cnt+1);
    int ans=0;
    for(int i=1;i<=cnt;i++)
    {
        if(cost[i]>s) break;
        s-=cost[i];
        ans++;
    }
    cout<<ans<<'\n';
    return 0;
}
```

### 作用、使用场景与易错点

适合相同收益下最大化数量；收益不同就不能只按成本排序。高度等于a+b可以摘，力气刚好用完也可以。时间O(n log n)，空间O(n)。

## P5019 铺设道路

[洛谷原题](https://www.luogu.com.cn/problem/P5019)

### 概念与策略

把深度直方图看成由若干条连续水平线段叠成，每次施工对应减去一条线段。

### 原理与正确性

左端需要d[1]层；扫描到i时，若d[i]>d[i-1]，左边已有线段最多延伸d[i-1]层，至少新开差值条。若下降，只需结束若干条，无需新开。这既给出不可突破的下界，又能按水平线段达到它，所以答案Σmax(0,d[i]-d[i-1])，d[0]=0。

### 完整 C++17 实现

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

signed main()
{
    int n,last=0,ans=0;
    cin>>n;
    for(int i=1;i<=n;i++)
    {
        int x;
        cin>>x;
        if(x>last) ans+=x-last;
        last=x;
    }
    cout<<ans<<'\n';
    return 0;
}
```

### 作用、使用场景与易错点

差分、区间加减与构造下界。例2,3,1,2贡献2+1+0+1=4，零深度把水平段截断。不要加绝对差，也不用一天一天模拟。时间O(n)，额外空间O(1)。

## P1208 混合牛奶

[洛谷原题](https://www.luogu.com.cn/problem/P1208)

### 概念与策略

有限供应下按单价升序采购，直到需求满足。

### 原理与正确性

若买了贵奶而便宜供应还有剩余，可等量交换，每单位费用下降且需求不变；故存在便宜先买的最优解。供应按整数单位买，本题每单位相同且可买部分产量，不是0/1背包。

### 完整 C++17 实现

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

struct node
{
    int p,a;
}a[5005];
bool cmp(node x,node y)
{
    return x.p<y.p;
}
signed main()
{
    int need,m,ans=0;
    cin>>need>>m;
    for(int i=1;i<=m;i++) cin>>a[i].p>>a[i].a;
    sort(a+1,a+m+1,cmp);
    for(int i=1;i<=m&&need>0;i++)
    {
        int buy=min(need,a[i].a);
        ans+=buy*a[i].p;
        need-=buy;
    }
    cout<<ans<<'\n';
    return 0;
}
```

### 作用、使用场景与易错点

适合货物同质、供应有限、单位价格固定的采购；不同质量或运费门槛需重新证明。需求可以为0，供应总量按题意保证足够。时间O(m log m)，空间O(m)。

## P1094 纪念品分组

[洛谷原题](https://www.luogu.com.cn/problem/P1094)

### 概念与策略

排序后用双指针，每次为最重物品决定单独一组或与最轻者配对。

### 原理与正确性

若最轻+最重仍超上限，最重与任何人都不能同组，必须单独。否则可让最重与最轻配对：若原解二者各与别人配对，把它们换成一对，剩余两件也能成对，因为最重不小于它们，新的剩余对不会超出原来与最重配对的和；有单独者时交换也不增加组数。

### 完整 C++17 实现

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

int a[30005];
signed main()
{
    int w,n;
    cin>>w>>n;
    for(int i=1;i<=n;i++) cin>>a[i];
    sort(a+1,a+n+1);
    int l=1,r=n,ans=0;
    while(l<=r)
    {
        if(l<r&&a[l]+a[r]<=w) l++;
        r--;
        ans++;
    }
    cout<<ans<<'\n';
    return 0;
}
```

### 作用、使用场景与易错点

仅适用于每组最多两件。若最多三件，双指针策略不能原样套用。l==r只剩一件算一组。时间O(n log n)，空间O(n)。

## P4995 跳跳！

[洛谷原题](https://www.luogu.com.cn/problem/P4995)

### 概念与策略

从地面0出发，交替跳剩余最高、最低石头，让大高度差反复出现，目标是最大平方差和。

### 原理与正确性

关键不是“选择最近”，而是让路径高低交错。对a<=b<=c<=d有(d-a)^2+(c-b)^2-[(c-a)^2+(d-b)^2]=2(d-c)(b-a)>=0，说明把高低端交错配对不会降低收益；对路径可通过交换并反转中间子段保持内部边代价，将端点逐步整理为高低交替。地面是全局最低且固定起点，规范最优顺序可取最大、最小、次大、次小……。这一性质依赖平方距离和正高度，不是任意代价函数通用的“最远优先”。

### 完整 C++17 实现

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

int a[305];
signed main()
{
    int n;
    cin>>n;
    for(int i=1;i<=n;i++) cin>>a[i];
    sort(a+1,a+n+1);
    int l=1,r=n,now=0,ans=0;
    bool high=true;
    while(l<=r)
    {
        int x;
        if(high) x=a[r--];
        else x=a[l++];
        ans+=(x-now)*(x-now);
        now=x;
        high=!high;
    }
    cout<<ans<<'\n';
    return 0;
}
```

### 作用、使用场景与易错点

极值交替、凸距离最大化的经典模型。例1,2,3：0→3→1→2得9+4+1=14；只升序得1+1+1=3。不能中途回地面，也不用最后回0。答案用64位。时间O(n log n)，空间O(n)，测试用全排列验证小规模。

## P4447 分组

[洛谷原题](https://www.luogu.com.cn/problem/P4447)

### 概念与策略

排序后将实力x接到末尾为x-1的组中；若可接多个，优先延长其中最短的组。目标是最大化最小组大小。

### 原理与正确性

同一末尾的组有相同未来可接实力，区别只是已有长度。把当前和未来可用延长机会优先分给短组，可以避免短组过早停下成为瓶颈；若一个方案把后续延长给了长组，却让短组停下，可交换这两组后续后缀，连续性不变且最小长度不减。无可接组才新建。用每个末尾值对应的小根堆保存组长。

### 完整 C++17 实现

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

int a[100005];
map<int,priority_queue<int,vector<int>,greater<int>>> q;
signed main()
{
    int n;
    cin>>n;
    for(int i=1;i<=n;i++) cin>>a[i];
    sort(a+1,a+n+1);
    for(int i=1;i<=n;i++)
    {
        int x=a[i],len=0;
        if(!q[x-1].empty())
        {
            len=q[x-1].top();
            q[x-1].pop();
        }
        q[x].push(len+1);
    }
    int ans=n;
    for(auto &item:q)
    {
        if(!item.second.empty()) ans=min(ans,item.second.top());
    }
    cout<<ans<<'\n';
    return 0;
}
```

### 作用、使用场景与易错点

此题的map按实力值查组，priority_queue的top取最短组；auto &item只用于遍历每个“末尾值→小根堆”映射。重复实力不能放同组，负实力不能直接作为数组下标。例1,2,2,3形成两组[1,2]与[2,3]，最小长度2。时间O(n log n)，空间O(n)。

## P1080 国王游戏

[洛谷原题](https://www.luogu.com.cn/problem/P1080)

### 概念与策略

按每位大臣左右手乘积a×b升序排序；维护前面所有左手数乘积，先除当前右手计算奖赏，再乘当前左手。乘积需要高精度。

### 原理与正确性

设当前前缀积P，相邻i,j的乘积满足ai*bi<=aj*bj。顺序i,j的两项为floor(P/bi)、floor(P*ai/bj)；反序j,i包含floor(P*aj/bi)。因为aj>=1，前一项不大于该值；由乘积排序关系，后一项也不大于该值。故正序最大值不大于反序最大值，其他大臣前缀积不变，交换安全。重复消逆序即得结论。

### 完整 C++17 实现

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

struct node
{
    int a,b;
}a[1005];
int num[5005],tmp[5005],best[5005];
int len=1,blen=1;
bool cmp(node x,node y)
{
    return x.a*x.b<y.a*y.b;
}
void mul(int x)
{
    int carry=0;
    for(int i=1;i<=len;i++)
    {
        int v=num[i]*x+carry;
        num[i]=v%10;
        carry=v/10;
    }
    while(carry)
    {
        num[++len]=carry%10;
        carry/=10;
    }
}
void check(int x)
{
    int rem=0;
    for(int i=len;i>=1;i--)
    {
        rem=rem*10+num[i];
        tmp[i]=rem/x;
        rem%=x;
    }
    int tlen=len;
    while(tlen>1&&tmp[tlen]==0) tlen--;
    bool larger=tlen>blen;
    if(tlen==blen)
    {
        for(int i=tlen;i>=1;i--)
        {
            if(tmp[i]!=best[i])
            {
                larger=tmp[i]>best[i];
                break;
            }
        }
    }
    if(larger)
    {
        blen=tlen;
        for(int i=1;i<=blen;i++) best[i]=tmp[i];
    }
}
signed main()
{
    int n,king,right;
    cin>>n>>king>>right;
    for(int i=1;i<=n;i++) cin>>a[i].a>>a[i].b;
    sort(a+1,a+n+1,cmp);
    num[1]=1;
    mul(king);
    for(int i=1;i<=n;i++)
    {
        check(a[i].b);
        mul(a[i].a);
    }
    for(int i=blen;i>=1;i--) cout<<best[i];
    cout<<'\n';
    return 0;
}
```

### 作用、使用场景与易错点

排序交换与高精度组合。num倒序存十进制数字，mul为高精度乘小整数，check从高位长除法得到商并按长度/高位比较最大值。国王始终最前面，他的右手不影响答案；先乘再除会错。最多1001个小于10000的因子，不超过4004位，5005位安全。时间O(n log n+nD)，空间O(n+D)。不能因为#define int long long就省掉高精度。

## P1012 拼数

[洛谷原题](https://www.luogu.com.cn/problem/P1012)

### 概念与策略

比较两个字符串x+y和y+x，较大的排列方式排前面，不能按原数值大小排序。

### 原理与正确性

相邻交换只改变拼接中这两个块；前后内容相同，两种局部拼接长度也相同，因此x+y较大时放x在前不会变差。比较器等价于比较无限周期串的顺序（或x/(10^len(x)-1)），所以具有一致性，能够用于sort；相等时返回false。

### 完整 C++17 实现

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

string a[25];
bool cmp(string x,string y)
{
    return x+y>y+x;
}
signed main()
{
    int n;
    cin>>n;
    for(int i=1;i<=n;i++) cin>>a[i];
    sort(a+1,a+n+1,cmp);
    for(int i=1;i<=n;i++) cout<<a[i];
    cout<<'\n';
    return 0;
}
```

### 作用、使用场景与易错点

适用于把完整数字块排列成最大拼接数。例9与34：934>349，所以9在前；12与121：12121>12112，所以12在前。结果用字符串输出，不做整数转换。若单块最大长度L，时间O(n log n×L)，存储O(nL)。
