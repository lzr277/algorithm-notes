# 学习记录维护约定

- 本目录用于洛谷《深入浅出》学习，讲解和示例使用中文与 C++17。
- 每次新增或修改学习内容，同步更新学习日志，检查代码与本地链接后，仅提交本次涉及的文件并推送 GitHub。
- 不顺带提交仓库中其他已有修改；推送失败时保留本地提交并明确报告原因。
- 手册须包含状态定义、推导、边界、复杂度、手算过程和练习；优先使用可离线打开的交互图解。
- 不把本地测试表述为洛谷评测通过。

- 图片/章节中的每个知识点都必须独立讲解概念、原理、C++ 实现、作用与使用场景，不得仅在例题中提及名称或公式。维护逐节点覆盖表，先知识后例题。

- C++ 采用用户约定风格：bits/stdc++.h、#define int long long、using namespace std、signed main；大括号独占一行，四空格缩进，运算符和参数逗号两侧不额外加空格，保留 cin/cout。优先直观数组和普通循环，不为简短写法引入不必要抽象。

- 知识点讲解要生动易懂，允许充分展开：先用具体场景和小例子建立直觉，再给定义、原理和实现；配合图解、手算表与变量解释，不只堆术语和结论。正文优先更新学习手册并同步动画版，不额外增加分散的阅读文件。

- 网页采用共享阅读主题：参考Hello算法的图解学习顺序和OI Wiki的文档侧栏，顶部保持紧凑、正文宽度适中，目录筛选可用。共享样式/脚本位于阅读主题.css/js；更新旧章外观时保留用户正文，不恢复成大横幅卡片堆叠。参考来源必须实际查阅、在章节中注明，正文图解独立编写。
