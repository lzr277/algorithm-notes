01 状态、搜索树与DFS：带着路标走岔路

概念：一个状态是一张“此时此刻”的照片

填数独时，不必一次想出16个格子的答案。只问：当前填到第几个格子？前面的格子填了什么？当前格还允许哪些数字？这些信息共同决定状态。dfs(u)是“前面已经安排好，现在处理第u个位置”，不是“神奇地解决所有事情”。

如果现在有1、2两个候选，你就有两条岔路：先试1，把后面的事交给下一层；这条路结束，再回来试2。把所有选择画出来，就是搜索树。树节点是部分方案，边是一次选择，叶子可能是完整答案，也可能是走不通的死路。

当前格
├─ 填1 → 下一格 → 再下一格 → 发现冲突 → 返回
└─ 填2 → 下一格 → 再下一格 → 全部完成 → 一个解

原理：先深后广，不代表更容易找到最短路

DFS总是先把一条分支走深，走到边界才回头。它能列举完整方案，是因为每个位置的合法选项都枚举过；能结束，是因为u不断增加，最终到达完成位置。漏掉一个候选就可能漏解，边界里忘记return可能继续访问不存在的位置。

实现骨架与适用场景

dfs(当前阶段)
{
    如果已经完成：记录答案，返回
    枚举这一步的选项
    {
        若选项不可行：跳过
        执行选择，更新标记
        dfs(下一阶段)
        撤销这一步的修改
    }
}

这是结构示意，不是可编译代码。完整实现见数独和皇后。适合排列、组合、填格与需要列举所有解的问题；图上DFS遍历O(V+E)，不代表枚举方案也只是O(V+E)，后者的状态树可能指数大。

02 保存与恢复现场：借走的东西要放回去

直观例子

在第一行放了一个皇后，你把“第2列已用”打勾，然后去安排第二行。如果第二行走不通，回到第一行改试第3列，原来的第2列勾必须擦掉，否则程序会误以为那儿还有皇后。

出发前：col[2]=false
选第2列：col[2]=true
深入下一层：使用这份标记判断冲突
返回以后：col[2]=false
下一次试第3列：从同一个原始局面开始

原理：兄弟分支不能相互污染

恢复不是把整个程序重置，而是只撤销当前分支新增的修改。父层已经放好的皇后不能擦掉，否则子层会接受非法方案。恢复到的是“进入这一轮选择前”，不是“全空棋盘”。

C++ 实现

col[i]=dg[u+i]=udg[n-u+i]=true;
dfs(u+1);
col[i]=dg[u+i]=udg[n-u+i]=false;

这就是AcWing基础课常见的标记—递归—撤销结构。本章完整皇后代码用这套写法适配一基下标。path[u]下一次会被覆盖且输出只在完整解处进行，所以不清零也可以；数独格子若仍会被当作“已给定”读取，则必须恢复为0。

什么时候不用手动恢复

若把left、right作为普通整数参数传给子调用，dfs(u+1,left+a[u],right)只改变子层的参数副本，父层left没有变，因此无需减回来。相反，若修改的是全局left，就要撤销。

还有一个更容易混淆的区别：图遍历和普通BFS的“已经访问”通常不应撤销；枚举当前路径/当前摆法的“已经占用”才需要随分支恢复。先解释标记的含义，再决定是否清除。

03 可行状态与剪枝：明知撞墙就别继续走

概念与原理

剪枝是证明某条分支不可能贡献所需答案后，提前停止探索。不是随便少试几个数。数独行里已经有3，当前格再填3，后面无论怎么填都不能消除重复，所以可以立即跳过。

皇后每行只放一枚，行冲突由递归层数天然排除；只需判断列和两种对角线。同一反斜方向对角线有行-列相等，另一方向有行+列相等。差可能为负，所以加n平移成数组下标。

位置(u,i)对应三个“占用牌”：
列：i
行列和：u+i
行列差的平移：n-u+i

实现与使用场景

if(col[i]||dg[u+i]||udg[n-u+i]) continue;

三张牌只要一张被占，就不用放棋子。不要每次都遍历全部已放皇后，标记数组让单次冲突判断变成O(1)。选列按1..n枚举，完整解自然按字典序输出；若想把比较有希望的列先试，输出顺序可能随之变化。

这种剪枝适合局部冲突不可逆的约束问题。它通常很有效，但不能因此把指数/阶乘上界写成多项式。本章皇后可给安全上界O(n×n!)，记录方案和标记空间O(n)，递归栈O(n)。

04 枚举子集与复杂度：每道题交给左脑还是右脑

概念：选不选就是一棵二叉树

每道习题只能交给一个脑子，左脑收到哪些题就是一个子集，右脑得到它的补集。n道题各二选一，完整分配有2^n种；每层是“处理第几道题”，不是“已经用了多少时间”。

题目时间2、3、5
第1题：左 / 右
每一条分支再给第2题选左 / 右
每一条分支再给第3题选左 / 右
叶子共 2×2×2=8 个

原理与手算

把2、3给左脑，5给右脑，两边都用5，整科5分钟完成。若全部给左脑要10分钟。因为同时工作，单科耗时为max(left,right)，不是left+right；但四科不能同时混着做，所以各科最优耗时最后相加。

实现与剪枝

dfs(u+1,left+a[u],right);
dfs(u+1,left,right+a[u]);

两次调用恰好覆盖所有分配，且每道题只属于一侧，不重不漏。若当前max(left,right)已经>=已知best，后面全是非负耗时，只会变大或不变，不能改进，可以返回。本题只求最优值，所以相等也能剪；若要统计最优方案数，随便剪掉相等分支就会漏计。

作用与复杂度

适合单科题数不大（本题每科至多20）的子集搜索。完整二叉树节点数1+2+...+2^n=2^(n+1)-1，故不计额外每叶扫描时O(2^n)，递归空间O(n)。如果在每个叶子重新求一遍总和，就会变成O(n×2^n)。不要把“参数只有三个”误读成状态数量很少。

05 BFS：像水波一样一圈圈扩散

概念与图解

DFS像一个人沿岔路探索，BFS像水从起点一圈圈漫开：先发现一步能到的点，再发现两步能到的点。层数就是走过的边数。

          起点S           距离0
          /   \
         A     B          距离1
        / \   / \
       C   D E   F        距离2

原理：队列守住层次顺序

先来的先处理，后来发现的点排在队尾。处理距离k的点时，只会加入距离k+1的邻居，不会让它们跑到尚未处理的距离k点前面。所以在每一步代价相同的图里，第一次发现某点时已经得到最短距离。

边代价不同就不成立：一条边花10，另一条绕路两条边各花1，最少边数并非最少代价。此时要学Dijkstra或相应算法，不是给BFS换个变量名就能解决。

AcWing风格数组队列

int hh=0,tt=0;
q[0]=start;
d[start]=0;
while(hh<=tt)
{
    int t=q[hh++];
    // 枚举t的合法邻居j
    // 若d[j]==-1：先赋d[j]=d[t]+1，再q[++tt]=j
}

hh是下一项要取的位置，tt是最后一项已放的位置；q[hh++]取走队头，q[++tt]先移出新的队尾空位再存。只要每个点至多入队一次，数组长度达到点数即可，不必实现循环队列。

完整的可运行AcWing847适配模板在后文，使用本地yxc原始资料的邻接表和层次遍历结构。图上时间O(V+E)，空间O(V+E)，与状态空间大小一起分析，而不只是说“BFS很快”。

06 访问状态与结构体：队列里到底装什么

概念与原理

电梯的状态只需要楼层，所以q存一个整数；马的位置需要x、y两个数，所以q存结构体node。只要两个信息共同决定后续能往哪儿走，就不能只存其中一个。

距离数组d同时承担两个职责：-1表示还没访问，非负数表示已发现且最少走了多少步。初始化不能留0，因为起点的正确距离就是0，不可达却应为-1。

C++ 实现

struct node
{
    int x,y;
}q[160005];

访问邻格时，先检查边界，再检查是否访问过，再赋距离，最后入队。在入队时标记，不等到出队时再标记。 否则同一层几个父节点可能把同一个邻居反复塞进去，既浪费时间，也可能挤爆固定队列。

马与电梯的具体含义

马的八种跳法是(±1,±2)、(±2,±1)，不是可以走任意一格。它可以跳过中间格，不存在象棋“蹩马腿”限制；题目只给了棋盘边界。400×400至多160000个格点，数组队列据此开大小。

电梯在第t层只能去t+k[t]和t-k[t]，下一次移动使用的是新楼层的k值。k[t]=0只是回到原地，已有访问标记会挡住自环；A=B时距离本来就是0，不需要特殊按一次按钮。

使用场景

网格、楼层、棋盘都是“隐式图”：不必预先存出每条边，只要在取出状态后枚举合法下一步。马题O(nm)时间空间，电梯O(n)时间空间，因为每点的转移数量为常数。

07 流星雨：一张格子地图，加一张截止时间表

先分清两个安全概念

某格子t=5才被烧毁，你t=2到达它，当时还安全，但不能在那里永远等下去。题目要的是永远不会被任何流星影响的格子，而不是暂时还没爆炸的格子。

先给每格记录death[x][y]：最早毁坏时刻；从未受影响则为INF。每颗流星不仅影响落点，还影响上下左右，重复影响要取min而不是最后一次覆盖。

       ↑
     ← 落点 →       五个位置同时取最早毁坏时刻
       ↓

原理与实现条件

从时间t走一步，抵达时间nt=t+1，必须满足 nt<death[nx][ny]，等于时已经不安全。出队的格子若death==INF，就找到了永久安全点，按BFS层序它就是最早逃脱时刻。

t=0起点已毁坏 → 直接-1
起点永不毁坏 → 答案0
到某格时刻2，death=2 → 不可进入
到某格时刻2，death=3 → 可以经过，但不是最终目的地

为什么不把时间也作为访问数组的一维

这些危险只会增加、不会消失。对同一格，更早到达不比更晚差：任何后续路线，早出发到达各点也更早，更容易满足截止时刻；等待不会让某条路重新开放。因此每格只保存最早抵达时间就够了。如果换成周期性开门、危险会消失的题，就不能照搬这一结论。

边界与复杂度

原题流星坐标至多300，邻格影响至多301。一旦到达任一坐标为302的非负格子，它必定永久安全；不需要模拟整个无限平面。本程序N=305足够留出安全边界，最多N²个状态，时间O(M+N²)，空间O(N²)。真正保证逃脱的是death==INF，不是看到数组边缘就无条件宣布成功。

08 头文件、模板来源与适配约定

#include <bits/stdc++.h>是GNU C++常用的聚合头文件，方便使用cin、数组算法、vector、queue等；并不是ISO C++标准保证所有编译器都有的头文件。洛谷/AcWing常用GNU C++环境可使用，换到不支持的编译器需显式引入相应标准头。

本章统一使用你的#define int long long和signed main()。宏不会把指数复杂度变快，也不能避免递归栈溢出；数组元素变为8字节后，空间要按实际类型估计。

本地原始DFS片段用int返回类型却无返回值，讲解遍历时应为void；原BFS的if(!s[j])应为if(!st[j])。本章统一用d判断是否入队，避免两份访问状态不同步。

本地AcWing图DFS模板：修正返回类型后使用

下面保留本地yxc模板的邻接表遍历结构，只修正返回类型并统一格式。h/e/ne的建图方式与后面的完整847程序相同，st须先初始化为false。

void dfs(int u)
{
    st[u]=true;
    for(int i=h[u];i!=-1;i=ne[i])
    {
        int j=e[i];
        if(!st[j]) dfs(j);
    }
}

它用于图遍历，不是枚举所有路径：不在返回时把st[u]清除。只调用dfs(1)只能访问1所在的可达部分；若要覆盖所有点，要依次检查每个尚未访问的点并启动一次dfs。深链可能导致递归栈过深，应按规模改用显式栈。

09 六个例题：先手推，再看代码

例1-四阶数独 四阶数独（教学接口）

图片未给出原题号与输入格式，因此采用明确的4×4教学接口：数字1..4，每行/列/2×2宫不重复，0为空，输出首解或No solution。不是某个未核对洛谷题的提交承诺。

用已知完整盘面1 2 3 4 / 3 4 1 2 / 2 1 4 3 / 4 3 2 1，挖掉几个格子来手推。dfs(u)用x=u/4、y=u%4转换成行列。x/2*2+y/2给四个宫编号0..3。先跳过给定数，再试候选，失败撤销。找到首解后一路return true，不再撤销成功盘面，这是刻意保留结果。E个空格，粗略上界O(4^E)，递归深度≤16；本教学盘面大小固定。

#include <bits/stdc++.h>
#define int long long
using namespace std;

// 教学接口：4行，每行4个整数，0为空；输出首个解或No solution。
int g[4][4];
bool row[4][5],col[4][5],box[4][5];
bool dfs(int u)
{
    if(u==16) return true;
    int x=u/4,y=u%4,b=x/2*2+y/2;
    if(g[x][y]) return dfs(u+1);
    for(int v=1;v<=4;v++)
    {
        if(row[x][v]||col[y][v]||box[b][v]) continue;
        g[x][y]=v;
        row[x][v]=col[y][v]=box[b][v]=true;
        if(dfs(u+1)) return true;
        row[x][v]=col[y][v]=box[b][v]=false;
        g[x][y]=0;
    }
    return false;
}
signed main()
{
    bool valid=true;
    for(int x=0;x<4;x++)
    {
        for(int y=0;y<4;y++)
        {
            int v;
            cin>>v;
            g[x][y]=v;
            if(v<0||v>4) valid=false;
            if(v<1||v>4) continue;
            int b=x/2*2+y/2;
            if(row[x][v]||col[y][v]||box[b][v]) valid=false;
            row[x][v]=col[y][v]=box[b][v]=true;
        }
    }
    if(!valid||!dfs(0)) cout<<"No solution\n";
    else
    {
        for(int x=0;x<4;x++)
            for(int y=0;y<4;y++) cout<<g[x][y]<<(y==3?'\n':' ');
    }
    return 0;
}

P1219 八皇后

洛谷原题

题目实际读入n，并非只固定8。输出字典序前三个方案，最后输出总数。

dfs(u)处理第u行，path[u]保存选中的列。n=4时两个方案2 4 1 3与3 1 4 2；第一行试1最终失败，必须撤掉所有新增标记后才能试2。按列升序自然得到字典序；只打印前三个，但不能只搜索前三个，否则总数就错了。

#include <bits/stdc++.h>
#define int long long
using namespace std;

int n,path[15],ans;
bool col[30],dg[30],udg[30];
void dfs(int u)
{
    if(u==n+1)
    {
        ans++;
        if(ans<=3)
            for(int i=1;i<=n;i++) cout<<path[i]<<(i==n?'\n':' ');
        return;
    }
    for(int i=1;i<=n;i++)
    {
        if(col[i]||dg[u+i]||udg[n-u+i]) continue;
        path[u]=i;
        col[i]=dg[u+i]=udg[n-u+i]=true;
        dfs(u+1);
        col[i]=dg[u+i]=udg[n-u+i]=false;
    }
}
signed main()
{
    cin>>n;
    dfs(1);
    cout<<ans<<'\n';
    return 0;
}

P2392 kkksc03考前临时抱佛脚

洛谷原题

每科独立将题目分配给两个脑子并行做，四科最终相加。

一科2、3、5分成(2+3)与5，最优耗时5。另三科若各只有1道题，耗时1、2、3，则全题答案5+1+2+3=11。每科开始必须重置best；把参数left/right的副本传下去，不要额外做错误的全局减法。

#include <bits/stdc++.h>
#define int long long
using namespace std;

int a[25],s[5],n,best;
void dfs(int u,int left,int right)
{
    if(max(left,right)>=best) return;
    if(u==n+1)
    {
        best=max(left,right);
        return;
    }
    dfs(u+1,left+a[u],right);
    dfs(u+1,left,right+a[u]);
}
signed main()
{
    for(int i=1;i<=4;i++) cin>>s[i];
    int ans=0;
    for(int subject=1;subject<=4;subject++)
    {
        n=s[subject];
        best=0;
        for(int i=1;i<=n;i++)
        {
            cin>>a[i];
            best+=a[i];
        }
        dfs(1,0,0);
        ans+=best;
    }
    cout<<ans<<'\n';
    return 0;
}

P1443 马的遍历

洛谷原题

输出起点到棋盘所有格的最少跳跃次数，不可达为-1。

3×3棋盘从(1,1)出发，第一层只有(2,3)、(3,2)，中心(2,2)不可达。这里d既记距离又记访问；找到某一个目标就结束会漏掉其他格子，本题应完整BFS后输出矩阵。

#include <bits/stdc++.h>
#define int long long
using namespace std;

struct node
{
    int x,y;
}q[160005];
int n,m,d[405][405];
int dx[8]={-2,-2,-1,-1,1,1,2,2};
int dy[8]={-1,1,-2,2,-2,2,-1,1};
signed main()
{
    int sx,sy;
    cin>>n>>m>>sx>>sy;
    memset(d,-1,sizeof d);
    int hh=0,tt=0;
    q[0]={sx,sy};
    d[sx][sy]=0;
    while(hh<=tt)
    {
        node t=q[hh++];
        for(int i=0;i<8;i++)
        {
            int x=t.x+dx[i],y=t.y+dy[i];
            if(x<1||x>n||y<1||y>m) continue;
            if(d[x][y]!=-1) continue;
            d[x][y]=d[t.x][t.y]+1;
            q[++tt]={x,y};
        }
    }
    for(int x=1;x<=n;x++)
        for(int y=1;y<=m;y++) cout<<d[x][y]<<(y==m?'\n':' ');
    return 0;
}

P1135 奇怪的电梯

洛谷原题

每层按钮跳跃幅度由当前位置k[t]决定，求最少按键数。

n=5、A=1、B=5、k为3,3,1,2,5，路径1→4→2→5共3次。每次检查落点在1..n内；楼层已访问不能再反复入队。B从未访问时，初始化的d[B]=-1正好是题目要求。

#include <bits/stdc++.h>
#define int long long
using namespace std;

int k[205],d[205],q[205];
signed main()
{
    int n,a,b;
    cin>>n>>a>>b;
    for(int i=1;i<=n;i++) cin>>k[i];
    memset(d,-1,sizeof d);
    int hh=0,tt=0;
    q[0]=a;
    d[a]=0;
    while(hh<=tt)
    {
        int t=q[hh++];
        int next[2]={t+k[t],t-k[t]};
        for(int i=0;i<2;i++)
        {
            int j=next[i];
            if(j<1||j>n||d[j]!=-1) continue;
            d[j]=d[t]+1;
            q[++tt]=j;
        }
    }
    cout<<d[b]<<'\n';
    return 0;
}

P2895 流星雨

洛谷原题

先预处理最早毁坏时间，再BFS找永远安全格。

只有(0,0,2)一颗流星时，原点和(1,0)、(0,1)在2时被毁；t=1可走到(1,0)，t=2再走到永久安全的(2,0)，答案2。若原点在0时毁坏则-1。切记time>=death都不可进入，不只是大于才危险。

#include <bits/stdc++.h>
#define int long long
using namespace std;

const int N=305,INF=1000000000;
struct node
{
    int x,y;
}q[N*N];
int death[N][N],d[N][N];
int dx[5]={0,1,-1,0,0};
int dy[5]={0,0,0,1,-1};
signed main()
{
    for(int x=0;x<N;x++)
        for(int y=0;y<N;y++) death[x][y]=INF;
    int m;
    cin>>m;
    for(int i=1;i<=m;i++)
    {
        int x,y,t;
        cin>>x>>y>>t;
        for(int j=0;j<5;j++)
        {
            int a=x+dx[j],b=y+dy[j];
            if(a>=0&&a<N&&b>=0&&b<N)
                death[a][b]=min(death[a][b],t);
        }
    }
    if(death[0][0]==0)
    {
        cout<<-1<<'\n';
        return 0;
    }
    memset(d,-1,sizeof d);
    int hh=0,tt=0;
    q[0]={0,0};
    d[0][0]=0;
    while(hh<=tt)
    {
        node u=q[hh++];
        if(death[u.x][u.y]==INF)
        {
            cout<<d[u.x][u.y]<<'\n';
            return 0;
        }
        for(int i=1;i<=4;i++)
        {
            int x=u.x+dx[i],y=u.y+dy[i],time=d[u.x][u.y]+1;
            if(x<0||x>=N||y<0||y>=N) continue;
            if(d[x][y]!=-1||time>=death[x][y]) continue;
            d[x][y]=time;
            q[++tt]={x,y};
        }
    }
    cout<<-1<<'\n';
    return 0;
}

10 可运行的AcWing风格图BFS模板

输入n、m及m条有向边（本适配程序n,m≤100000），输出1到n的最少边数，不可达为-1。h是邻接表头，e存边的终点，ne存同一链表的下一条边下标；add不是搜索，它只是建图。模板来自yxc本地资料，队列与距离记录为本章适配。

#include <bits/stdc++.h>
#define int long long
using namespace std;

// 模板来源：yxc/AcWing，本地原始资料/第三章.txt；数组队列和距离记录适配。
const int N=100005,M=100005;
int h[N],e[M],ne[M],idx,d[N],q[N];
void add(int a,int b)
{
    e[idx]=b;
    ne[idx]=h[a];
    h[a]=idx++;
}
signed main()
{
    int n,m;
    cin>>n>>m;
    memset(h,-1,sizeof h);
    memset(d,-1,sizeof d);
    for(int i=1;i<=m;i++)
    {
        int a,b;
        cin>>a>>b;
        add(a,b);
    }
    int hh=0,tt=0;
    q[0]=1;
    d[1]=0;
    while(hh<=tt)
    {
        int t=q[hh++];
        for(int i=h[t];i!=-1;i=ne[i])
        {
            int j=e[i];
            if(d[j]!=-1) continue;
            d[j]=d[t]+1;
            q[++tt]=j;
        }
    }
    cout<<d[n]<<'\n';
    return 0;
}

11 最容易混淆的几件事

情况 是否撤销访问/占用 理由
皇后列与对角占用 回来要撤销 标记描述当前摆法
数独失败候选 撤销数字和三个标记 让下一候选从相同盘面开始
按值传入的left/right 不必手动撤销 父层参数没有被改
图遍历已经访问的点 通常不撤销 避免环与重复遍历
普通BFS的距离数组 不撤销 首次抵达已最短
流星雨最早毁坏时间 不变 它是环境信息，不是当前路径

自测：为什么枚举全部路径时可能要恢复路径访问，而普通最短路BFS不需要？因为前者不同路径是不同答案；后者同一状态以后怎么走相同，重复到达不会带来更短距离。

复习时遮住程序，先写函数含义，再画一个只有2—3层的小搜索树；标明何时入栈/出栈或入队/出队，最后才写代码。遇到错误优先检查恢复现场、入队标记时机、边界和题目究竟要求一个解还是全部解。
